# FR311F 코 세부 부위·직접 의미·명명형 24종

## 목적

눈·눈썹 트랙 다음으로 《神相全編》 동일 계통의 코 전통 해석 자료를 구조화한다.

이번 단계의 핵심은 다음 네 층을 분리하는 것이다.

1. 코 세부 부위 명칭
2. 相山根 / 相鼻의 일반 직접 규칙
3. 코 명명형 24종의 형태 기술
4. 각 명명형에 직접 붙은 전통 의미 주장

중립 관찰 엔진의 코 기하나 provider landmark를 전통 부위와 자동 동일시하지 않는다.

## 출전

### 第632卷 / 神相全編二

五官說에서 코는 審辨官으로 분류된다.

이 항목은 코 연구의 전통 체계 기준선으로만 사용한다.

### 第634卷 / 神相全編四

이번 의미 연구의 직접 본문:

- 相印堂
- 相山根
- 相鼻
- 코 명명형 24종

## 세부 부위 사전

등록:

- 山根
- 鼻梁
- 年上
- 壽上
- 準頭
- 蘭臺
- 廷尉
- 鼻孔
- 竈門

중요:

이 명칭은 전통 문헌 내부 주소다.

예:

- 準頭 != 자동 pronasale
- 山根 != 자동 sellion/nasion
- 蘭臺/廷尉 != 자동 현대 비익 landmark

중립 기하와 연결하려면 별도 전통-관찰 바인딩 검증이 필요하다.

## 相山根 직접 규칙

구조화한 대표 규칙:

- 宜高不宜低折
- 鼻梁不斜曲而常常瑩潤者，晚年有祿
- 山根連額，鼻梁隆隆而起，與額平者，主位至三公
- 山根蹙折，鼻梁蹙小陷折者，主貧乏無成
- 山根枯暗，鼻梁無肉而枯暗者，主與人多不足
- 山根不陷，主壽
- 山根斜曲官災

이 규칙은 역사적 전통 관상 주장으로만 저장한다.

## 相鼻 직접 규칙

대표 구조화:

- 準頭圓 + 鼻孔不昂不露 + 蘭臺廷尉相應
- 光潤豐起
- 色黑肉薄
- 隆高有梁
- 準頭豐大
- 準頭尖細
- 鼻梁圓而貫印堂
- 孔仰露出
- 準頭豐起
- 準頭圓肥
- 準頭尖薄
- 鼻聳天庭
- 鼻梁無骨

총 일반 직접 규칙 20개를 등록한다.

## 구조화 규모

- 전통 코 세부 부위: 9
- 일반 직접 규칙: 20
- 코 명명형: 24
- 명명형 형태·동반조건 기술: 80
- 명명형 의미 주장: 54

## 형태와 의미 분리

예: 伏犀鼻

형태:

- 插天庭中
- 山根直上印堂隆
- 肉不多兮骨不露

의미:

- 神清
- 位立至三公

형태 기술 자체와 높은 지위 판단을 같은 필드에 넣지 않는다.

## 코 외 동반 조건 분리

예: 孤峰鼻

코 자체:

- 鼻大無肉
- 竈門開
- 鼻崔嵬

외부 문맥:

- 兩顴低小

따라서 관골 조건을 코 자체 형태처럼 저장하지 않는다.

猩鼻의:

- 眉眼相挨
- 粗髮毛
- 面闊脣掀身廣厚

도 모두 context로 분리한다.

## 혼합 의미 보존

예: 獅鼻

- 사자형 조건이 온전히 맞으면 富貴
- 그렇지 않으면 財帛有虛盈

이를 하나의 '좋은 코'로 평탄화하지 않는다.

예: 猴鼻

- 富貴
- 恐奸情

재물과 성정 판단이 서로 다른 방향이므로 별도 claim으로 유지한다.

## 권한 경계

FR311F는 다음을 허용하지 않는다.

- 準頭와 pronasale 자동 동일시
- 山根과 현대 해부학 landmark 자동 동일시
- 蘭臺/廷尉와 비익 좌표 자동 연결
- MediaPipe/provider landmark 바인딩
- 수치 임계값
- 코 명명형 자동 사진 분류
- 현대 심리학·의학 사실화
- 실제 미래 예측 사실화
- 상품 해석 자동 활성화

## 검증 상태

이번 24종 명명형과 신규 일반 규칙은
《欽定古今圖書集成》 第634卷 전사를 직접 읽고 구조화한 상태다.

각 신규 항목을 1925 文明書局 NLC 판의 정확한 페이지에서
직접 시각 판독 완료했다고 주장하지 않는다.

따라서 named form:

nlc1925DirectScanAdjudicated = false

를 유지한다.

## 다음 단계

FR311F가 안정되면:

1. 코 명명형·일반 규칙을 FR311C/D와 같은 주제 질의/출력 구조에 연결
2. 코와 다른 부위의 직접 조합 근거 조사
3. 필요할 때만 전통 코 부위 ↔ 중립 관찰 기준 바인딩 연구

순으로 진행한다.

중립 관찰 기술이 이미 존재한다는 이유로 전통 의미를 자동 연결하지 않는다.
