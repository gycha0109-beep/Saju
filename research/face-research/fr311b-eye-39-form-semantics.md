# FR311B 눈 39형 전수 의미 분해

## 목적

FR311에서 등록한 눈 전통 명명형 39개를 실제 원문 의미 단위로 전수 분해한다.

이번 단계에서는 특히 다음 세 층을 분리한다.

- 눈 자체 형태
- 눈 외 동반 조건
- 전통적 의미 주장

동물형·명명형을 현대 이미지 분류명과 자동 동일시하지 않는다.

## 1차 근거

《欽定古今圖書集成》 藝術典 第633卷 / 神相全編三.

39개 명명형은 다음 순서로 연속 수록된다.

龍眼 / 鳳眼 / 猴眼 / 象眼 / 龜眼 / 鵲眼 / 獅眼 / 虎眼 / 牛眼 / 孔雀眼 /
鴛鴦眼 / 鳴鳳眼 / 睡鳳眼 / 瑞鳳眼 / 鴈眼 / 陰陽眼 / 鶴形眼 / 鵝眼 /
桃花眼 / 醉眼 / 鶴眼 / 羊眼 / 魚眼 / 馬眼 / 豬眼 / 蛇眼 / 鴿眼 / 鸞眼 /
狼目 / 伏犀眼 / 鷺鷥眼 / 猿眼 / 鹿眼 / 熊眼 / 蝦眼 / 蟹眼 / 燕眼 /
鷓鴣眼 / 貓眼

FR311B는 제633권 전사를 사람이 읽고 구조화한 상태를
`gujin633_transcription_reviewed`로 기록한다.

1925 文明書局 《神相全編》 NLC416-13jh001662-59167 스캔은
출전 계보에 포함하되, 이번 단계에서 39형 각각의 실물 페이지를
직접 판독 완료했다고 주장하지 않는다.

따라서 모든 레코드:

`nlc1925DirectScanAdjudicated = false`

를 유지한다.

## 규모

- 눈 명명형: 39
- 의미 주장: 116
- 형태·동반조건 기술: 128

## 눈 자체와 외부 조건 분리 예

### 獅眼

눈 자체:

- 眼大
- 威嚴

외부 조건:

- 粗眉
- 전체 인상의 端莊

의미:

- 성정
- 정치·권위
- 부귀
- 수명

따라서 거친 눈썹이 보이지 않는 사진에서
눈만으로 獅眼을 확정하지 않는다.

### 伏犀眼

눈 자체:

- 眼大

외부 조건:

- 頭圓
- 兩眉濃
- 耳內毫長
- 體厚豐

의미:

- 총명
- 고위 관직
- 부귀
- 장수

즉 전통 명명형은 눈 모양만으로 구성되지 않을 수 있다.

### 鸞眼

눈 자체:

- 眼微長

외부 조건:

- 準頭圓大
- 步急
- 言辭媚且良

의미:

- 귀한 신분
- 군주 가까이에서 크게 쓰임

눈 하나의 기하 형태로 환원하지 않는다.

## 관계 근거 예

### 鴛鴦眼

- 夫妻情順又且美
  - 배우자 관계
  - favorable

별도의 성적 판단 문구도 존재하므로
부부 관계와 성적 성향 주장을 한 덩어리로 합치지 않는다.

### 鳴鳳眼

- 中年而遇貴
  - 중년
  - 귀인 지원

인복 렌즈에서 귀인 근거로 조회할 수 있지만
이를 숫자 점수로 합산하지 않는다.

### 龜眼

- 悠遠綿綿及子孫
  - 후손 관련 긍정 주장

### 蟹眼

- 有兒不得供親養
  - 자녀 존재
  - 부모 봉양 부족

자녀와 효양 문제를 별도 주제로 보존한다.

## 불확실 전사 보존

다음 항목은 제633권 전사 문구 자체가 불안정하거나
현대 해석을 확정하기 어려운 부분이 있어
`reviewed_with_uncertainty`를 사용한다.

- 熊眼
- 蝦眼
- 貓眼

예:

- 熊眼 말미
- 蝦眼의 오행·시기 관련 구절
- 貓眼의 구두점과 식생활 관련 구절

이 항목들은 불확실 문구를
`phrase_uncertain`으로 보존한다.

후속 1925 NLC 실물 스캔 대조 없이
강한 의미 판정으로 승격하지 않는다.

## 관계 근거 렌즈

FR311B는 `eye_relational_evidence` 조회를 제공한다.

대상:

- 형제
- 부모
- 배우자
- 자녀
- 귀인
- 효양
- 기타 직접 관계 주제

결과는 관련 claim id만 반환한다.

금지:

- 인복 점수
- 관계 운 자동 좋음/나쁨 판정
- 재물·신분·성정 주장을 관계 근거로 전환
- 서로 다른 눈 형의 주장 합산

## 권한 경계

FR311B는 다음을 허용하지 않는다.

- 39형을 사진에서 자동 판정
- 동물형 명칭을 현대 기하 형태로 자동 번역
- 랜드마크/좌표 연결
- 임계값
- 분류기
- 현대 심리학·의학 사실화
- 전통 문구의 실제 미래 예측 사실화
- 상품 해석 자동 활성화
- 불확실 전사를 확정 사실로 승격
