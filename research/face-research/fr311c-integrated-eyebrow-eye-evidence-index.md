# FR311C 눈썹·눈 통합 해석 색인 및 조합 판정기

## 목적

FR311, FR311A, FR311B에서 축적한 눈썹·눈 전통 관상 근거를 실제 질의에서 안전하게 조회할 수 있게 통합한다.

이번 단계는 새로운 전통 의미를 추가하는 단계가 아니다.

- 기존 직접 근거를 색인한다.
- 사용자 질문을 관련 주제로 변환한다.
- 직접 조합과 단순 병렬 근거를 구분한다.
- 긍정/부정 근거가 동시에 존재하면 충돌을 그대로 보존한다.
- 근거 없는 강화·상쇄·점수화를 금지한다.

## 입력 자료

### FR311

- 일반 눈썹·눈 형태
- 직접 형태 해석 규칙
- 직접 눈×눈썹 조합 규칙
- 대표 직접 조합:
  - 目短眉長 → 愈益田莊

### FR311A

- 눈썹 전통 명명형 24개
- 의미 주장 87개

### FR311B

- 눈 전통 명명형 39개
- 의미 주장 116개

따라서 FR311C의 명명형 의미 색인은:

- 명명형 63개
- 직접 의미 주장 203개

를 포함한다.

## 통합 색인

FR311A/B 원본 레코드를 복제하지 않고 공통 조회 레코드로 색인한다.

각 색인 항목은 최소 다음을 유지한다.

- 원본 claim id
- 눈썹/눈
- form key
- 전통 명칭
- 주제
- 관계 대상
- 시기
- 전통적 긍정/부정/혼합/조건부 상태
- 전사 확실성
- 직접 원문 조각
- 의미 요약
- 출전

FR311 일반 규칙은 별도 direct-rule 색인으로 유지한다.

## 질의 렌즈

지원 렌즈:

- 인복
- 대인관계
- 재물
- 부부
- 형제
- 귀인
- 관직·출세
- 자녀

### 인복

인복은 원문 고유 개념이나 점수로 만들지 않는다.

다음 직접 관계 근거를 조회하는 상위 렌즈다.

- 부모
- 형제
- 배우자
- 자녀/후손
- 친족
- 친구
- 귀인
- 효양

예:

柳葉眉에는

- 骨肉情疏
- 友交忠信
- 貴人盼

가 함께 존재한다.

따라서 FR311C는:

- 친족 부정 근거
- 친구 긍정 근거
- 귀인 긍정 근거

를 모두 반환하고 `source_conflict`로 보존할 수 있다.

`인복 좋음` 같은 단일 점수로 압축하지 않는다.

## 조합 판정

### direct_source_combination

문헌이 정확한 조합을 직접 하나의 규칙으로 명시한다.

예:

`目短 + 眉長`

→ FR311 직접 규칙
→ 재물 관련 의미

추가 강화 의미는 만들지 않는다.

### named_form_context

어떤 형태가 특정 명명형 설명 안의 동반 조건으로 직접 등장한다.

현재 제한적으로 연결한 예:

- 新月眉 + 目秀
- 黃薄眉 + 目長
- 獅眼 + 粗眉
- 伏犀眼 + 兩眉濃

이들은 해당 명명형의 원문 문맥이지,
모든 얼굴에 적용되는 독립 일반 공식이 아니다.

### parallel_evidence_only

각 형태는 기존 직접 규칙에 등장하지만
그 정확한 조합 의미는 원문이 직접 말하지 않는다.

예:

`平 눈썹 + 目尾相垂`

각 요소에 대한 근거는 존재하지만
둘의 결합 의미를 별도로 만드는 것은 금지한다.

### unsupported

조합을 뒷받침할 직접 근거 자체가 충분하지 않다.

새 의미를 생성하지 않는다.

## 충돌 처리

같은 질의에서 다음이 동시에 존재하면:

- favorable 직접 근거
- challenging 직접 근거

`source_conflict`로 처리한다.

금지:

- 평균
- 우선순위 자동 생성
- 다수결
- 긍정/부정 상쇄
- 강화 계산

## 불확실 전사

FR311B의 `phrase_uncertain`은 통합 색인에서도 그대로 유지한다.

불확실 문구를 확정 근거와 합쳐 하나의 강한 결론으로 만들지 않는다.

## 권한 경계

FR311C는 다음을 허용하지 않는다.

- 인복 점수
- 전통 길흉 자동 점수화
- 근거 없는 조합 합성
- 강화/상쇄 자동 추론
- 출전 우선순위 자동 결정
- 명명형 사진 자동 분류
- 랜드마크/좌표/임계값 연결
- 현대 심리학·의학 사실화
- 상품 해석 자동 활성화

## 합격 사례

1. `目短 + 眉長 / 재물`
   - direct_source_combination

2. `平 눈썹 + 目尾相垂`
   - parallel_evidence_only

3. `柳葉眉 / 인복`
   - 친족 부정 + 친구 긍정 + 귀인 긍정
   - source_conflict
   - 점수 없음

4. `鳴鳳眼 / 귀인`
   - 중년 귀인 직접 근거 반환

5. `鴛鴦眼 / 부부`
   - 부부 직접 근거만 반환
   - 별도 sexuality 주장을 부부 근거에 섞지 않음

6. `龍眼 / 인복`
   - 관계 직접 근거 없음

## 다음 단계

FR311C가 안정되면 두 선택지가 있다.

1. 같은 神相全編 계열에서 눈·눈썹 직접 조합 근거를 추가 조사
2. 柳莊相法 등 다른 계통의 눈·눈썹 의미를 별도 계통으로 구축한 뒤 비교

어느 경우에도 서로 다른 계통의 의미를 자동 합치지 않는다.
