# FR309A 십삼부위 하위 부위 사전

## 목적

FR309에서 등록한 십삼부위 13개 주축 아래에 실제 전통 명칭으로 등장하는 하위 부위 주소를 붙인다.

이번 단계는 얼굴 주소 체계 확장이다. 길흉, 성격, 인복, 재물, 배우자 등 의미 해석은 발행하지 않는다.

## 식별자

관찰 엔진에서 FR310 식별자가 이미 사용 중이므로, 본 작업은 FR309의 직접 후속인 FR309A로 둔다.

## 하위 부위 수

FR309A v1은 총 125개의 하위 주소를 등록한다.

예:

- 天中 → 天嶽, 左廂, 內府, 高廣, 尺陽, 武庫, 軍門, 輔角, 邊地
- 山根 → 太陽, 中陽, 少陽, 外陽, 魚尾, 奸門, 神光, 倉井, 天門, 玄武

- 地閣 → 下舍, 奴僕, 碓磨, 坑塹, 地庫, 陂池, 鵝鴨, 大海, 舟車

## FR309 연결

FR309에 이미 존재하는 이름은 새 객체로 다른 얼굴 부위인 것처럼 복제하지 않고 관계만 연결한다.

현재 명시 연결:

- 邊地 → biandi
- 驛馬 → yima
- 山林 → shanlin
- 魚尾 → yuwei
- 奸門 → jianmen
- 地庫 → diku

## 권한 경계

FR309A는 다음을 허용하지 않는다.

- 세부 부위 → 성격 해석
- 세부 부위 → 길흉 해석
- 세부 부위 → 인복/재물/배우자 해석
- 전통 부위 → 현대 얼굴 좌표 자동 대응
- 전통 부위 → 제공자 랜드마크 자동 대응
- 숫자 임계값
- 분류기
- 상품 해석 활성화

또한 1925 실물 스캔 파일이 공개돼 있다는 사실과, 해당 페이지를 사람이 직접 판독해 글자를 확정했다는 사실을 구분한다. 현재 코드의 `directPageImageAdjudicated` 및 `scanAdjudicated`는 false다.
