# FR311 눈썹·눈 전통 해석 연구 v1

## 목적

FR309/FR309A에서 마련한 얼굴 주소 체계를 실제 전통 해석 연구에 사용한다.

이번 단계의 핵심은 다음 세 층을 분리하는 것이다.

1. 원문이 사용하는 일반 형태 표현
2. 문헌이 붙인 복합 명명형
3. 원문이 직접 연결한 전통 해석

현대 관찰 표현과 전통 명명형을 임의로 동일시하지 않는다.

## 근거

### 《欽定古今圖書集成》 藝術典 제633권 / 《神相全編三》

공개 페이지:

- page 30: 論眉 / 相眉 및 초기 눈썹 명명형
  - https://zh.wikisource.org/wiki/Page:Gujin_Tushu_Jicheng,_Volume_473_(1700-1725).djvu/30
- page 31: 후반 눈썹 명명형 / 相目論 시작
  - https://zh.wikisource.org/wiki/Page:Gujin_Tushu_Jicheng,_Volume_473_(1700-1725).djvu/31

두 페이지는 현재 위키문헌에서 교정 완료된 본문으로 간주하지 않는다.
FR311은 해당 스캔 면에 연결된 전사를 연구 표면으로 사용하며,
직접 스캔 글자 판독을 완료했다고 승격하지 않는다.

### NLC 1925 《神相全編》 / 卷三 / 達摩相眼

기존 저장소 FR176 → FR182 계보를 재사용한다.

FR182가 직접 스캔 위치를 고정한 형태 문구:

- 秀而正
- 細而長
- 目大而光
- 目有三角
- 目長一寸
- 目尾相垂

따라서 이 선택 문구들은 새 전자본문 후보보다 강한 기존 저장소 근거를 재사용한다.

중요:

따라서:

`平 == 一字眉`

라는 동치는 허용하지 않는다.

## 직접 해석 규칙

### 눈썹

FR311 v1이 구조화한 직접 출전 규칙:

- 細平而闊、秀而長
  - 성정 / 총명 관련
  - `平` 하나의 의미로 분해하지 않음
- 粗而濃、逆而亂、短而蹙
  - 성정 관련
  - 각 단어 하나씩 독립 규칙으로 분해하지 않음
- 眉過眼
  - 부귀 관련
- 短不覆眼
  - 재물 부족 관련
- 壓眼
  - 곤궁 관련
- 昂
  - 강한 기질 관련
- 卓而豎
  - 호방한 성정 관련
- 尾垂眼
  - 유약한 성정 관련
- 眉頭交
  - 재물·형제 관계 관련
- 眉逆生
  - 배우자·자녀 관계 관련
- 眉高居額中
  - 높은 지위 관련

### 눈

기존 직접 스캔 계보를 재사용한 규칙:

- 目秀而長
  - 지위/관직 관련
- 目大而光
  - 재산 관련
- 目有三角
  - 성정 관련
- 目長一寸
  - 지위/관직 관련
- 目尾相垂
  - 부부 관계 관련

전통적 판단을 역사적 자료로 보존할 뿐,
현대 심리학·의학·인과적 사실로 인정하지 않는다.

## 직접 조합 규칙

### 허용

`目短眉長`

원문 자체가 눈과 눈썹을 함께 묶어 재산 관련 의미를 직접 제시한다.

따라서 FR311은 이 정확한 조합을
`direct_source_cross_region_combination`으로 기록한다.

### 차단 예

`平` 눈썹 + `目尾相垂`

현재 FR311 근거에서는 이 둘을 함께 묶어
새로운 인복/대인관계/부부/성격 의미를 만드는 직접 조합 구절이 없다.

따라서 질의 결과는:

`unsupported_no_direct_source_combination`

이어야 한다.

각 단일 규칙의 존재를 이유로
AI가 새로운 종합 의미를 만들어서는 안 된다.

v1에서 사용하는 주제:

- temperament

- wealth
- status
- career_reputation
- siblings

- children_family

주제는 검색/분류용이며
서로 다른 원문 의미를 자동 합산하는 점수 체계가 아니다.

## 권한 경계

FR311은 다음을 열지 않는다.

- 명명형 = 현대 형태의 자동 동치
- 사진 좌표 / 랜드마크 연결
- 각도 임계값
- 길이 비율 임계값
- 형태 분류기
- 현대 심리·의학 사실 주장
- 출전 없는 부위 간 의미 합성
- 사용자 대상 상품 해석

## 다음 연구

FR311 v1 다음 우선순위는 명확하다.

1. 24개 눈썹 명명형 각각의 원문 의미 분해
2. 39개 눈 명명형 각각의 원문 의미 분해
3. 주제별 직접 근거 색인
4. 같은 부위 내부의 직접 조합 규칙
5. 눈썹 × 눈 직접 조합 규칙 추가 조사
6. 인복/대인관계 질문에서 직접 근거가 실제로 존재하는지 별도 검증

기술 측정 연구는 이 전통 의미 연구를 막지 않는다.
