# FR311D 관상 해석 출력 계약

## 목적

FR311C가 찾아낸 전통 관상 근거를 사용자에게 보여줄 수 있는 구조화된 출력으로 변환한다.

FR311D는 새로운 전통 의미를 발명하지 않는다.
기존 원문 근거의 의미 요약, 직접 규칙, 조합 판정, 충돌, 불확실성을 보존해 출력한다.

## 출력 구조

- 질의 주제
- 출력 상태
- 한 줄 요약
- 긍정 직접 근거
- 부정 직접 근거
- 혼합/조건부 근거
- 불확실 전사 근거
- 일반 직접 규칙
- 명명형 내부 문맥
- 조합 판정
- 출전 refs
- 제한사항
- 전통 문헌 해석 고지

## 출력 상태

### conflict

같은 주제에 favorable / challenging 직접 근거가 함께 존재한다.

예:

柳葉眉 + 鳴鳳眼 / 인복

- 柳葉眉: 骨肉情疏
- 柳葉眉: 友交忠信
- 柳葉眉: 貴人盼
- 鳴鳳眼: 中年而遇貴

긍정·부정 근거를 모두 보여주며 어느 하나를 우선하지 않는다.

### direct_combination

문헌이 정확한 특징 조합을 하나의 직접 규칙으로 말한다.

예:

目短 + 眉長 / 재물

직접 규칙:

目短眉長，愈益田莊

이 경우에도 강도가 더 세진다는 추가 의미는 만들지 않는다.

### named_form_context

특정 명명형 설명 안에 다른 부위 특징이 동반 조건으로 등장한다.

예:

新月眉 + 目秀

이는 新月眉 원문 문맥이지 독립적인 모든 얼굴용 조합 공식이 아니다.

### parallel_evidence

각 특징의 개별 근거는 존재하지만 정확한 조합 의미는 확인되지 않는다.

예:

平 눈썹 + 目尾相垂

개별 근거만 표시한다.

### no_direct_evidence

현재 질의 주제와 선택 특징 사이에 직접 근거가 없다.

다른 주제의 재물/신분/성정 의미를 가져와 빈칸을 채우지 않는다.

## 불확실 전사

FR311B의 phrase_uncertain은 별도 uncertain 영역으로 출력한다.

확정 직접 근거와 같은 수준으로 표현하지 않는다.

## 고정 고지

모든 결과는 다음 의미 경계를 유지한다.

"전통 관상 문헌에 기록된 해석을 정리한 것이며 현대 과학·심리·의학적 사실이나 실제 미래 예측을 뜻하지 않는다."

## 금지

- 점수
- 자동 길흉 결론
- 긍정/부정 다수결
- 강화/상쇄 추론
- 출전 우선순위 임의 생성
- 직접 근거 없는 합성
- 전통 명명형 사진 자동 판정
- 현대 심리·의학 사실화
- 실제 미래 예측
- 상품 예측 문구 자동 활성화

## 합격 사례

1. 柳葉眉 + 鳴鳳眼 / 인복 -> conflict
2. 目短 + 眉長 / 재물 -> direct_combination
3. 平 + 目尾相垂 / 인복 -> parallel_evidence
4. 新月眉 + 目秀 -> named_form_context
5. 龍眼 / 인복 -> no_direct_evidence
6. 불확실 전사 claim -> uncertain section

## 다음 단계

FR311D 이후에는 두 방향이 가능하다.

1. 제품 표현층에서 이 구조화된 출력을 자연어 문장으로 표현하되 FR311D 경계를 그대로 유지
2. 같은 神相全編 계열에서 눈×눈썹 직접 조합 근거를 추가 수집해 FR311C/D가 사용할 근거 밀도를 높임

제품 문장 생성은 구조화된 근거보다 강한 내용을 말할 수 없다.
