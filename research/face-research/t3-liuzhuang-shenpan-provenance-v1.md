## 1. Research question

The verified 1925 文明書局 scans now repeatedly read `審辨官`:

- NLC416 + NLC511 `五行貴賤` combined locus;
- NLC416 + NLC511 separate `五官說` / nose locus.

The remaining T3 question was therefore not another glyph guess. It was:

> Where did the repository/electronic `審判官` transmission come from, and may it be treated as independent historical authority?

## 2. Earliest dated electronic manifestation located

The earliest dated web manifestation located in this bounded search is:

```text
Bongta / 유장상법(柳莊相法)
published: 2009-02-04 11:55 KST
URL: https://bongta.tistory.com/466
```

It preserves `審判官` repeatedly:

- `五行貴賤`: `鼻爲審判官`;
- `五官說 / 五星說`: `四曰鼻爲審判官`;
- following nose section: `鼻爲審判官`.

## 3. Critical provenance note from the source itself

The Bongta page explicitly states that its traditional-character text was converted with HWP and warns that:

- some characters were converted incorrectly;
- readers should compare the appended simplified-character text;
- the underlying source itself contains some typos.

This matters because the same page also appends the simplified text.

The simplified block already reads:

```text
鼻为审判官
四曰鼻为审判官
三十、鼻为审判官
```

Therefore:

```text
審判官 was NOT created merely by the HWP simplified→traditional conversion.
```

However, the page does not identify a directly inspectable printed edition or scan for the simplified source from which it was copied.

The upstream source remains unpinned.

## 4. Later electronic manifestations

The same `审判官` reading and closely matching surrounding text appear in later web reproductions including:

- `柳庄相法上册` at mlzxfw.com;
- `柳庄相法` at gushu.net.cn;
- later article/readers reproducing the same chapter structure and reading.

These pages demonstrate that a modern electronic `審判官 / 审判官` transmission exists.

They do **not** establish multiple independent historical witnesses.

The shared chapter order, repeated wording, and repeated textual anomalies are consistent with copying from a shared electronic ancestor or derivative web-text family. The exact copy direction among every later site is not proven here.

## 5. Modern printed derivative

A 2024 Korean POD book by D.J.O 동양의철학 연구소 lists the same chapter structure and labels chapter 30 `鼻爲審判官`.

That confirms persistence of the modern `審判官` reading into a printed derivative.

It does not retroactively create an independent historical 柳莊 witness because its upstream textual basis has not been demonstrated as independent of the modern electronic family.

## 8. Why this is not called an OCR error

The evidence is insufficient to say exactly how `審辨` became `審判`.

Possible mechanisms include manual transcription, an upstream OCR/transcription substitution, editorial normalization, or a genuinely different source not yet located.

No directly inspected historical `審判官` scan has been found in this bounded pass.

Therefore:

```text
delete 審判官 = NO
call 審判官 a proven OCR error = NO
count it as independent historical authority = NO
```
