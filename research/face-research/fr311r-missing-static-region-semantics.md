# FR311R — 누락 정적 얼굴 지역 의미 연구

## 목적

기존 FR311 통합 의미 인덱스가 눈썹·눈·코·인중/입/입술·귀에 편중되어 있던 문제를 해소한다.

이번 단계에서 추가한 핵심 지역:

- 이마: 額 / 天中 / 天庭 / 司空 / 中正 / 印堂
- 광대: 兩顴 / 左顴 / 右顴
- 턱·하관: 頦 / 地閣 / 頤 / 腮 / 承漿 / 地倉 / 懸壁 / 燕頷
- 얼굴 전체: 面 / 頭面骨格

## 의미 경계

원문의 재물·지위·수명·부모·성정 등 판단은 **역사적 전통 교리 데이터**로만 보존한다.

다음은 계속 금지한다.

- 현대 사실로 간주
- 사진 landmark와 전통 부위 직접 등치
- 임의 수치 threshold
- population norm
- named-form 자동 분류
- 자동 전통 관상 binding
- 제품 해석

특히 수명·부모 결과·성격·도덕성·범죄성은 product fact로 승격하지 않는다.
