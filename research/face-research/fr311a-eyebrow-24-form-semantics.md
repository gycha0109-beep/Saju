# FR311A 눈썹 24형 전수 의미 분해

## 목적

FR311에서 등록한 눈썹 전통 명명형 24개를 실제 원문 의미 단위로 전수 분해한다.

이번 단계의 핵심은 명명형 하나를 한 줄 운세로 압축하지 않고 다음을 분리하는 것이다.

- 원문 전체
- 형태 기술
- 관계·시기·주제별 의미 주장
- 조건부 판단
- 출전 상태
- 현대 형태 자동 대응 금지

## 1차 근거

### 《欽定古今圖書集成》 藝術典 第633卷 / 神相全編三

24개 명명형은 다음 순서로 연속 수록된다.

鬼眉 / 疏散眉 / 黃薄眉 / 掃箒眉 / 尖刀眉 / 八字眉 / 羅漢眉 / 龍眉 /
柳葉眉 / 劍眉 / 獅子眉 / 前清後疏眉 / 輕清眉 / 短促秀眉 / 旋螺眉 /
一字眉 / 臥蠶眉 / 新月眉 / 虎眉 / 小掃箒眉 / 大短促眉 / 清秀眉 /
間斷眉 / 交加眉

FR311A는 위키문헌 제633권 전사를 사람이 읽고 구조화한 상태를
`gujin633_transcription_reviewed`로 기록한다.

### 1925 文明書局 《神相全編》

NLC416-13jh001662-59167 실물 PDF가 공개돼 있다는 사실은 출전 계보에 남긴다.
그러나 이번 FR311A에서는 해당 24개 항목의 1925 스캔 페이지를 직접 대조 완료했다고 주장하지 않는다.

따라서 모든 레코드:

`nlc1925DirectScanAdjudicated = false`

를 유지한다.

## 규모

- 명명형: 24
- 의미 주장: 87
- 형태·문맥 기술: 63

## 구조 예시

### 柳葉眉

형태·문맥:

- 眉粗帶濁濁中清

의미는 별도 주장으로 분리:

- 骨肉情疏 → 친족 관계의 소원함
- 生子遲 → 자녀가 늦음
- 友交忠信 → 교우의 신의
- 貴人盼 → 귀인의 주목·지원
- 發達顯揚名 → 발달·명성

즉 “유엽미는 인복이 좋다”로 한 줄 변환하지 않는다.

### 一字眉

형태:

- 毫清
- 首尾皆如蓋

의미:

- 富貴 → 재물/신분
- 壽且高 → 수명
- 少年發達登科早 → 초년 발달/과거
- 夫婦齊眉到白頭 → 부부 관계

`一字眉 == 현대적 완전 수평 눈썹` 같은 자동 동치는 여전히 금지한다.

### 前清後疏眉

시기를 보존한다.

- 초년: 공명·재물 평범
- 중년: 명리 성취
- 말년: 발탁·가문 명예

이를 하나의 “좋음/나쁨”으로 압축하지 않는다.

### 間斷眉

부모 관련 순서를 보존한다.

- 先損娘
- 後損爹

현대 사실 주장이나 예측으로 사용하지 않고, 전통 문헌의 역사적 주장으로만 저장한다.

## 인복 렌즈

`인복`은 원문 고유 개념으로 등록하지 않는다.

FR311A의 `inbok_relational_evidence` 렌즈는 다음 직접 관계 주장만 조회한다.

- 부모
- 형제
- 배우자
- 자녀/후손
- 친족
- 친구
- 귀인

결과는 관련 claim id를 반환할 뿐:

- 점수 생성 금지
- 좋음/나쁨 자동 종합 금지
- 다른 재물·신분 주장을 인복으로 변환 금지

예:

柳葉眉는 친족 소원 / 친구 신의 / 귀인 지원이 동시에 존재하므로
이 세 근거를 각각 반환한다.

旋螺眉는 현재 직접 관계 주장이 없으므로
`no_direct_relational_evidence`를 반환한다.

## 권한 경계

FR311A는 다음을 허용하지 않는다.

- 전통 명명형을 사진에서 자동 판정
- 현대 눈썹 분류명과 자동 동일시
- 랜드마크/좌표/임계값 연결
- 인복 점수
- 현대 심리학·의학적 사실화
- 전통 문구의 실제 미래 예측 사실화
- 사용자 대상 상품 해석 활성화
