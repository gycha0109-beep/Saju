# FR311S — 정적 관상 구조 체계 연구

## 목적

부위별 의미 규칙만 모으고 삼정·오악·육부·십이궁 같은 **전통 방법론의 구조 자체를 생략하는 문제**를 방지한다.

이번 단계는 전통 구조를 사진 좌표로 변환하지 않는다. 원전 계보별 구조 정의를 연구 데이터로 고정한다.

## 삼정 계보 분리

### 631권 계보

- 上停: 髮際 → 眉間
- 中停: 眉間 → 鼻
- 下停: 準下人中 → 頦

### 632권 계보

- 上停: 髮際 → 眉
- 中停: 眉 → 準頭
- 下停: 準頭 → 地閣

두 계보는 표현이 완전히 같지 않다.

따라서:

```text
631 삼정
+ 632 삼정
→ 개발자가 고른 하나의 canonical 경계
```

를 만들지 않는다.

각각 별도 methodologyId를 유지하고, 실제 neutral geometry binding은 후속 별도 연구 대상으로 남긴다.
