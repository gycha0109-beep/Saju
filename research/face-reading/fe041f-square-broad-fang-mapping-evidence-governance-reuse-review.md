# FE041F — Square/Broad `方` Mapping-Evidence Governance Reuse Review

Watchtower-Track: `face-reading`

## Why this phase exists

FE041D/FE041E established that the three FR142 neutral `方` candidate metrics
are **not** members of the FE035B 13-metric canonical product registry.

The next semantic question therefore cannot be answered by picking the
"closest-looking" product metric or inventing a threshold.

Saju already has a mature evidence-governance template for a different
criterion family: FR185 defines ten prerequisites for Eye-Pair `細/長`
metric-to-concept mapping. FE041F performs an explicit reuse review of that
**governance structure only**.

No Eye-Pair metric, mapping relation, directionality, threshold, calibration,
or semantic conclusion is copied into `方`.

## Reuse decision

The FR185 ten-key evidence structure is reusable because it describes the
evidence classes needed before a neutral metric can be bound to a traditional
concept. Every evidence item remains criterion-specific.

For square/broad `方`, current status is:

- satisfied: source concept identity + pinned provenance;
- satisfied: exact candidate neutral metric identity + versioned definition;
- missing: explicit mapping-hypothesis provenance;
- missing: independent blinded expert operationalization;
- missing: repeat-capture stability;
- missing: source-grounded construct correspondence;
- missing: alternative-metric/confound rejection;
- missing: end-to-end evidence traceability;
- missing: explicit mapping acceptance/rejection decision;
- missing: fail-closed completeness of the final evidence set.

So the current count is **2 / 10 satisfied, 8 / 10 unresolved**.

## Existing square/broad evidence does not silently close those gaps

FR143 proves synthetic numeric behavior only. FR151 records perturbation-review
support while independent multi-session evidence and construct validation stay
closed. FR157 still does not provision an external trust root or admit
independent-session evidence. FR140 has an independent-human-reviewer role, but
no concrete reviewer actor and no collection authorization.

## Neutral canonicalization is a separate lane

FR185 governs metric-to-concept mapping evidence. It does **not** define how a
new neutral metric is promoted into the product canonical registry.

FE035B explicitly says:

- v1 is not mutated in place;
- a new neutral metric requires a new contract version;
- registry membership never implies semantic authority.

Therefore FE041F does not invent a neutral-metric canonicalization policy and
does not issue a successor registry.

## Next frontier

Two independent research lanes may now proceed without conflation:

1. define explicit `方` mapping-hypothesis provenance for each FR142 candidate,
   following the FR186-style evidence pattern but using square/broad source
   lineage only;
2. define a separate neutral candidate canonicalization policy before any
   FE035B successor registry can admit the new metrics.

Threshold and calibration work remains downstream of mapping evidence.
