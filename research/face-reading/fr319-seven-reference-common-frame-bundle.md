## Exact-capture requirement

A common coordinate frame alone is not enough.

FR319 separately requires private provenance proving that every one of the seven scalar values belongs to the same exact capture.

For each reference, private provenance must attest:

- exact capture binding;
- exact source value binding;
- governed source authority;
- private provenance availability;
- the exact source capture digest.

All seven digests must be identical.

Same subject, same session, synchronization, or coordinate-frame equality does not substitute for exact-capture binding.

## Privacy

The exact source capture digest is accepted only as private runtime evidence.

The repository-safe receipt never persists:

- source capture digest;
- subject id;
- capture id;
- raw provenance;
- subject-level reference values.

The runtime bundle can contain the seven scalar values in memory, but those values are not a repository-safe artifact.

Tests may use real-local-shaped fixtures only to validate the contract code path. They are not real evidence and do not change the repository gate.
