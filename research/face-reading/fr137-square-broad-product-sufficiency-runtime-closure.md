# FR137 — Square-Broad Product Sufficiency Runtime Closure

## Decision

`criterion.intake.square_broad` (`方大`) is not product-semantically executable on the current authority chain.

FR137 therefore closes the product boundary with the repository's existing diagnosis vocabulary:

- `diagnosisResolution = unsupported_method`
- `unavailableSections = ['five_officers.intake.static_support']`
- no machine criterion state
- no structured traditional claim
- no bounded traditional narrative
- no `ProductFaceReadingSemanticV3` issuance for this criterion
- no `CharacterFaceGrounding` issuance for this criterion

This is a runtime closure, not a new traditional interpretation and not a promotion of the research diagnosis runtime.

## Why this is the production-safe result

FR122 already establishes that `criterion.intake.square_broad` has no authorized traditional metric binding, calibrated threshold, machine criterion state, or semantic slice. FR136 further establishes that no existing human-annotation authority, protocol, label schema, reviewer policy, or consensus policy can be reused as criterion-specific authority for `方大`.

The repository contract already contains `FaceDiagnosisResolution = 'resolved' | 'resolved_mixed' | 'unsupported_method'` and section-level `unavailableSections`. FR137 uses those existing concepts rather than inventing a new product state.

## Neutral geometry boundary

FR134's role-invariant neutral shape metrics remain measurable neutral geometry only. FR137 deliberately accepts no neutral metric values as runtime input. This makes the following shortcut structurally unavailable:

`neutral metric value -> 方 / 大 / 方大 criterion state`

FR137 also accepts no research fixture or human-label assertion state. The existing `research-diagnosis-runtime.ts` remains `research_only` and is not promoted by this gate.

## Emission contract

The issued FR137 closure has all semantic outputs null:

- `criterionState = null`

- `productSemanticReading = null`
- `characterGrounding = null`

The closure consumes zero neutral metric values and zero research assertion states. A consumer that calls the explicit semantic-emission authorization guard receives `FaceAuthorityValidationError`.

No LLM may fill the missing criterion state, claim, or narrative.
