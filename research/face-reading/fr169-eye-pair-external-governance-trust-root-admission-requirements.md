# FR169 — Eye-Pair External Governance Trust-Root Admission Requirements

## Status

**External governance trust-root admission requirements frozen only.**

FR169 is downstream of an actively issued FR168 eye-pair candidate trust-root material intake. It binds the next governance stage to the exact FR168 candidate coordinates and digests and freezes the checks that must succeed before any eye-pair trust root may be treated as externally governed and provisioned.

FR169 does not claim that an independently governed verifier or authoritative external root anchor currently exists in this repository. It therefore does not execute external governance verification, provision a trust root, pin a witness trust root, admit a witness credential, or admit independent-session evidence.

## Why FR169 is a requirements boundary rather than fabricated provisioning

FR156 froze the general external witness trust-root requirements and explicitly prohibited caller-supplied references, caller-generated keys, digest matches, mathematically valid signatures, self-signed credentials, synthetic credentials, and historical labels from creating external trust.

FR157 then implemented only bounded candidate trust-root byte intake for the square-broad-fang track. It did not establish governance authority, semantic root validity, externally governed key pinning, or witness trust. The repository contains no later square-broad-fang artifact that closes that provisioning gap; FR158 begins the eye-pair metric track.

FR168 deliberately imports only the FR157 candidate-intake design precedent, not square-broad-fang authority. It verifies exact candidate artifact byte identity and retains bounded coordinates/digests while keeping governance, semantics, scope, key pinning, and provisioning false.

Therefore FR169 cannot legitimately set `actualTrustRootProvisioned=true` using project-generated or synthetic material. Doing so would violate the trust boundary already frozen by FR156, FR157, FR167, and FR168.

## Exact predecessor binding

FR169 requires an object actually issued by the active FR168 boundary. A structurally identical clone is rejected.

The FR169 artifact retains the exact:

- FR168 candidate material digest;

Those coordinates remain inventory/binding identifiers. They do not become authority merely because FR169 records them.

## Frozen admission requirements

Before a later eye-pair external trust root can be provisioned, all of the following must be independently satisfied:

1. an external governance verifier provisioned outside caller/project authority;
2. external governance authority identity verification;
3. exact binding to the issued FR168 candidate material digest;
4. semantic parsing and verification of the trust-root artifact;
5. a governed supported-key-format policy;
6. externally governed key pinning;
7. trust-root validity-policy verification;
8. revocation/status verification;
9. signer-chain policy verification;
10. a governed semantic trust-evidence verifier;
11. eye-pair criterion-scope verification;
12. witness-authority-scope verification;
13. prospective-validity binding verification;
14. capture-to-witness binding verification; and
15. atomic success of the required admission checks before provisioning.

The later implementation must fail closed if any required check is absent or fails.

## Explicit insufficiency rules

None of the following can satisfy the admission requirements by itself:

- caller-supplied authority references;
- caller-supplied authority-evidence references;
- caller-supplied policy references;
- caller-supplied verifier references;
- caller-supplied public keys;
- caller-supplied key-pinning evidence references;
- digest equality;
- mathematical signature validity;
- self-signed material;
- a root generated by this project;
- synthetic roots or credentials; or
- FR168 candidate intake alone.

Synthetic material remains appropriate only for deterministic parser/mechanics tests. It cannot prove external governance.
