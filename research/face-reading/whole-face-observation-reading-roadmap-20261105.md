> **개정:** 2026-11-05  
> **Watchtower-Track:** face-observation-engine / face-research (각 트랙의 권한·책임 구분 유지)

> **비범위:** [사주 전용 7단계 로드맵](../../docs/ROADMAP.md), 사주 명식 변환, 새로운 제품/결제/공개 배포.

## 1. 목표를 다시 고정한다

명하의 목표는 얼굴 검출, 헤어라인 검출, 마스크 수 증가가 아니다. **실제 얼굴 사진에서 관상에 필요한 세부 형태를 관측하고, 검증 가능한 범위에서 특정 전통의 형태 조건에 연결한 다음, 이미 존재하는 관상 판독 경로로 전달하는 것**이다.

```text
일반 스마트폰 RGB 얼굴 사진
  → 촬영/부위별 가시성 확인
  → 얼굴 좌표 + 실제 이미지 경계 + 상대적 입체 형상(가능한 경우)
  → 출처와 단위가 있는 중립 관측값(F0)
  → 전통 문헌의 형태 조건과 검증된 대응 여부(F1)
  → 개별 부위·부위 간 조합·삼정/오관/십이궁 해석
  → 지원/부분 지원/관측 불가를 구분한 종합 판독
```

- **관측 좌표가 있다 ≠ 세부 형태가 측정됐다.**
- **측정 계산기가 있다 ≠ 사진에서 자동으로 측정할 수 있다.**
- **모델이 모발/귀/코 픽셀을 나눴다 ≠ 모근선/귓바퀴/코 돌출을 확정했다.**
- **형태를 측정했다 ≠ 특정 전통의 명명된 관상형에 해당한다.**
- **전통 관상 해석 ≠ 개인의 성격·재산·질병·운명에 관한 과학적 예측.**
- 사주팔자의 생년월일시 기반 **명식은 얼굴에서 역산하지 않는다.** 이 로드맵이 연결하는 것은 관상 형태·조건·판독이다.

## 3. 얼굴 전체 관측 범위 — 반드시 빠짐없이 평가할 대상

## 4. 수정한 실행 순서 및 각 단계 종료 증거

### 1단계 — 전체 관상 항목과 출처 요구를 하나로 정리

**구현:** FR282/FR293의 29개 키, FR294의 11개 하드갭, FR311 전통 형태 조건, 현재 비공개 두 시점 항목별 화면을 **한 대응표**로 연결한다. 위 표의 누락 후보는 별도 표시하고 아직 승인되지 않은 신규 정규 측정으로 취급하지 않는다.

각 행에는 **필요한 특징 / 실제 사진 증거 / 촬영 방향 / 가시성 / 기존 계산기 / 부족한 검출기 / 전통 조건 출처 / 판독 가능 상태 / 다음 검증**을 남긴다.

**완료 증거:** 눈썹·미간·눈·코·광대·볼·입·턱·귀·이마 및 전체 조합이 빠짐없이 항목별로 대응되고, 측정 가능·부분·미구현·원천적으로 관측 불가를 구별한다.

### 2단계 — 현재 있는 얼굴 관측 경로부터 실제 사진으로 연결

**구현:** 새 뷰어나 두 번째 관상 엔진을 만들지 말고 **#2453의 항목 우선 로컬 두 시점 관찰 흐름**을 재사용한다. 2026-10-29 수정 이후의 실제 캡처 재실행/오류·품질·원본 보존 확인을 마친 뒤, 18개 계산기가 **사진→분리된 기하→관측값**까지 연결되는지 항목별로 확인한다.

측정 계산만 가능한 항목은 `calculation_only`, 모델 후보만 존재하면 `candidate_only`, 실제 관측 근거가 있으면 `observed`, 불충분하면 `partial/unavailable`로 나눈다.

**완료 증거:** 선택한 실제 캡처에서 각 항목이 어디서 멈추는지와 누락 이유가 추적된다. 새로 계산한 값이 기존 정규 수치 또는 마스크를 덮어쓰지 않는다.

### 3단계 — 정면 RGB의 세부 2D 형태 채우기

**구현:** 기존 MediaPipe 좌표와 현재 로컬 얼굴 분할 후보(#2454의 ResNet18 ONNX 포함)를 동일 사진에서 비교한다. 눈썹의 실제 털 범위·두께·밀도, 눈꺼풀, 콧볼/콧구멍, 입술 경계, 이마/모근선, 귀 외곽을 각각 **적합한 관측기**로 검증한다. 한 모델을 전 부위 승자로 지정하지 않는다.

검출 영역 픽셀 정확도와 관상에 필요한 **실제 특징의 측정 정확도**를 별도로 기록한다. 사람 검토·라이선스·품질/가림 조건을 통과하지 않은 결과는 후보로만 남긴다.

**완료 증거:** 각 2D 특징의 검증 자료·오류 유형·반복 측정 결과·불가 조건, 기존 대비 개선/퇴행이 항목별로 확인된다.

### 4단계 — 상대적 3D와 귀의 방향 의존 관측 채우기

**구현:** [FR295](fr295-rgb-relative-3d-benchmark-protocol.md)/[FR299](fr299-independent-3d-nose-reference-bundle.md)/[FR300-R1Z](fr300-r1z-bm-rgb-selfie-independent-benchmark-strategy.md)의 **동일 RGB 입력·독립 참조·촬영조건·권리 검증** 경계를 그대로 사용해 코, 광대·볼, 턱, 이마의 **상대적 입체 형태**를 비교한다. 귀는 가시성 선행 검증 후 귓바퀴·귓불·부착·펼쳐짐을 항목별로 평가한다.

정면 RGB가 부족한 항목은 **선택적인 좌우 사선/측면 추가 촬영**을 연구 후보로 검토하되, 현행 단일 RGB 제품에서 이를 필수화하거나 특수 깊이 하드웨어를 요구하지 않는다. 다각도만 있으면 실측 3D가 된다고 주장하지 않는다.

**완료 증거:** 항목별 독립 참조·반복성·좌우 일관성·시점별 오류가 확보되거나, 미확보 항목은 `unavailable`로 유지된다. 모델 내부 Z/렌더링/마스크 넓이를 물리적 돌출 정답이라고 부르지 않는다.

### 5단계 — 중립 관측값을 특정 전통의 형태 조건과 연결

**구현:** FR311 등 기존 출처·조건을 우선 재사용하고 **부위별 완전한 전통 형태 조건 → 요구 관측값 → 사람의 형태 판정 근거 → 자동 판정 가능 여부** 순서로 검증한다. 예를 들어 눈썹의 기울기를 측정했다는 이유만으로 임의 각도를 상향형/특정 고전 명칭의 합격 임계값으로 정하지 않는다.

서로 다른 전통의 부위 명칭과 조건을 무단 통합하지 않는다. 문헌 해석이 없어도 2D/3D 물리 형태 관측은 계속 제공할 수 있다.

**완료 증거:** 조건별 출처·관측 입력·반복 인간 판정·충돌·불가 결과가 연결되며, 검증된 형태 분류만 허용된 전통 해석 계층에 전달된다.

### 6단계 — 오관·삼정·십이궁과 부위 간 조합을 기존 판독 엔진으로 연결

**구현:** 기존 FRB/T5/T6/Claim·출처 권한을 보존한다. 정면 비율·공통 좌표계·가시성·전통 기준점이 확보된 부위만 결합한다. **한 항목만 누락되면 전체 얼굴을 버리는 방식 대신**, 부족한 부위만 판독 보류하고 나머지 지원된 항목을 유지한다.

문장 생성 모델은 **선행된 중립 관측 및 승인된 전통 의미**를 표현할 수 있을 뿐, 새 분류·운세·성격 판단을 임의 생성하지 않는다.

**완료 증거:** 실제 사진에서 `사진→중립 관측→조건 판정→근거 있는 조합→한국어 결과`가 각 단계에서 추적되고, 근거 없는 전통/사주 명식 혼합이나 권한 승격이 없다.

### 7단계 — 전체 얼굴 대상 독립 검증 및 통합 완료 판정

**구현:** 기존 23장 로컬 개발 자료, 168장 헤어라인 자료, 별도로 확보할 독립 검증 자료를 **용도별로 분리**한다. 사진별 누락 이유·촬영조건·조명·가림·표정·좌우 시점·모델 버전 및 라이선스를 기록한다. 데이터가 적거나 편향됐으면 신뢰도/외삽 제한을 드러낸다.

**완료 증거:** 각 필수 관측 항목의 사람 정답 대비 오류·반복성·미지원 상태, 전통 형태 판정의 재현성, 조합 결과의 출처·한계가 실제 재실행으로 확인된다. **실제 완성 항목과 미완성 항목을 구별**하고, 문서나 CI 통과만으로 완료를 선언하지 않는다.

## 5. 우선 적용과 의존성

1. **즉시:** 1단계 전 항목 대응표와 2단계 기존 로컬 측정/관측 경로 확인. #2453을 복제하지 않는다.
2. **독립 병행:** 3단계 2D 세부 형태 비교는 항목별로 진행 가능. 헤어라인 #2213/#2337 독립 증거 경로도 보존하되 **다른 부위 작업을 막는 전역 선행 조건으로 두지 않는다.**
3. **증거 의존:** 4단계 상대 3D는 FR295/FR299의 실제 참조·권리·등록 조건을 통과하기 전까지 제품 수치로 승격하지 않는다. 귀 내부/두께는 계속 불가.
4. **판독 의존:** 5단계 검증 전 전통 형태 자동 대응 금지. 6단계는 실제로 자격을 얻은 항목만 선별 소비한다.
5. **촬영 UX:** 정면 단일 사진의 제공 가능 항목을 먼저 확보하고, 추가 시점은 부족한 특징을 좁혀 후속 검토한다.

**기술 선정 기준:** 관상 항목의 관측 충족도 > 독립 정답 대비 오류·재현성 > 일반 RGB/실사용 성능 > 가림·실패 처리 > 프라이버시·상업 이용 권리 > 운영 비용. Keras/TensorFlow, PyTorch, ONNX, MediaPipe는 수단일 뿐 선택 자체가 목표가 아니다.
