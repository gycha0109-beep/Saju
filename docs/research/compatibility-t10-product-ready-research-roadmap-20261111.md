## 2. 연구 실행 순서

### 1단계 — 직접 궁합 방법론의 원문 확보와 출처 적격성 감사
- [ ] 기존 R068/R069/R070, 2014 주미강·2018 남기동/김만태 초록, 『滴天髓闡微』 원국 문맥 및 기존 참고문헌 후보를 **중복 조사하지 않고** 원문 본문·쪽수·실제 문장·적용 대상·반례가 필요한 항목으로 구분한다.
- [ ] **두 명식을 직접 비교하는** 궁위·육신·용신의 규칙, 전제(혼인/연인 등), 학파 차이, 예외·부정 사례를 출처별로 수집·대조한다. 원국 내부 규칙을 대인 규칙으로 승격하지 않는다.
- [ ] 문헌의 전통적 해석 규칙과 현대 관계 성과에 대한 실증적 예측 근거를 분리한다. 초록/서지만 확인된 자료는 '미확인'으로 남긴다.
- **완료 조건**: 후보별 원문 위치·직접 인용 범위·두 명식 입력·계산 전제·허용 의미·예외·확인 수준의 감사표. 적격 근거가 없으면 **그 규칙만 불인정**하고 전체 완료 선언 금지.

### 2단계 — 궁위·육신·용신 각각의 적용 가능 Rule/Methodology 검증
- [ ] 1단계의 직접 출처가 허용하는 범위에서만 실제 두 명식에 적용되는 **입력/조건/출력/반례**를 명시한다.
- [ ] 궁위: 일지 외 합·충/형·해·파 등 후보는 실제 출처와 기존 구조 계산 지원 여부를 분리한다. '합=좋음/충=나쁨' 자동 규칙 금지.
- [ ] 육신: 원국 재성·관성의 역사적 성별 전제와 강약/용례를 감사하고 현대 파트너·동성 관계 등으로 무단 일반화하지 않는다.
- [ ] 용신: 개인별 판정 자체의 근거·방법이 먼저 성립해야 하며 오행 분포만으로 용신 또는 상호 보완을 선언하지 않는다.
- **완료 조건**: 각 축에 적용 가능한 근거 있는 좁은 규칙/미지원 상태/반례를 명시하고, 기존 Claim·Rule·Methodology·Source·계산 위치와 연결. **세 축을 무조건 모두 채우는 것이 아니라 실제 해석에 필요한 축의 적격성을 판정**한다.

### 3단계 — 복수 근거의 종합 방법과 관계별 해석 범위 연구
- [ ] 일지 육합+다른 위치 충, 일지 충+다른 위치 육합, 개인 원국 배우자성 불일치 등의 사례에서 **소스가 허용한 조건부 우선순위·예외·상쇄 여부**를 조사한다.
- [ ] **수치 가중치·궁합 점수는 직접 근거가 있을 때만** 검토. 출처가 종합 순위를 제공하지 않으면 우열 점수 대신 독립적인 관찰·상호 조건·미해결 한계를 전달할 수 있는지 방법론을 검증한다.
- [ ] 부부/연인/친구/가족/동료를 동일 규칙으로 합치지 않고 실제 승인 상품의 관계 입력 범위에 맞춰 검증한다.
- **완료 조건**: 최소 두 방향의 상충 사례와 무관찰 사례에 대해 결론 생성/보류 기준, 허용 한국어 문장, 반례·출처 이견을 추적. 종합법이 성립하지 않으면 해당 결론은 계속 HOLD.

### 4단계 — 실제 명식쌍 기반 개인별 Reading 품질 구현·검증
- [ ] 기존 8쌍 테스트를 재사용하고 **추가 검증이 필요한 경계 유형에 한해** 입력을 확장한다. 계산 결과, 문장별 Claim/Rule/Source/명식 위치, 조건·불확실성을 일치시킨다.
- [ ] 서로 다른 명식에서 실제 근거 차이가 한국어 Reading 차이로 전달되는지, 동일 구조일 때 허위 차별화를 하지 않는지, 역순·시각 미상·동일 출생정보의 서로 다른 사람을 검증한다.
- [ ] 전통적 해석과 현대 실제 관계 결과를 구별하고 결혼 성사·이혼·외도·수명 등 사건을 근거 없이 예측하지 않는다. 직접 출처가 성립하지 않은 요소는 출력에서 보류한다.
- **완료 조건**: 실제 두 명식쌍별 읽을 수 있는 한국어 Reading, 문장 단위 출처·계산 증거, 미지원 이유, 회귀 테스트·CI. 품질 미달 시 해당 결함만 보완한다.

### 5단계 — 상품별 T10 해석 적격성 및 인계 판정
- [ ] 첫 상대 비교·추가 상대 비교·본인 관계운+첫 비교 각각에서 **해석 자체의 독립 완결성**과 인물·상대·권한 혼선을 점검한다. 본인 T8과 타인 T10을 단순 병치해 종합 궁합이라고 하지 않는다.
- [ ] 실제 허용 가능한 해석 범위와 결손을 근거별로 정리하고 상품 전체가 목적에 부합하는지 판단한다. **단순 구조 사실만 보여주는 결과는 종합 궁합 상품 완료로 인정하지 않는다.**
- [ ] 연구·구현·품질 조건 충족 후에만 상품·Reader·Commerce 트랙으로 전달한다. Official·Production·판매·결제 변경은 이 로드맵의 자동 권한이 아니다.
- **완료 조건**: 3개 구매 구성별 실제 해석 품질 검증, 출처/권한/경계 CI 증거, 판매 보류 유지 또는 **별도 출시 적격성 심사에 넘길 수 있는 근거 있는 판정**. 상용 궁합에 필수인 종합 방법론이 끝내 성립하지 않으면 **로드맵을 완료 처리하지 말고 구체적 블로커를 보고**한다.

## 3. 실행·보존 규칙

1. 이미 완료한 3단계 제한 연구·8쌍 검증·원국 R068/R069/R070을 반복하지 않고 그대로 활용한다.
2. **연구 목표는 '검토 후 종료'가 아니라 '근거 있는 궁합 상품 해석을 완성할 수 있는지 판정하고 실제 가능한 부분을 구현'**하는 것이다. 단, 근거가 없는 결과를 만들면서까지 완료하지 않는다.
3. 문헌 전문·실제 본문을 확보할 수 없으면 접근 불가/초록만 확인을 표시한다. 외부 기관에 문의하지 않는다.
4. 기존 계산·역사적 범위·고객 정보·권한·가격·결제 구조 변경 금지. 유료 API/운영 호출/배포는 별도 승인.
5. Saju 원국·연월 7단계 품질 로드맵과 T10 연구를 혼합하지 않는다. 기존 PR #2763 작업 브랜치에서 작업하며 다른 PR 임의 병합 금지.
6. 매 단계 실제 소스·규칙·검증·반례와 워크로그를 남긴다. 확인되지 않은 완료율을 추정하지 않는다.
7. **ROADMAP_COMPLETE는 이 새 로드맵의 1~5단계 필수 근거·구현·검증·문서화·상품별 판정이 모두 충족됐을 때만** 선언한다. 3단계 과거 완료를 새 목표의 완료로 승계하지 않는다.

## 4. 즉시 다음 작업

2. 원국·궁위·육신·용신의 '두 명식 직접 규칙/단순 원국 관찰/근거 미확인' 표 작성.
3. 가장 좁고 명확하게 증명된 규칙부터 기존 Saju 근거 체계에 연결하고, 합·충 상충 사례로 재현.
