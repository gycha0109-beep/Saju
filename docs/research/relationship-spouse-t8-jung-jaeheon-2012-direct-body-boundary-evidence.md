## Positive evidence preserved

This thesis should not be reduced to a failed candidate.

1. It states explicitly that the **Day Branch represents the spouse**, providing a sex-neutral spouse-palace location layer.
2. It operationalizes marriage analysis with both palace and spouse-star variables instead of relying on one classical slogan.
3. It tests family-relationship changes across marriage, childbirth, divorce, and family deaths using Daewoon/Sewoon interactions.
4. It recognizes that variables treated as irrelevant under conventional generalized theory may still have empirical relevance.

These are useful research findings and remain preserved as source evidence.

## Why `EXPLICIT_ROLE_NEUTRAL_NATAL_MAPPING` remains OPEN

The same body also supplies the hard negative.

Printed p.9 does not merely discuss historical terminology: it explicitly assigns `正官` to a woman's husband and `偏官` to an outside/other husband, while the adjacent palace rule says the Day Branch represents one's spouse.

Printed pp.54 and 58 repeat the operational sex split in the marriage chapter:

```text
male marriage/spouse condition   → 財星 / Wealth
female marriage/spouse condition → 官殺 / Officer-Killing
```

The empirical model then keeps `일지` and `배우자별` as separate variable families. Therefore the neutral location rule does not replace the sex-conditioned spouse-star layer.

The source does **not** publish:

- a rule that replaces `male → Wealth / female → Officer-Killing` with one role-neutral natal mapping;

Therefore:

