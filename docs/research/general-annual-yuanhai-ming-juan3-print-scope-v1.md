## 2. 1차 `木` 판독의 철회 및 2차 `未` 판독
**첫 확대 판독에서 `亥卯木`이라고 기록했던 부분은 오판독이었다.** 동일 이미지의 해당 글자를 인접 본문 및 같은 문단의 `癸未`에 쓰인 자형과 다시 대조하면, 위·아래 두 가로획 및 중앙 종획이 확인되어 **`亥卯未合起羊刃`의 `未`**로 읽힌다. v2의 "NLC 원본은 木, NLC 기반 OCR은 未이므로 충돌"이라는 진술은 취소한다.

| 직접 관찰 범위 | 판독 | 증거 성격 |
|---|---|---|
| NLC 제2책 卷三 PDF 11쪽 오른쪽 판면 / `亥卯?合起羊刃` | **`亥卯未合起羊刃`** | 특정 인쇄 실물 1종의 확대 직접 판독 |
| 같은 소장본 기반 [識典 OCR](https://www.shidianguji.com/zh/book/NGJ8922642210287/chapter/1lnh0qpidcm57) | `亥卯未合起羊刃` | 디지털 OCR; 이번 위치에서 실물과 **일치** |
| [卷三 편집형 전사](https://www.shidianguji.com/zh/book/SDZJ0626/chapter/1lctut1kn9cti) | `亥卯未合起羊刃` | 독립 인쇄 실물 대조 여부 미확인 |
| [다른 명대 간본 기반 OCR](https://www.shidianguji.com/zh/book/NGJ892411999032112149610/chapter/1lqsbrh19ji9f) | `亥卯木` | **다른 인쇄 원본의 해당 글자를 직접 판독한 것은 아님** |

단일 NLC 인쇄본의 `未`를 근거로 **모든 판본의 정본**, OCR `亥卯木`의 원인, 판본 계통을 단정하지 않는다. 반대 전사 기록 `亥卯木`은 이문 연구 자료로 계속 보존한다.

## 3. 시주 `己巳` / `巳巳`
- 동일 **PDF 11쪽 오른쪽 판면**에는 `又如癸未乙卯甲子己巳`로 읽히는 세로 열이 있다. **확대 시각 판독 후보는 `己巳`**이며, `巳巳`보다 명확해 보인다.
- 이 후보는 **동일 스캔 1차 독해**로만 기록한다. `己`, `巳`, `已` 유사 자형을 동일 간본 내 다른 명확한 인쇄 예와 대조한 독립 이중 판독이 완료되지 않았으므로 `actualPrintedHourStemConfirmed=false`를 유지한다.
- NLC OCR 전사 `巳巳`, 편집형 전사 `己巳`을 그대로 보존한다. 인쇄본이 명확하다는 이유가 없이 OCR 텍스트를 자동 수정하지 않는다.

## 4. 승인 및 계층 한계
- 이 단계는 **전사 6건과 별개로 인쇄본 NLC 1종을 직접 대조**한 결과다. 서로 다른 6개 독립 실물 간본을 확보했다는 뜻은 아니다.
- `癸未·乙卯·甲子·己巳 / 辛亥 / 辛酉` 전사 기반의 6슬롯 후보 구조는 그대로 연구자료로만 보존한다.
- 국지적 `亥卯未` 판독은 **고전 문구의 표기 사실**일 뿐, 삼합이 언제나 충보다 우위이거나 충이 해소되는 보편 규칙을 증명하지 않는다.
- 인물 `岳飛`의 실재 명식 귀속, 운세·수명 사건의 사실성, 정식 현대 연운 의미 모두 검증/승인하지 않았다.
- **현대 연운 의미 승인 0/14**, `globalTripleClashPriorityAuthorized=false`, `productionAuthorized=false`, 공식 사주 리딩 / 캐릭터 LLM / Commerce / 결제에 영향 없음.
