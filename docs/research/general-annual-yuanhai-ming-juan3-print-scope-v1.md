## 2. 1차 `木` 판독의 철회 및 2차 `未` 판독
**첫 확대 판독에서 `亥卯木`이라고 기록했던 부분은 오판독이었다.** 동일 이미지의 해당 글자를 인접 본문 및 같은 문단의 `癸未`에 쓰인 자형과 다시 대조하면, 위·아래 두 가로획 및 중앙 종획이 확인되어 **`亥卯未合起羊刃`의 `未`**로 읽힌다. v2의 "NLC 원본은 木, NLC 기반 OCR은 未이므로 충돌"이라는 진술은 취소한다.

## 3. 시주 `己巳` / `巳巳`
- 동일 **PDF 11쪽 오른쪽 판면**에는 `又如癸未乙卯甲子己巳`로 읽히는 세로 열이 있다. **확대 시각 판독 후보는 `己巳`**이며, `巳巳`보다 명확해 보인다.
- 이 후보는 **동일 스캔 1차 독해**로만 기록한다. `己`, `巳`, `已` 유사 자형을 동일 간본 내 다른 명확한 인쇄 예와 대조한 독립 이중 판독이 완료되지 않았으므로 `actualPrintedHourStemConfirmed=false`를 유지한다.
- NLC OCR 전사 `巳巳`, 편집형 전사 `己巳`을 그대로 보존한다. 인쇄본이 명확하다는 이유가 없이 OCR 텍스트를 자동 수정하지 않는다.

## 6. 2026-10-12 후속 소장본 탐색 및 판독 경계

### 6.1 NLC PDF 11쪽 재현 좌표 보강
원본 사용자가 제출한 NLC 제2책의 **PDF 11쪽**에는 대상 사례가 실제로 존재한다. 해당 오른쪽 판면에서 **오른쪽 → 왼쪽**으로 원국 `又如癸未乙卯甲子己巳` 후보, `此命卯刃癸印`, `時上己巳破印` 후보, `運行辛亥亥卯未合起羊刃`와 `沖起卯刃` 문맥이 이어지고 그 다음에 `〇論刑合` 제목이 나온다. **`論刑合`가 같은 쪽에 있다는 이유로 대상 사례가 없다고 판단하면 안 된다.** 이 문서 1~3절의 PDF 11쪽 위치 표기는 유지한다.

재현 기준은 위 SHA-256 NLC PDF의 **11번째 페이지, 내장 이미지 1483×1404px**이며, 오른쪽 판면의 원국과 이어지는 여러 세로 열을 통째로 대조한다. 한 글자만 떼어 놓은 이미지나 OCR로만 판독 권한을 정하지 않는다. 기존 v2 `木` 확정 오판독은 철회 상태를 유지한다. 시주의 `己/巳/已`는 **같은 인쇄본의 재확대가 다른 판본의 독립 검증을 대체하지 않으므로 확정 보류**한다.

## 10. 이문 발생 경위와 시주 교감의 범위 — 2026-10-12

### 10.1 『淵海子平』 전승의 시대·편집 계통

기존 실물 **명 만력 28년(1600) 계열** `亥卯未`와 **명 숭정 7년(1634) 계열** `亥卯木`가 서로 다른 판면의 직접 확인 글자라는 사실은 유지된다. 그러나 **먼저 인쇄된 판본 = 저자의 원형**이라는 식의 단정은 금지한다.

**새로 확보한 편집 계통 자료:** 숭정판 「刻合併評注淵海子平引」은 앞선 책을 합치고 잘못된 문구를 바로잡았다는 **간행자의 자기 설명**을 담는다 ([識典 서문](https://www.shidianguji.com/zh/book/NGJ892411999032112149610/chapter/1lqbrsabl0vfe)). 이 문구는 숭정판이 적극적인 편집을 주장한다는 증거이며, 실제 어느 저본을 어떻게 따랐는지를 독립적으로 확증하지는 않는다.

[東里書齋의 판본 소개](https://www.donglishuzhai.net/books/111.html)는 (a) 1548년 가정판, (b) 1600년 만력판, (c) 1634년 숭정판의 문자 차이를 구별하고, 편집자가 숭정판을 저본으로 삼되 명백한 오류는 **별도 교감주 없이 직접 수정할 수 있음**을 공지한다. 따라서 해당 현대 온라인 텍스트의 `亥卯未`는 숭정판 원본 `木`의 독립 반증으로 계산할 수 없다. 출처의 명시적 교정 정책과 실물 인쇄 판독을 분리해야 한다.

### 10.3 `己巳 / 巳巳`의 별도 기계적 정합성 검증

목판 실물 자형과 명리 산출 규칙을 다른 증거 층위로 다룬다. 전사들에 보이는 사례는 `癸未·乙卯·甲子·己巳`; NLC 만력판 파생 OCR 1건에는 `巳巳`라고 전사된다.

전통 **五鼠遁(日上起時)** 규칙에 의하면 **甲日의 子時는 `甲子`부터 시작**하여 `乙丑 → 丙寅 → 丁卯 → 戊辰 → 己巳`로 진행한다 ([『欽定協紀辨方書』 五鼠遁 전재](https://libokang.com/guji/zonghe/钦定协纪辨方书/2/); [규칙 설명](https://wiki.openfate.ai/zh-hant/bazi/calendar/five-rats-method)). 가정된 **`甲子` 일주·`巳` 시지**에 대한 기계적 시주는 **`己巳`**로 결정된다.

`巳巳`의 첫 글자 `巳`는 천간 10자에 속하지 않으므로 **정상적인 간지 시주 표기로는 불가능한 OCR 기록**이다. 이는 `己巳`가 내부 규칙상 맞는 정규화 후보임을 보여준다. 그러나 역사적 명식의 실제 탄생 시간이 `巳時`였는지, 해당 인쇄본의 첫 글자 획이 정말 `己`였는지에 관한 **문헌학적 실물 자형 감정과 역사 사실 인증은 따로 보류**한다. OCR 원 문자열도 소거하지 않는다.

## 12. 한국 소장 『子平三命通變淵源』의 양인 항목: 학술 인용 확인 / 원본 사례 미검증 (2026-10-12)

### 12.1 학술 전사로 「日刃·陽刃」 항목의 존재 확인

[김면수(2019), 「명리원전 『子平三命通變淵源』 연구」 국회도서관 서지](https://dl.nanet.go.kr/detail/KDMT1201930296)는 **국립중앙도서관 소장 목판본을 저본으로 삼은 연구**다. [학위 연구의 텍스트 공개본](https://www.scribd.com/document/1061771789/子平三命通變淵源연구)의 「卷上 看命入式」 해설은 정관·편관·재성·신살 등과 더불어 **「日刃·陽刃」**을 항목으로 분류한다.

문헌에서 따온 학술 인용(원본 이미지 직접 판독이 아님):
- `獨陽刃以時言之，四柱中不要入財鄕，怕衝陽刃。`
- 연구는 앞뒤로 `其人主眼大鬚長` 등 양인 성격·형충에 관한 문장도 주석에 인용한다.
- **그 인용 구간은 본 연구의 문제 원국 `癸未·乙卯·甲子·己巳`나 `亥卯未/木合起羊刃`을 직접 포함하지 않는다.** 이는 연구서에서 해당 원국이 없다는 *부재 증명*도 아니다. 목판 원본 권상 「看命入式」의 전체 항목을 직접 열어야 한다.
- **주요 오검출 방지:** 2019년 연구서의 `己巳` 언급 중에는 다른 「金神」 격국의 시간용어를 교정한 각주도 있다. 단독 `己巳`만 발견했다고 목표 4주 명식 사례가 확인된 것으로 계산하지 않는다.

## 15. 『子平三命通變淵源』 「日刃·陽刃」의 연운·합충 관련 *인용 문맥* 추가 비교 — 2026-10-13

### 15.1 학술인용/후대 해설/명대 원본 판독의 삼층 구분

- **학술 인용(저본은 국립중앙도서관 목판본으로 기재됨):** [김면수(2019), 『子平三命通變淵源』 연구](https://www.scribd.com/document/1061771789/子平三命通變淵源연구), 연구 본문 p.104 각주 305는 「日刃·陽刃」의 `獨陽刃以時言之，四柱中不要入財鄕，怕衝陽刃`을 인용한다. **이 연구의 인용은 본문에 근거하지만 고문헌 원래 판면을 이번 조사에서 직접 열어 획을 재검토한 것은 아님**.
- **후대 해설서의 귀속 인용:** [凌雪衣, 『子平遺風系列之格局大義』 「第十二節論日刃、陽刃」](https://www.scribd.com/document/978363995/凌雪衣-青衿名士-子平遗风系列之格局大义140页-0)는 `《淵源》`으로 귀속된 단락 속에 `不喜會合` 및 **甲日이 酉運을 경계한다는 일반 서술**을 전한다. **인용자의 전사 선택과 원본 판각을 직접 교감하지 못했으므로 이곳의 글자는 추가 원본 인쇄본으로 계산하지 않음**.
- **명대 서로 다른 실제 원본:** 이전 직접 판독한 1600 만력 판면 `亥卯未合起羊刃`, 1634 숭정 판면 `亥卯木合起羊刃`는 별도의 2종 조판 원본 증거로 유지한다. 위 인용 둘로 원형을 정하지 않는다.

### 15.2 명대 특정 명식과의 접점—동일 사례가 아닌 유사 주제

명대 사례의 일주는 `甲子`, 세운은 `辛酉`이며, 현대 해설서가 `《淵源》`의 일반 양인론으로 소개한 `甲日…忌酉運`은 **甲일·酉의 범주에서 주제상 교집합**을 가진다. 그러나
1. `甲日忌酉運`의 **運**과 명대 특정 사례의 **辛酉年**을 같은 시간 단위·동일 명령문으로 바꿀 수 없음.
2. `不喜會合`이라는 양인 일반 설명과 `合起羊刃`라는 해당 명대 간본의 구문은 서로 같은 함수나 자동 우선순위 연산이 아니다. 후대 해설의 인용 범위에 `癸未·乙卯·甲子·己巳` 명식이 **발견되지 않았지만**, 이것은 **원래 목판 전체에 없다는 부재 증명으로 사용 금지**.
3. 문헌의 연도·목판 전승 관계는 1548년 실물 및 한국 원전 판면을 확보해야 결정 가능. 1253년 서문 연대를 목판의 인쇄 연대로 치환하지 않는다.

## 18. 동일 명식의 『淵海子平』 내부 두 장절 확인: 岳飛 귀속 전승과 인쇄 이문 분리 — 2026-10-13

### 18.1 이 연구에서 처음 구분한 **두 개의 서술 위치(locus)**

동일한 사주 `癸未·乙卯·甲子·己巳`, `辛亥` 대운 및 `辛酉` 유년의 서술이 서로 다른 두 위치에 반복됨을 별도 공개 전사에서 확인했다.

| 항목 | **『喜忌篇』 「劫財羊刃」 해설(웹 ‘卷一’; 만력 인쇄 권2)** | **별도 「論羊刃」 사례** |
|---|---|---|
| 공개 전사 | [BTKO 卷一](https://www.btko.net/Show-33), [재확인 GetIt01](https://www.getit01.com/p201805252314174/) | [후대 전사](https://www.btko.net/Show-59), 앞서 직접 판독한 인쇄 스캔 |
| 사례 명식 | `癸未乙卯甲子己巳` | `癸未乙卯甲子己巳` |
| `辛亥/辛酉` | 모두 등장 | 모두 등장 |
| **岳飛 장군 인명** | **`此岳飛將軍命`이라고 전사에서 직접 명시** | **만력 p.11·숭정 p.19의 해당 인쇄 문단에는 인물 이름이 없음** |
| 사망 서술 | `三十九歲死於獄中` | 사례별 `身雖貴亦遭刑`, `不可一合一沖也` |
| 이미 직접 판독한 목표 인쇄면 | **0건** | 만력 `亥卯未` / 숭정 `亥卯木`, 총 2종 조판 |

**실물 이미지에서 추가로 확인한 문단 내부 대비:** 1634년 숭정판 제2책 **1-based PDF p.19 왼쪽 판면**에는 해당 원국의 `癸未`에 **`未`가 인쇄**되어 있으면서, 운 설명의 `亥卯木合起羊刃`에는 **`木`이 인쇄**되어 있다. 즉 동일 인쇄 문단 내 **`癸未` 대 `亥卯木`의 글자 구별**이 존재한다. 이 사실은 `木`이 원본에서는 언제나 `未`였다는 설명이나 OCR 오인설을 배제하지만, 편집자의 의도적인 木 약기·부분적인 오각·기존 저본 복제 오류 중 **발생 원인을 확정하는 자료는 아니다**. 원본 대상 문단의 두 판면 모두 **`不可一合一沖也`**라는 한 사례 종결 서술을 포함하며, 이를 전역적인 三合·沖 승패 결정 알고리즘으로 확장할 수 없다.

### 18.2 병행 「喜忌篇」의 **바로 그 명대 원본**까지 추적

연구에 활용할 수 있는 두 간본의 **제1책 PDF 서지**를 특정했다. 단 해당 병행 구절이 특히 숭정판의 제1책에 실렸다는 사실까지 검증한 것은 아니다.

- [만력 계통 『刻京臺增補淵海子平大全』 제1책 NLC892-2642-210287](https://commons.wikimedia.org/wiki/File:NLC892-2642-210287_刻京臺增補淵海子平大全_第1冊.pdf) — **48 PDF 쪽**, 서지에서 **卷之一·卷之二 수록**.
- [숭정 7년 『新刊合併官板音義評注淵海子平』 제1책 NLC892-411999032112-149610](https://commons.wikimedia.org/wiki/File:NLC892-411999032112-149610_新刊合併官板音義評注淵海子平_第1冊.pdf) — **37 PDF 쪽**.

**권차 재검토:** 만력 원본 NCL-06593 **PDF p.1의 실제 목차**에서 **`二卷 … 喜忌篇`**을 확인했고, [1600 간본의 전사된 목차](https://www.shidianguji.com/zh/book/SDZJ0626/chapter/1lhnc3bvvh5bo)와 부합한다. 따라서 『喜忌篇』에 붙은 웹 ‘卷一’은 만력 인쇄 권2의 권차와 다르다. **숭정판 해당 구절의 정확한 인쇄 권차와 물리 분책은 아직 확인하지 못했으며**, 숭정 제1책의 존재 자체가 구절의 수록 증거는 아니다.

**이번 실행에서는 NLC 제1책 두 PDF 파일의 바이트 다운로드가 외부 네트워크 DNS 차단으로 실패**, 해당 병행 구절의 개별 PDF 쪽 번호/오른쪽·왼쪽 판면/인쇄 자형은 `null`이다. **제1책의 인터넷 전사를 ‘원본 인쇄 판독’이라고 소급 선언하지 말 것.** 최초의 제2책 목표 판면 두 종만 실물 검증됨.

### 18.3 『神峰通考』와의 또 다른 서술 차이

[『神峰通考』 공개 전사본](https://zh.wikisource.org/zh-hant/神峰通考)의 `劫財羊刃` 해설에도 `癸未乙卯甲子已巳`, `岳飛`, `辛亥`, `辛酉`, 옥중 사망 서술이 나온다. **전사상 시주는 `已巳`이며, 기존의 계산상 `己巳`와 문자 모양이 다르다**. 실제 명대 인쇄 목판과 표제, 저본 연결, 후대 전사자의 OCR/현대 교정 여부를 대조하기 전에는 `已`를 물질적 독립 이문으로 인정하지 않는다. 서로 다른 제목의 작품에 같은 일화가 수록됐다는 사실은 텍스트 전승/차용 가능성도 포함하므로 **독립 문헌 계보가 성립했다는 뜻이 아님**.

### 18.4 결론 및 다음 실행 경로

- 새로 확인된 **독립 텍스트 위치 1곳**(「喜忌篇」)과 또 다른 작품의 전사 1건. 이것은 **새로 직접 판독한 인쇄본 0건**이므로 기존 판면 **2종·스캔 3건 그대로**.
- 병행 「喜忌篇」에서 `岳飛`라는 이름을 전해 준다는 사실만 기록함. 악비의 **실제 출생연월일시와 옥중 사망 서사의 역사적 일치**를 인증하지 않음.
