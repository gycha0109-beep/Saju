## 현재 구현 위치: 1단계(궁위·육신·용신 기존 연구 검증)

**실제 근거**:
- 주미강(2014) 공개 [RISS 국문초록](https://www.riss.kr/link?id=T13562621)은 자평 궁합의 **궁위·육신·용신** 세 방법을 설명한다. 장남의 육신론과 원수산의 용신 중심 견해는 서로 다르며, 개별 방법과 종합의 필요성을 명시한다. **구체적인 실행 가중치·충돌 우선순위**는 초록에서 확인되지 않는다.
- 남기동·김만태(2018) [KCI 초록](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002338687)은 **이별 부부 사례 분석 범위에서** 배우자궁이 배우자성보다 중요한 관찰 결과를 보고한다. 해당 표본 결과를 모든 시대·관계 유형·두 명식의 보편적 우선순위로 승격하지 않는다.
- 기존 R069 (`general-natal-spouse-claim-corpus.ts`): 역사적 성별 전제를 둔 배우자 원국 해석 출처만 보존; `executable: false`, 두 사람 상호작용 금지. R068/R070도 원국 관찰이며 T10으로 직접 연결 불가.
- #2763 기존: 실제 두 사람 간 천간합/지지육합/충의 계산 증거, 일지 관계 후보, 두 사람 각각의 간여지동 관찰. 아직 검토되지 않은 연구와 **일반적인 궁합 판정**은 서로 다르다.

**새 구현**:

## 2단계(상충 조정) 시작을 위한 확정 경계

| 충돌/우선순위 질문 | 실제 문헌 수준 | 처리 |
| --- | --- | --- |
| 2014 논문의 여러 학파(육신 우선 vs 용신 우선) | 공개 국문초록에서 상충하는 사상 확인 | **단일 가중치 미정**. 직접 출처 없이 수치·우선순위 생성하지 않음 |
| 2018의 '궁 > 성' | 이별 부부 사례 기반 관찰 | 전체 고객/모든 유형의 보편적 우선순위로 일반화 불가 |
| 두 명식의 일지 육합과 다른 위치의 지지충 동시 존재 | 기존 구조 테이블로 **사실** 계산 가능 | 상대적인 길흉 또는 단일 점수로 환원할 문헌 근거 부족 |
| 각 사람의 원국 관계 T8와 두 사람 T10이 다른 관찰 | 기존 계산·연구 결과는 분리됨 | 개인 원국 주장을 두 사람의 사건 인과로 합치지 않음 |
| 용신이 상대방의 오행으로 보완되는지 | 2014 초록의 방법론 개념 | 개별 용신 확정·실제 두 명식 보완 규칙 부재: **판단 보류** |

**다음에 할 것**: 이번 1단계 코드가 CI를 통과하면 소스 범위 검증을 종료하고, 2단계의 실제 두 명식에 나타난 구조적 병존 사례를 출처별로 감사한다. 충돌 우선순위가 끝내 입증되지 않으면 **미결정**을 결과로 채택한다. 3단계 신규 500명 감사/출시 승격은 이 트랙에서 임의 수행하지 않는다.

**중단/종료 조건**: 세 단계가 끝나거나 직접 출처가 없는 해석을 더 진행할 근거가 없으면 연구 범위 종료를 선언하고, 공식 T10/판매 적격 여부는 별도 게이트에 남긴다. `ROADMAP_COMPLETE`는 실제로 로드맵 조건을 모두 충족한 경우에만 선언한다.
