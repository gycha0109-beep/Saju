## Variant corpus

### V1 — 煞 supports 印 in a light-Seal configuration

```text
印輕逢煞
透煞以生印
```

This supports a Kill→Seal support/generation relation in that bounded configuration.

### V2 — the same family is not automatically favorable

```text
身強印重而透煞
```

is a failure proposition in the Seal-pattern source family.

Therefore:

```text
印 + 煞 presence
!= automatic favorable relation
```

### V3 — 財 can alter the Kill/Seal configuration

```text
透煞以生印，而又透財，以去印存煞
```

is a contamination proposition.

### V4 — 印 can protect 煞 from 食神 control

The Seven-Kill source family preserves:

```text
七煞逢食制而又逢印
煞逢食制，印來護煞，而逢財以去印存食
```

Here 印 is not represented as simply neutralizing 煞. It protects 煞 against 食神 control, and 財 removing 印 can restore the 食神-control path.

## Rejected shortcut

The verified variants directly reject:

```text
SEAL_PRESENT + KILL_PRESENT
→ SEAL_TRANSFORMS_KILL
→ FAVORABLE
```

as a universal executable rule.

The phrase family commonly summarized as 殺印相生 / 印化殺 must therefore remain configuration- and source-bounded.
