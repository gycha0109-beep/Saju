## 1. 무엇을 검증했는가

- **L0** = 텍스트 전사/검색·서지 위치. 원본 판면의 정확한 글자 확인 아님.
- **L1-EXACT** = 명시된 *일간 ↔ 비교 천간 ↔ 단독 十神 이름*이 역사적 인쇄 면에서 직접 확인. 출생/육친의 일간 명칭이지 특정 유년을 뜻하지 않음.
- **L1-GROUPED** = 인쇄된 두 이름의 *복합 문구*. 단독 이름과 동치 처리 불가.
- **L2-M** = 流年/太歲/流歲에 어떤 천간을 사용하는지와 같은 *일반 적용 방법*을 인쇄본에서 직접 확인. 특정 짝의 명칭 사용례 **아님**.
- **L2-C** = 동일 저본·동일 문맥 안에서 **甲일간 + 명시된 유년 간지(연간 포함) + 정확 十神명**이 결속된 *직접 역사적 유년 사례*. 단지 十神의 현대 제품 뜻을 검증하지 않음.
- **L2-D** = L1 + L2-M 같은 서로 다른 근거를 합성하는 *추론*. **직접 사례 개수에 합산하지 않음**. 실제 계약 추가·승인은 별도 권한 심사 필요.
- **L3** = 현대 제품의 직업·책임·재물·관계·건강 등 해석/예측 의미. 현재 모두 승인되지 않음.

위 L2-M/C/D, L3 구분은 **이 연구 문서 전용 표기**이며 현재 코드베이스의 enum·공식 계약·타입이 아님.
