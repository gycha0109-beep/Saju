## 1. R3 검색 대상과 검증 구조

질문은 `갑 일간 + 특정 연도 流年/太歲 干支 + 해당 十神 이름`이 **같은 인쇄본 문맥에 동시에 명시되는가**이다. 검색엔진 적중은 인쇄본의 존재·원문 정확성·실증성 확인과 다르다. 직접 사용례 `L2-C` 외에는 L0(전사), L1(일간 단독 명칭), L2-M(일반 방법), L2-D(이들에서 파생한 합성 가설)을 구분.

## 2. 신규로 확인한 중요한 원전 문맥과 위험한 오독

### (a) P3 비견: 진짜 太歲이지만 정확 十神 이름이 없다

『三命通會』 卷二 `論太歲` 전사(위키문헌):
- 앞 문맥 `甲子生人又見甲子年`은 출생년도와 뒤의 동일 연도를 대비하는 **真太歲** 사례로 별도 설명된다.
- 대상 부분은 **`甲子日見甲子太歲，謂之日年相併`**. `甲子日` 및 `甲子太歲`이므로 `甲日 × 甲年` 구조 자체는 원문 전사에서 직접 묘사한다.
- 그러나 여기의 이름은 `日年相併`이지 **`比肩`이 아니다**. 다른 장의 `比肩者...甲見甲` L1을 결합하면 **L2-D 파생**이지 인쇄된 개별 `比肩` 직접 L2-C가 아니다.
- 전사 URL: <https://zh.wikisource.org/zh-hant/三命通會/卷二>. 정확 明刻 인쇄 PDF 페이지와 해당 구절의 새 JPEG 검증은 **이번 라운드에 수행하지 않음**. **결과 분류: `L0_ANNUAL_IDENTITY_DIRECT_LABEL_MISSING`**.

### (b) P2 상관: 丁卯年의 `生`을 삭제하면 안 된다

『三命通會』 `論傷官` 전사에는 `如甲日人，以辛為官，見丁卯年，生寅午戌月，是傷官重犯` 및 뒤쪽 `流年再見`이 등장한다. `丁卯年生`/현대 표점과 원문 무표점의 관계를 소급 변경하지 않는다. 구절의 **출생 명식 해석** 뒤에 **유년에서 다시 만나는 경우**가 이어지는 구조이다. 출생 丁卯를 구체 *나중 연운 丁卯*으로 치환하는 순간 소스 범위를 위반한다.
- [전사와 구획](https://www.moshuyuan.com/zh-tw/chapter/zibu/san-ming-tong-hui/lun-shang-guan.html) `甲日見丁`은 명대 별도 인쇄 원전 L1 확인 유지.
- 기존 明刻 『三命通會』 第10冊 PDF p19 인쇄 L1과 상기 전사문은 **동일 판본이라는 자동 동일시 금지**. 새 구절의 정확한 인쇄 자구/행 간격은 이번 R3에 재대조하지 않았음.

### (c) P2 편인: 같은 壬申이라도 時와 年을 구별

『三命通會』 卷八 `六甲日壬申時斷`에 `甲日時逢壬申`, `倒食`, `偏官偏印`이 있다. 이 경우 壬申은 출생 **時柱**이다. 같은 명명 규칙을 특정 `壬申流年`에 적용했다는 직접 인쇄 사례가 될 수 없다.
- 비교용 URL: <https://zh.wikisource.org/zh-hant/三命通會/卷八>. 기존 明刻 第10冊 PDF p12 `倒食即偏印`·`甲見壬`의 L1 자체는 보존.
- `梟印`, `梟神`, `倒食`, `偏印`을 입력할 때에는 historicalRawLabel 그대로 보존. 등가성을 입증한 절 없이 명칭을 일괄 변경 금지.

### (d) P2 식신·P3 정인: 年로 검색돼도 출생 年柱일 수 있음

明刻 『三命通會』의 `甲食丙` 및 `六甲...癸爲正印` L1은 이미 검증. `六甲日丙寅時斷`/ `甲日癸酉時`은 **時柱**이고, 현대 표가 `甲木日元`의 `丙午年 食神`, `癸卯年 正印`을 써도 역사적 고전 인쇄의 직접 용례 증거는 아님.
- 원전 전사 [卷八](https://zh.wikisource.org/zh-hant/三命通會/卷八), [卷五](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷05).
- 현대 전사/계산 사용례: <https://www.muharram.net/bazi/nan-renwu-dingwei-jiawu-jisi-7de145f7.html> (**현대 생성된 사주 표**). 자료 유형이 명대·민국 인쇄본과 다름.
