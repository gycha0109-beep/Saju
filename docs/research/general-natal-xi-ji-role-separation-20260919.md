# R032 / R033 — 喜神・用神・忌神 operational separation

Date: 2026-09-19  
Issue: #967  
Status: SEMANTIC ROLE SEPARATION VERIFIED / GENERIC RESOLVERS BLOCKED

## Source
子平真詮評註 — 論正官取運 / 論財  
https://www.ncc.com.tw/fate/paleo/bg/bg_034.htm

## R032

The commentary gives an unusually explicit role tuple:

```text
官用財生
正官 = 用神
財   = 喜神
傷官 = 忌神
```

This directly establishes that 喜神 and 用神 are not synonyms in this operational context.

A second passage sharpens the point. A chart can be classified under 財 because 財 occupies the month-order category while the commentary still says:

```text
實非以財為用也，特財為喜神耳
```

Therefore:
```text
month-order category != automatic 用神 identity
喜神 != 用神
```

## R033

忌神 is also contextual.

The same volume gives:
```text
財化為官，忌神變為喜神
```

That is incompatible with a static table such as:
```text
element X always good
opposing element Y always 忌神
```

The role depends on the active configuration and governed relation/transformation.

## Boundary

This artifact verifies semantic separation only.

It does not answer:
- how to choose 用神 globally;
- how to derive 喜神 for every methodology;
- how to derive 忌神 for every methodology;
- whether a relation/transformation is canonically effective in a given chart.

Accordingly generic 喜神/忌神 resolvers and Production authority remain unauthorized.
