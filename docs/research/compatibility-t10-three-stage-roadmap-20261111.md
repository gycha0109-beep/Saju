# 명하 관계 비교(T10) 연구 보강 로드맵 — 3단계 확정

- 확정일: 2026-11-11. 사용자 승인: **기존 연구 대조 후 남은 3개 과제만 집중 보강하고 실제 구현으로 전환**.
- 작업 트랙: Saju PR #2763, 브랜치 `feat/saju-cross-chart-structural-evidence-20261109`.
- 범위: 2026-11-06 승인 상품의 **두 사람 관계 비교** 해석 근거. 본인 관계운 T8, 6개 단품, 5개 패키지 또는 MyeongHa 결제 권한을 변경하지 않는다.
- 계획 추정: **총 3~5일**(1단계 1~2일 / 2단계 1~2일 / 3단계 1일). 이는 과거 대화에서 사용자에게 제시된 *예상 소요*이지 실제 완료 보증이나 비동기 작업 약속이 아니다.
- 우선 적용 정책: Saju `docs/ROADMAP.md`의 기존 **원국·연월 해석 품질 7단계 활성 실행 로드맵을 수정하거나 대체하지 않는다**. 이번 문서는 별도 승인된 관계 비교 연구의 *제한된 범위 관리 기록*이다.
- 기초 조사: `docs/research/compatibility-pairwise-source-scope-review-20261111.md`; 기존 R068·R069·R070, Canonical 2개 명식, #2763 일지 육합·충 후보 및 개별 간여지동 관찰을 재사용한다.

## 1단계. 궁위·육신·용신의 **기존 연구 사용 가능 범위 검증** (1~2일)

**목표**: 같은 원전·논문에서 말하는 방법론적 관찰과 실제 명하 계산·검증된 해석을 연결하고, 단순히 데이터가 존재한다는 이유로 두 사람의 T10 판단이 가능한 것처럼 처리하지 않는다.

- [ ] **궁위**: 실제 두 명식의 일지 육합/충과 각각의 간여지동 관찰, 출처·적용 대상·조건(부부/혼인 사례)을 연결. 해당 관찰이 없을 때 '좋음/나쁨'을 결론 내리지 않음.
- [ ] **육신**: 기존 T5 십신과 R069 배우자성 연구의 구조·역사적 성별 범위, 강약 판단 근거, 직접적 두 사람 비교 규칙 유무를 추적.
- [ ] **용신**: 기존 원국 오행 계산과 달리, 실제 개인별 용신 판정의 근거/검증된 규칙 및 '상대의 오행 보완'에 필요한 직접 규칙이 있는지 확인. 없으면 미지원 명시.
- [ ] 판정 가능한 **사실·연구 관찰 / 아직 미검토 해석 / 근거 부재**를 분리하는 실행 가능한 연구 증거표와 단위 테스트에 반영.
- **완료 조건**: 3개 축 각각에 (① 소스 위치·권위 ② 명식 계산 위치 ③ 허용 의미 ④ 제한·미지원 사유)가 있고, 두 사람 순서 반전·불완전 입력에도 사실을 과장하지 않으며, 공개 Preview·Official·판매 플래그가 그대로 보류됨.
- **근거 경계**: RISS 주미강(2014) *국문초록*에서 궁위/육신/용신 3축과 학파 간 충돌을 확인; KCI 남기동·김만태(2018) *국문초록*에서 이별 부부 표본의 간여지동·배우자성 약함 언급을 확인. 초록만으로 가중치나 관계 성과 예측을 공식화하지 않는다.

## 2단계. 합·충 등 **상반된 근거의 조정·종합 방법 검증** (1~2일)

**목표**: 1단계에서 검증된 후보가 상충할 때 어떻게 처리할지 문헌·기존 Rule/Methodology에 의해 결정한다.

- [ ] 일지 육합과 다른 위치 충 등 **부호가 다른 사실의 동시 존재**, 단일 명식 내부의 장·단, 두 명식 간 관찰을 **독립 구분**.
- [ ] 소스가 명시한 우선순위/조건/예외만 실행 규칙 후보로 등록하고, 소스 간 이견이나 우선순위 부재는 **종합 결론 보류**.
- [ ] 근거가 없는 용신 추론, 혼인 결과·점수·길흉 단정, 모든 관계유형의 동일한 추론을 금지.
- **완료 조건**: 재현 가능한 상충 사례의 실제 명식 계산/근거·Rule·Source를 기록; 우선순위를 뒷받침할 직접 소스가 없으면 미결정 상태를 테스트로 고정. **문헌이 끝내 불충분하면 '종합 규칙 미성립'을 종료 판정**하고 무한 연구하지 않는다.

## 3단계. **실제 두 명식 조합에서 품질·근거 추적 검증** (1일)

**목표**: 같은 계산과 문헌에 결속된 근거가 실제 개인별 출력에서 변하는지 입증한다. 공식 품질 승격은 별도의 기존 릴리스 게이트를 따른다.

- [ ] 서로 다른 실제 달력 출생입력의 쌍, 상대 순서 반전, 시각 미상, 조건 미해당, 일지 육합과 충 교차, 역사적 성별 가정 불일치를 고정 테스트.
- [ ] 출처·명식 해시·정확한 계산 위치·허용된 결론과 보류 사유를 결과 단위로 추적. 기존 두 사람 출력 HTML·공개 Preview 경계가 변경되지 않는지 검증.
- [ ] 확인된 해석만 기존 Saju 해석 체계로 전달하는 방식 평가. 미확인 주장/전반적 관계 판정을 판매용 Reader가 생성하지 못하게 유지.
- **완료 조건**: 실제 명식쌍 테스트와 CI/테스트 증거, 상품별 가능한 해석 범위·남은 미해결 범위 최종 판정. T10 전체가 충분하지 않으면 연구 **범위 종료**와 **판매 보류**를 구분해 기록.

## 작업 규칙 및 종료 기준

1. **기존 연구/코드/문서와 동일한 작업 반복 금지.** 3개 확정 과제 외 기능 추가·새 서비스/별도 해석 엔진 생성 금지.
2. 결과 구분: **계산 사실** / **출처 기반 연구 관찰** / **검토 전 해석 후보** / **공식 인정된 해석**. 권한 없는 결과는 승격하지 않는다.
3. R068/R069/R070의 한 사람 원국 연구를 곧바로 상대방과의 T10 관계 결론으로 합성하지 않는다. 각 사람 명식·버전·권한·입력 시각 및 역사적 적용 범위 보존.
4. 논문 **초록**과 **본문 원문**을 구분하고, 미확인 문헌은 판정 근거로 취급하지 않는다. 학파 간 모순을 점수·가중치로 임의 봉합하지 않는다.
5. 새 유료 API 호출·실결제·운영 배포·공식 해석 권한·가격/카탈로그 변경 없음. 필요하면 별도 사용자 승인.
6. 병합·완료는 실제 CI 및 원래 승인된 각 트랙 완료 조건을 따름. 연구 종료가 곧 T10 판매 승인이라는 뜻은 아님.
