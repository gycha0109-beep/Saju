# R034 — 調候 priority conditions

Date: 2026-09-19  
Issue: #968  
Status: VERIFIED_BOUNDED_PRIORITY_SEMANTICS / EXECUTION BLOCKED

## Source
子平真詮評註 — 論用神配氣候得失  
https://www.ncc.com.tw/fate/paleo/bg/bg_033.htm

## Result
The source does not support a simple global rule:
```text
調候 always overrides everything
```

It says:
```text
取用神，於扶抑之外，必須參合氣候
```

So climate is an additional required axis.

For winter 金水 it further says fire cannot be absent, while explicitly warning:
```text
非定以為用也
```

A cited weak-body case then keeps 酉金 as the support/use even though 丁火 is climate-relevant.

Therefore:
```text
climate urgency/necessity
!= automatic final 用神 identity
!= universal override of strength/support
```

## Seasonal context
The commentary explicitly contrasts:
```text
春木逢火 vs 夏木逢火
秋金遇水 vs 冬金遇水
```

The same element relation changes meaning with season.

## Boundary
R034 verifies priority semantics only. It does not authorize a climate-state classifier, a day-stem/month requirement resolver, or a universal arbitration rule between Tiaohou and Fuyi.

No Production / SKU / Commerce authority is created.
