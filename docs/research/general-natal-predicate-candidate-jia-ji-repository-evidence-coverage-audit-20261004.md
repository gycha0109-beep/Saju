# R180 — 甲己 pair-local outcome 저장소 보유 근거 coverage audit

> 날짜: 2026-10-04  
> 상태: 연구 완료 후보  
> 트랙: saju-research

## 목적

R179는 甲己 pair-local interaction outcome을 위해 여섯 개 요구조건을 고정했다.

R180은 새 전통 규칙을 만드는 단계가 아니다.

현재 저장소에 이미 존재하는 연구 자산이 이 여섯 요구조건을 어디까지 커버하는지 감사해,
중복 연구를 방지하고 외부 primary/canonical witness 탐색이 필요한 지점을 특정한다.

## 저장소 내 확보 자산

### R051

甲己를 천간 오합 family로 보존한다.

    pair identity = verified
    effective combination = unauthorized
    transformation = unauthorized

즉 pair identity는 있지만 interaction result는 없다.

### R142

천간 오합의 반복 counterpart 및 경쟁 target topology를 구조적으로 보존한다.

그러나:

    target selection = unauthorized
    effective combination resolver = unauthorized
    transformation resolver = unauthorized

이다.

### R172

壬生午月 사례에서:

    運透己官
    本命有甲
    原局透甲，則官星被回剋而無用

이라는 exact source narration을 보존한다.

이 근거는 甲이 己官을 回剋한다고 보고하지만,
甲己 구조 합 후보와의 coexistence settlement를 직접 설명하지 않는다.

### R177 / R178

R177은 같은 甲/己에:

    甲(木)剋己(土)
    stem_five_combination candidate

두 표면이 동시에 존재함을 확인했다.

R178은 두 천간이 모두 비일간이므로 day-master 化氣 result contract의 직접 전이를 차단했다.

따라서:

    binding = 미결정
    transformation = 미결정
    interaction outcome = 미결정
    post-combination subject identity = 미결정

상태다.

## R179 요구조건 coverage

### 1. EXACT_NON_DAY_MASTER_JIA_JI_INTERACTION_SOURCE

**부분 substrate만 있음.**

R172/R177/R178이 exact 壬–甲–己 문맥과 topology를 제공하지만,
비일간 甲己의 合 interaction을 직접 판정하는 source witness는 없다.

### 2. CONTROL_AND_COMBINATION_COEXISTENCE_SEMANTICS

**결과 권한 없음.**

剋과 合 구조 후보는 동시에 보존되지만
공존, 취소, 약화, 변경 중 무엇이 일어나는지 판정하는 근거가 없다.

### 3. BINDING_OR_NON_BINDING_SEMANTICS

**결과 권한 없음.**

R051의 pair identity는 binding 판정이 아니다.
R178도 generic 化氣/羈絆 result transfer를 차단한다.

### 4. POST_COMBINATION_SUBJECT_IDENTITY_OR_FUNCTION_PERSISTENCE

**결과 권한 없음.**

interaction 이후 甲/己가 유지되는지,
기능이 달라지는지,
다른 주체로 대체되는지에 대한 권한이 없다.

### 5. CONTEXT_AND_EXCEPTION_CONDITIONS

**부분 substrate만 있음.**

월지, 일간, 운, configuration dependence, repeated-pair topology 등은 표현되어 있다.

하지만 이 조건들을 묶어 甲己 interaction outcome을 결정하는
source-bounded 충분조건 집합은 없다.

### 6. PAIR_LOCAL_OUTCOME_DISTINCT_FROM_CROSS_RELATION_PRECEDENCE

**저장소 governance는 있음.**

R177/R178/R179/I233은 pair-local outcome과 generic cross-relation precedence를 분리한다.

하지만 이 governance 경계는 전통 source가 제공하는 甲己 interaction result authority가 아니다.

## 결론

현재 저장소는 여섯 요구조건 모두에 대해
구조 substrate 또는 governance boundary를 보유한다.

그러나 normative source authority 충족 수는:

    0 / 6

이다.

따라서 기존 자산을 조합하거나 모델 추론으로 승격하는 방식으로는
R179 요구조건을 닫을 수 없다.

다음 진전은 외부 primary/canonical witness discovery여야 한다.

특히 우선순위는:

1. 비일간 甲己 interaction을 직접 다루는 문헌
2. 剋과 合이 함께 있는 경우의 coexistence semantics
3. binding/non-binding 및 post-combination 기능 지속 여부

순으로 두는 것이 적절하다.

이 탐색에서도 검색 snippet이나 일반 상식만으로는 authority를 획득한 것으로 간주하지 않는다.
