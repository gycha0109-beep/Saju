# SA-5V 배우자궁 위치 한정 공식 판독 진입 적격성 검토 v1

이슈: #2039  
트랙: `saju-bridge`

## 목적

SA-5U에서 실제 미리보기 전달 권한까지 검증된 배우자궁 위치 한정 기능이 향후 공식 판독 경로에 진입할 수 있는 구조인지 검토한다.

이 단계는 **진입 적격성만 판정**한다. 실제 공식 판독 권한을 부여하거나 `officialReadingSections`를 수정하지 않는다.

## 검토 대상

- 판독 구역: `relationship:natal:spouse`
- 주장 유형: `relationship.spouse.traditional_spouse_palace_position`
- 의미 계열: `DAY_BRANCH_TRADITIONAL_SPOUSE_PALACE_POSITION`
- 의미 범위: `position_only`
- 직접 사실 근거: `pillars.day`

허용되는 가시 의미는 다음뿐이다.

> 전통 명리에서는 일지(日支)를 배우자궁의 위치로 봅니다.

필수 한정문:

> 이는 배우자궁의 위치에 대한 전통적 분류이며, 배우자의 성격이나 정체, 결혼 시기 또는 관계 결과를 의미하지 않습니다.

## 격리 검증 경로

실제 권한표를 수정하지 않고 다음 경로를 연구 검증 안에서만 실행한다.

```text
실제 프로젝트 관리 배우자궁 위치 주장
→ 판독 근거 선택
→ 정규 의미 단위
→ 공식 판독 계획
→ 공식 판독 렌더링
→ 리더 근거화
```

정규 의미 단위의 본문과 한정문은 기존에 승인된 위치 한정 프로필 및 미리보기 의미 입장 기록에서만 가져온다.

## 검증 결과 조건

적격 판정을 위해 다음이 모두 성립해야 한다.

1. SA-5U 미리보기 전달 권한이 정확히 유지된다.
2. 실제 배우자궁 위치 주장이 판독 근거 선택에서 단 하나의 목표 주장으로 선택된다.
3. 직접 사실 근거가 `pillars.day` 하나로 유지된다.
4. 정규 의미 단위가 기존 제목과 요약만 포함한다.
5. 필수 한정문이 정규 의미 단위, 공식 판독 출력, 리더 근거화까지 보존된다.
6. 공식 판독 계획이 관계 의미와 해석 범위로 표현 가능하다.
7. 리더 근거화 축은 `relationship`으로 유지된다.
8. 배우자 성격·정체·외모·직업·결혼 시기/결과·이혼/재혼·길흉·용신/기신·배우자 별 자동 선택·궁합 확장이 발생하지 않는다.
9. 기존 공식 판독 5개 구역은 변경되지 않는다.
10. 배우자 구역의 현재 소비자 권한은 계속 `legacy_narrative`이다.
11. 공개 의미·결제·영속 저장·일반 공개·운영 해석 권한은 계속 닫혀 있다.

## 결정

성공 시:

`POSITION_ONLY_OFFICIAL_READING_ADMISSION_ELIGIBLE`

이 결정이 의미하는 것은 오직:

- 현재 위치 한정 의미가 기존 공식 판독 의미 구조에 손실 없이 들어갈 수 있음;
- 다음 단계에서 실제 공식 판독 진입 구현을 검토할 수 있음.

이 결정이 의미하지 않는 것:

- 공식 판독 권한 부여;
- 공식 판독 지원 구역 추가;
- 공개 의미 권한;
- 결제;
- 영속 저장;
- 일반 공개;
- 운영 해석 권한.

외부 전문가 검토, 검토 증명, 검토자 신뢰 컨텍스트 및 신뢰 부여 요구사항은 다시 도입하지 않는다.

운영 상태는 계속 `HOLD`다.
