## 1. 기존 작업과 이번 작업의 차이

- **#2492**: 원국(4개 기둥), 대운, 세운의 6개 **슬롯**에서 9개 교차 쌍과 16개 삼합 후보를 확인하고, 합·충의 슬롯 공유/분리 여부까지 판별. 이것은 원래 있던 기능이므로 재구현하지 않는다.
- **#2500**: 인쇄본 『子平真詮』 「論刑沖會合解法」 PDF 24쪽(인쇄 十五)에 `亥卯未` + `卯酉沖`, `巳酉丑` + `卯酉沖` 사례가 **원국 명식 문맥에서 기술됨**을 확인.
- **#2502**: 『子平真詮』 「論行運」, 『三命通會』 「論太歲」「總論歲運」에서 **원국/대운/세운을 함께 고려한다는 범위만** 확인. 완전한 삼합 3지지와 충의 우선순위 방법은 미발견.
- **이번 단계**: 실제 계산된 6슬롯 구조와 위 두 **인쇄본 원국 사례의 지지 글자 구성이 같은지**를 엄격하게 비교. `same_branch_values_and_shared_slot_analogy_only`는 **원전의 결과를 현재 연운에 적용할 수 있다는 뜻이 아님**.

## 2. 실제 재현 대상 (모두 의도적으로 조립한 합성 스냅샷)

사용한 2027 세운은 `丁未`; 2026 세운은 `丙午`. 대운 및 원국 기둥의 지지 부분은 테스트에서 임의 지정한 **구조 검증용 가상 값**이다. 사용자의 실제 출생 데이터나 실현 가능한 대운 명식이 아니다.

| 사례 | 세운 | 대운 | 원국 지지(年/月/日/時) | 프로그램이 관측해야 하는 것 | 무엇이 여전히 불가능한가 |
|---|---|---|---|---|---|
| A | 未 | 卯 | 亥 / 酉 / 丑 / 子 | 세운 未 + 대운 卯 + 원국 亥 = `亥卯未`; 대운 卯↔원국 월 酉 = `卯酉沖`; **대운 슬롯 공유**. 또 세운 未↔원국 일 丑 충은 별도 기록 | 원전의 `會而不沖`를 **연운에서도 자동 실행** |
| B | 未 | 酉 | 巳 / 丑 / 卯 / 子 | 대운 酉 + 원국 巳/丑 = `巳酉丑`; 대운 酉↔원국 일 卯 충, **대운 슬롯 공유** | 세운 없이 완성한 대운–원국 삼합을 개인 길흉으로 확정 |
| C | 未 | 酉 | 亥 / 卯 / 卯 / 子 | 같은 지지 `卯`가 원국 월·일 서로 다른 슬롯에 나타남. 2개 삼합 후보 × 2개 충 = **총 4개 비교**. 이 중 **같은 슬롯 공유 2개 vs 글자만 같고 슬롯이 다른 2개** | 다른 기둥의 卯를 같은 지지라는 이유로 합쳐 "해소"했다고 판정 |
| D | 午 | 寅 | 戌 / 子 / 申 / 辰 | `寅午戌` 삼합 후보, `午子沖` 동시 관측. 인쇄본에서 **동일한 완전한 삼합·충 지지 조합 사례는 미확인** | 『子平真詮』 예의 "합 우선"을 다른 합·충 조합에 일괄 적용 |
| E | 午 | 子 | 子 / 子 / 子 / 子 | 삼합 후보 0, 다수 지지 충; 유사 인쇄 예도 없음 | 결과 없음 = 길함/안전하다는 낙관적 기본값 |

**중요:** A/B는 고전의 문자 구성에 대한 **조건부 유사성**만 표시한다. 고전 원국의 위치·명식·그 밖의 합/충이 테스트의 원국·대운·세운과 동일하지 않다. C는 명확히 **가짜 슬롯 일치(false positive)**를 차단하는 반례다.

## 3. 확인 수준의 세 가지 단계

| 관측 결과 분류 | 허용되는 의미 | 허용되지 않는 결론 |
|---|---|---|
| `same_branch_values_and_shared_slot_analogy_only` | 삼합 세 글자, 충 두 글자, 두 관계가 공유하는 **정확한 슬롯의 글자**까지 고전 설명과 일치 | 삼합이 충을 해소·제압했다고 확정 |
| `same_branch_values_but_different_pillar_slots` | 글자의 종류는 같으나, 충이 삼합의 **같은 실제 기둥을 사용하지 않음** | 지지 값만으로 서로 다른 원국 기둥을 한 슬롯으로 병합 |
| `no_printed_case_with_identical_branch_values` | 비교한 **두 개의 원국 인쇄 예**에서는 동일 패턴 발견되지 않음 | 다른 고전에도 해당 규칙이 없다는 보편적 결론 |

**원문 위치:** [『子平真詮』 스캔 PDF 인쇄 十五, PDF 24쪽](https://commons.wikimedia.org/wiki/File:NLC416-11jh010455-35296_子平真詮.pdf). [『三命通會』 卷二 원국/세운/대운 공동 논의, PDF 25~27쪽](https://commons.wikimedia.org/wiki/File:NLC892-411999029701-67187_三命通會_第4冊.pdf).
