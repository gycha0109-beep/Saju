# R150 — Minimal interaction predicate set for executable claims

Date: 2026-09-29  
Track: saju-research  
Status: research-only

## Purpose

R150 closes the R141–R150 interaction-semantics block by asking a narrower question than "can interactions be executed?":

> What exact predicates are required before the one already-authorized bounded interaction consequence may be emitted?

The answer is deliberately split into:

1. bounded evidence execution inside the I45→I46→I47 contract
2. InterpretationClaim authority
3. production authority

Only the first exists here.

## Exact bounded claim

The only deterministic interaction consequence in the reviewed R141–R149 frontier is the I46/I47 three-combination placement result:

BROKEN_BY_TIGHT_EMBEDDED_CLASH

This is not a generic clash rule.

It applies only inside the exact challenge-root evidence contract.

## Seven-predicate per-clash set

A per-clash deterministic break evidence item requires seven predicates:

1. all four pillars are resolved
2. structural three-combination bureau formation is resolved and aligned
3. the tracked clash relation is aligned to the current structural graph
4. the clash contains exactly one bureau participant and one external counterpart
5. the external counterpart is embedded within the bureau span
6. the counterpart is tightly adjacent to the directly clashed bureau participant
7. I46 authorizes BREAK_AUTHORIZED for that exact placement

Within I47 these are fail-closed requirements.

Removing any one prevents the same per-clash deterministic evidence from being emitted.

This minimality claim is contract-local, not a universal traditional-astrology theorem.

## Eight-predicate aggregate set

The aggregate item-level postInteractionBureauState requires the same seven predicates plus:

8. exactly one direct source-bounded break is present

I47 intentionally keeps the aggregate state not_determined when the direct break count is not exactly one.

Therefore the cardinality predicate belongs to the aggregate claim but not to the individual clash evidence.

## Removal semantics

R150 records explicit removal outcomes:

- unresolved pillars → PILLARS_UNRESOLVED
- unresolved or misaligned bureau formation → formation gate failure
- misaligned clash topology or participant partition → CLASH_TOPOLOGY_MISALIGNED
- non-embedded or non-tight placement → the exact break placement no longer exists
- invalid I46 policy → METHODOLOGY_NOT_AUTHORIZED
- direct-break count other than one → aggregate state remains not determined

The audit follows the removal-sensitivity approach already operationalized in R130, but it does not import strength semantics.

## Broader interaction frontiers remain blocked

R150 records eight blocked frontiers:

- R141 — generic multi-relation settlement
- R142 — competing stem-combination target winner
- R144 — punishment effect
- R145 — harm/break effect
- R146 — hidden-stem runtime activation
- R147 — directional interaction effect
- R148 — global interaction precedence
- R149 — generic position effect

None has a minimal executable predicate set established for InterpretationClaim emission.

## Execution is not claim authority

The I47 evidence contract can deterministically materialize one bounded evidence state.

That does not authorize:

- generic interaction semantics
- a chart-role fact
- an InterpretationClaim
- preview semantic admission
- production promotion

R150 therefore distinguishes:

boundedEvidenceExecutionAuthorized = true

from:

interpretationClaimEmissionAuthorized = false  
productionAuthorityPromoted = false

## Rejected shortcuts

R150 rejects:

- structural relation identity alone as executable effect
- pair/group membership as settled consequence
- directionality as effect authority
- position materiality as generic resolver
- bounded source case as global precedence
- target competition as winner selection
- punishment multiplicity as severity
- harm/break membership as harmful polarity
- hidden membership as runtime activation
- embeddedness without tightness as break
- tightness without embeddedness as break
- I46 policy without aligned formation as break
- multiple direct breaks as one aggregate state
- bounded evidence execution as InterpretationClaim authority
- research minimality as production promotion
- preview readiness as semantic admission
- numeric weight as a substitute for missing predicates
- first-match/array order as a substitute for missing predicates

## Authority

R150 establishes:

- a seven-predicate minimal set for per-clash break evidence inside I45/I46/I47
- an eight-predicate minimal set for aggregate bureau state
- fail-closed contract-local necessity
- source-bounded contract-local sufficiency
- a strict boundary between bounded evidence execution and semantic claim authority

R150 does not establish:

- a general interaction minimal predicate set
- a generic interaction resolver
- generic InterpretationClaim emission
- automatic engine admission
- preview promotion
- production authority

The next roadmap block, R151–R160, moves to temporal reasoning and replay rather than broadening this narrow interaction execution contract.
