# R185 — 甲己 direct-rule 2차 문구 provenance 추적

> 날짜: 2026-10-05  
> 상태: 연구 완료 후보  
> 트랙: saju-research

## 목적

R184에서 현대 2차 자료에 exact 甲己 same-pair `克 + 合` 설명이 실제로 존재함을 확인했다.

R185는 그중 조건부 direct-rule 문구군의 공개 provenance를 뒤로 추적한다.

## 현재 가장 이른 귀속 가능한 공개 표면

검색 가능한 공개 표면에서 다음 metadata가 함께 나타난다.

- 제목: 「天干地支的刑冲合害等作用关系的整理与复习」
- 표시 인명: 宋坤
- 표시 시각: 2011-10-06 11:35
- 문구군:
  - 甲己가 모두 유근/유생/유조이면 합화하지 않음
  - 생극을 논함
  - 甲木克己土
  - 서로 견제 또는 合绊
  - 양쪽 힘 감소

이 표면은 현재 조사 범위에서 R184-C01 계열 문구보다 이른
**earliest attributable public surface candidate**다.

그러나 이 표현은 의도적으로 제한한다.

    earliest attributable surface candidate != first publication
    displayed name != verified original author

## 후대 재게시의 추가 단서

2021년 阿启网 재게시 표면은 동일 제목 계열을 유지하면서
본문 서두에 다음 성격 표기를 둔다.

    松原易学年会 讲座稿

이것은 중요한 provenance clue다.

하지만 아직 다음은 알 수 없다.

- 어느 연도의 松原易学年会인지
- 실제 강연자가 누구인지
- 宋坤이 원저자인지 정리자인지
- 공식 배포된 강연원고가 남아 있는지
- 2011 웹표면이 그 강연원고에서 직접 왔는지

따라서 강연원고 표기는 source lineage candidate일 뿐 primary witness가 아니다.

## 중복 표면

동일 문구군은 후대 여러 사이트에 반복된다.

예:

- 吾爱文档 계열
- 汉相堂 2019 표면
- 阿启网 2021 표면

문구 반복은 검색에는 유용하지만 독립 근거 수를 늘리지 않는다.

    duplicate text != independent corroboration

## R184 exact 비일간 사례는 별도 계보

R184에서 가장 중요한 사례 중 하나는:

    日元 = 庚
    甲 / 己 모두 비일간
    甲己相合
    甲 = 克 위치
    己 = 被克 위치

라는 direct-match 사례다.

그러나 이 사례는 현재 Read01 재게시 표면으로만 잡혀 있고,
2011 宋坤 문구군과 동일 계보인지 확인되지 않았다.

따라서 R185에서는 자동 연결하지 않는다.

## 이번 단계의 진전

R184:

    direct-match modern candidate = yes
    original lineage = unresolved

R185:

    earliest attributable public rule surface candidate = 2011-10-06
    displayed attribution = 宋坤
    later lecture-manuscript clue = 松原易学年会 讲座稿
    original author = unresolved
    first publication = unresolved
    primary manuscript = not acquired
    direct-case lineage = still unresolved

즉 provenance 질문이 한 단계 좁아졌다.
