# Saju Final — Unit 09: T2 강약 준비도 그래프 공통 판단 연결 Worklog

- 작업일: 2026-11-24
- 브랜치: saju-final-unit-09-strength-readiness
- 범위: 기존 공통 원국 판단에 I18D/I18E/I19/I20/I20D/I22/I23v2/I24 연구 판단 준비도 연결
- 상태: **코드 연결 및 회귀 테스트 추가 완료 / CI 확인 대기**

## 1. 목적

기존 whole-chart-judgment의 강약 관측 상태가 최종 신강·신약 판정으로 오해되지 않도록, 이미 구현된 비수치 준비도 그래프를 같은 명식 판단 결과에 연결한다.

새로운 강약 계산식을 만들지 않고, 기존 연구 모듈이 제공하는 입력 불확정·특수격 검토·방법론 미해결 사유를 하나의 추적 가능한 결과로 제공한다.

## 2. 연결한 기존 모듈

- I18D: 근 위치와 구조 관계의 접점 검토
- I18E: 특수격 신호 라우팅
- I19: 관계 이후 뿌리 효과 검토
- I20: 계절 단계와 위치별 동류·인성 지원 근거
- I20D: 충에 닿는 구응 관계 후보 라우팅
- I22: 지원 근거의 제한된 부분 순서 및 비교 불가 상태
- I24: 지장간 식상·재성·관성 제약 메커니즘 분리
- I23 v2: 최종 강약 대신 결정적 중지·검토 사유 출력

## 3. 코드 변경

파일: src/interpretation/whole-chart-judgment.ts

1. Canonical snapshot과 이미 계산된 Ten-God 위치 목록을 받아 위 연구 모듈을 연결하는 readiness builder를 추가했다.
2. 계절·위치별 지원 근거는 기존 I20 출력에서 가져온다.
3. 숨은 식상·재성·관성은 위치·십신을 보존한 채 I24 메커니즘 분류로 전달한다.
4. I23 v2 결과를 whole-chart judgment의 strengthReadiness로 붙인다.
5. 판단 버전을 whole-chart-judgment-v7로 올린다.

## 4. 추가 회귀 테스트

파일: test/whole-chart-judgment.test.ts

## 5. 범위 제한

이 연결은 I23 v2가 정의한 강약 준비도 그래프까지다. I25/I26의 모든 세부 관계 효과·정산을 완료한 것으로 취급하지 않는다.

- 강약 판정: 계속 미출력
- 숫자 점수: 미사용
- 최종 용신·희기: 미선택
- 격국 성립: 미판정
- Official/Production 권한: 변경 없음
