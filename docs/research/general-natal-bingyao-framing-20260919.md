Date: 2026-09-19

## Source stratum

徐樂吾評註 — 論用神  
https://www.ncc.com.tw/fate/paleo/bg/bg_032.htm

Direct wording:

```text
（二）病藥。以扶為喜，則以傷其扶者為病；以抑為喜，則以去其抑者為病。
除其病神，即謂之藥。此以病藥取用神也。
```

## Bounded result

The source does not define a global list of bad "disease" elements and good "remedy" elements.

Instead the roles are relational:

```text
扶 is desired
→ what harms the governed support = 病

抑 is desired
→ what removes the governed suppression = 病

remove the governed 病
→ 藥 family
```

Therefore 病/藥 identity is downstream of a governed configuration and governed effect relation.

## Authority

R038 verifies the semantic framing and applicability dependency only.

It does not authorize:
- a fixed element-to-disease table;
- a fixed element-to-remedy table;
- presence-only 病/藥 labels;
- a universal 病藥 resolver;
- cross-method winner logic;
