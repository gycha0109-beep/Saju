# SA-7D-B1-R14 — 『淵海子平』 甲辰日·壬辰年 명례의 연간 사용과 偏印 직접 명칭 분리 감사 v1

> 2026-10-09 · Watchtower-Track: `saju-research` · R13 C13-01 한 후보만 제한 조사 · **웹 전사 문맥 대조 PASS / 원본 인쇄 직접판독 미실시 / 신규 L2-C 0건 / Annual 1/8 불변 / Production HOLD**.

## 1. 질문 및 정확한 증거 기준

R13의 C13-01은 『淵海子平』 `論正財`에 **戊子·丁巳·甲辰·丙寅** 명식과 **六十五歲 逢壬辰年**이 함께 등장한다는 근접 사례다. 이것이 *해당 역사 인쇄본에서* 甲日×壬流年을 **`偏印`이라고 직접 명명**한 증거인지 점검한다.

- **L0 명례의 유년 시점 식별:** 특정 명식의 甲日, 해당 인물의 후속 유년 `壬辰年`.
- **L0 연간 작용 설명:** 같은 명례에서 `壬辰透出壬水` 및 壬水의 오행적 작용을 설명하는가.
- **L0 일반 명칭:** 같은 웹 편집본 다른 문단에서 일반 `甲見壬→倒食/偏印/梟神`처럼 분류하는가.
- **L2-C 직접 고전 유년 명칭:** 정확히 **그 壬辰 유년**에 `偏印`이라는 십신명을 서술자가 붙였다는 동일 인쇄 증거(실제 책·권차·쪽·판면)인가.

**판정:** 앞 세 질문의 일부는 웹 전사에서 확인된다. 마지막 **직접 인쇄 L2-C는 충족되지 않았다**. 한 문서 안의 *일반 十神 표*와 *특정 年運 명례*를 현대 계산으로 결합하면 `L2-D_CONDITIONAL` 가능성을 논의할 수 있으나 `L2-C`로 셀 수 없다.

R14는 **일반 `甲→壬 偏印` 명칭의 존재**를 부정하지 않는다. 하지만 그 명칭이 `六十五歲逢壬辰年`의 개별 연운 설명에 *직접 인쇄되어 있었다*는 증명은 다른 문제다.

## 3. 웹 전사 간 교차와 판본 출처 한계

- 중국 전사본 여러 웹사이트와 한국어 플랫폼 게시 전사에서 **`甲辰日` 명식·`壬辰年` 명시·`壬辰透出壬水`**라는 본문 구조가 반복된다. 이는 **같은 텍스트를 재게시했을 가능성이 높아** 복수의 독립 역사 인쇄 증인을 확보했다는 뜻이 아니다.
- 편집본 간 주변 문구는 `忌火沖水` vs `忌水沖火`처럼 **상반된 글자 순서의 판독·전사 차이**가 있다. 따라서 고전 원문을 정확한 판본 인용으로 확정하려면 **인쇄 이미지 직접 확인**이 별도 필요하다.
- [Commons 인쇄본 서지 제1冊](https://commons.wikimedia.org/wiki/File:NLC892-2642-210287_刻京臺增補淵海子平大全_第1冊.pdf): NLC `NLC892-2642-210287`, **明萬曆刻本**, 48쪽, 표제 소개에 `卷之一·卷之二` 포함. **`論正財` 실제 정확 페이지와 해당 `壬辰` 문구가 이 개별 인쇄본 판면에 존재하는지 이번 연구에서 직접 확인 못함**. Commons가 표시한 file size·SHA-1 메타는 실제 전체 PDF 바이너리를 다운로드·계산한 자기 검증이 아님. 일단 **원본 추적 후보**로만 식별.
- PDF 바이트 취득 시도가 외부 접근 오류로 성립하지 않았으므로 **원본 PDF SHA-256 / PDF 정확 pageno / printed page / 직접 인쇄문구는 모두 UNVERIFIED**. 제1冊의 카탈로그 존재를 `L1` 증거로 승격하지 않는다.
- 특히 전사상 `偏印`이 **동일 문단에 없음**은 관찰 가능한 부정 결과이지만, **모든 시대의 실제 인쇄판에서도 해당 이름이 절대 없다**는 전역 부존재 증명은 아니다.

## 4. 새 연구 결론 및 재진입 게이트

**R14/C13-01 최종 분류(문서 전용 태그, TS enum 아님):**

- `DAY_STEM_IN_EXAMPLE = 甲 [L0]`
- `ACTUAL_ANNUAL_PERIOD = 壬辰年 [L0]`
- `EXPLANATORY_ANNUAL_STEM = 壬水 [L0]`
- `GENERAL_TENGOD_LABEL_FOR_甲壬 = 偏印 [L0, separate generic section]`
- `L2_C_DIRECT_NAMED_甲日_壬辰年_偏印 = NO_VERIFIED_PRINT_WITNESS`
- `CANDIDATE_DISPOSITION = ANNUAL_YEAR_STEM_USED_BUT_DIRECT_TENGOD_NAME_ABSENT_IN_CHECKED_TRANSCRIPT`

**P1 후보 조사 일시 종료:** 동일 전사 URL을 더 늘리는 작업만으로는 L2-C 증분을 얻지 못한다. **정확한 인쇄 이미지의 `論正財` 본문에 해당 年을 `偏印`이라 직접 명명하는 새 본문/주석·페이지 리드가 제시될 때만** 원문 판면 확인을 재개한다. 원문이 일반 오행 유년 작용만 적었다면 L0 또는 방법론 범위에 보존하고 끝낸다.

**핵심 유의:** 내용에는 `六十五歲逢壬辰年死矣` 같은 전통 길흉 서술이 있지만, 이것은 고전 저자의 사례 서술이지 **현대 개인의 건강·수명 사건을 예측할 수 있다는 실증**이 아니다. 사주 서비스의 미래 사건 설명으로 자동 승인·확장 금지.
