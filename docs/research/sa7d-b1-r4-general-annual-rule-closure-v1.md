# SA-7D-B1-R4 — 유년 천간 十神 대응의 일반 규칙 완결성 감사 v1

> Watchtower-Track: `saju-research` · 2026-10-09 · **역사적 계산 범위 연구만**. 명하의 공식 엔진/십신 계약 또는 Annual product grade를 변경하지 않는다. `bridgeReentryReady=false`, `Production=HOLD`, 8종 모두 `sourceSupportGrade=INSUFFICIENT`.

## 1. 서로 다른 세 가지 가설

- **H1 방법 일관성:** 고전 子平文獻은 日干을 기준으로 十神/陰陽生剋을 분류하고, **流年/太歲의 연간**을 판단 입력으로 살펴본다는 *일반 방법*을 기술한다.
- **H2 출력 도출가능성:** **직접 인쇄가 확인된 특정 日干→비교干 이름 L1**과 위의 流年 일반 방법 L2-M을 **현대 연구자가 결합할 경우** `甲일간×해당 유년 천간→해당 역사 십신 이름`이라는 **조건부 계산 추론 L2-D**을 만들 수 있는가?
- **H3 고전 명명/제품 권한:** H2가 성립하더라도 그 명칭이 *해당 역사 저술의 실제 개별 流年에서 직접 쓰였다*, *모든 학파에서 같은 명칭이었다*, *현대 개인의 직업·부·관계 이벤트를 예측한다*는 세 개의 **다른 명제**를 입증하는가?

**판정:** H1 = **문헌에 일반 방법 근거 존재, 적용 범위 한정 PASS**. H2 = **연구용 조건부 추론 구성 가능(7/8 관계만 L1 독립 이름 확인), 소스 사이 가교 정당화는 미승인**. H3 = **직접사용례와 제품 승격 모두 일반규칙만으로 불가**.

### 핵심 오류 방지

- **명제 M1과 M1b는 다른 판본·전사 모달리티.** 전사에서 추가 확인한 두 번째 문장을 기존 明刻의 `p2` 이미지에 있었다고 문서화하지 않는다.
- **L2-M은 명칭을 계산할 때 비교할 천간의 역할을 시사**할 뿐, 年支·藏干·用神·格局·大運 등 전통적 吉凶 판단에 쓰이는 다른 구성요소를 배제하지 않는다.
- 고전 사상 내의 *분류 기법*에 대한 서술이지, 사주 풀이가 현실 사건을 실제로 예측한다는 과학적 효력의 증거가 아니다.

## 3. L2-D 도출에 필요한 전제 계약 (제안)

```text
입력
  natalDayStem = 甲     // 인쇄 원전에서 日干이 甲임이 확정
  annualStem = X        // 실제 해당 유년의 年干; 出生年柱/大運/時干 아님
  L1(X)               // 甲에 대한 X의 역사 十神 이름, 인쇄 단독명 확인
  M                   // 流年 天干과 日干의 관계를 비교한다는 문헌 근거
  schemeCompatibility  // 학파·연대·陰陽/生剋 대응이 본 주장에서 호환됨을 증빙
출력
  derivedTenGodLabelCandidate = L1(X)
  evidenceKind = L2_D_CONDITIONAL_NOT_DIRECT
  directPrintedAnnualCaseVerified = false  // 별도의 L2-C 없을 경우
  productAuthority = NONE
```

`schemeCompatibility`가 불명·미증명일 경우 `L2-D`는 **방법론적 가설로만 유지**한다. 단순 `L1+M`의 형식적 조합을 해당 출판본에 실제 연간명칭이 존재했다는 역사적 증명으로 사용하지 않는다. 아래 표의 `조건부 연구 도출 가능`은 인쇄 직접 사례 L2-C나 Product PASS가 아니다.
