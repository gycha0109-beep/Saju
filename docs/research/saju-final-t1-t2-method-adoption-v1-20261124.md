- 결정일: 2026-11-24
- 적용 범위: 여섯 메뉴 공통 원국 판단의 연구·Reader 경로
- 근거: 기존 I18~I25 구현 및 R034/R035/R139, 강약 방법론 검토 v2
- 상태: **내부 방법 채택 — 비수치·다중 근거·판정 준비도 방식**
- Official / Production 승격: 이 문서에서 다루지 않음

## 1. 결정 요약

명하의 T1/T2는 오행 개수나 한 개의 강약 점수로 원국을 분류하지 않는다.

- T1은 계절·월령, 천간·지지·지장간, 독립 통근, 지원·제약, 구조 관계를 각각 보존하는 구조 균형 근거로 채택한다.
- T2는 得時/失時와 黨眾/助寡를 서로 다른 판단 축으로 보존한다. 한 축의 결과를 다른 축으로 대체하지 않는다.
- T2의 최종 신강·신약은 현재 하나로 확정하지 않는다. I23 v2의 결정적 준비도 그래프를 이용해 입력 불확정, 특수격 검토, 방법론 미해결 사유를 구분한다.
- 숫자 점수, 가중치 합산, 반복 근거의 개수 합산, 자동 강약 라벨은 채택하지 않는다.

## 2. T1 — 구조 균형

### 채택하는 입력과 관측

| 근거 | 채택 방식 | 제한 |
|---|---|---|
| 계절·월령 | 월지 오행과 일간의 생·극 관계, 계절 旺相休囚死 관측 | 월령 하나로 최종 강약을 결정하지 않음 |
| 천간 투간 | 실제 드러난 글자·위치·십신을 보존 | 투간 개수로 우세를 계산하지 않음 |
| 지지 대표 십신 | 각 지지의 대표 십신을 천간 채널과 분리해 보존 | 지지 대표 십신을 지장간 전체와 동일시하지 않음 |
| 지장간 | 각 지지 내부 글자와 십신을 별도 채널로 보존 | 배열 순서로 본기·중기·여기를 일반화하지 않음 |
| 통근·뿌리 | source-bounded root class 및 실제 위치를 보존 | 뿌리 존재를 곧바로 강한 뿌리·지원 효과로 치환하지 않음 |
| 지원·제약 | 비겁·인성의 지원 후보와 식상·재성·관성의 제약 메커니즘을 구분 | 동일한 음수/양수 단위로 합산하지 않음 |
| 합·충·형·파·해·회합 | 실제 참여 위치와 관계 종류를 보존 | 관계가 존재한다는 사실만으로 뿌리 파괴·보존·합화·구응을 확정하지 않음 |

### 채택한 처리 원칙

1. 동일 명식에서 서로 다른 근거 채널은 독립적으로 남긴다.
2. 월령의 복수 신호는 하나의 대표값으로 강제 축약하지 않는다.
3. 근거의 위치·관계·출처가 다르면 구분하고, 단순히 같은 계열의 반복이라는 이유로 힘을 더하지 않는다.
4. 서로 비교할 근거가 아닌 경우에는 부분 순서와 비교 불가 상태를 유지한다.
5. 구조 관계의 효과가 미확정이면 해당 효과만 보류하고, 이미 확인된 다른 근거는 유지한다.

## 3. T2 — 일간 강약

### 분리해서 보존할 두 축

| 축 | 의미 | 현재 채택 범위 |
|---|---|---|
| 得時 / 失時 | 계절·월령의 환경 | 월령과 계절 단계의 관측 근거 |
| 黨眾 / 助寡 | 일간을 돕는 동류·인성 및 뿌리 구성 | 근거 구성요소와 제한된 비교 관계 |

두 축은 함께 검토하지만 서로 같은 값이 아니다. 得時라고 반드시 强이 되는 것도 아니고, 失時라고 반드시 弱이 되는 것도 아니다.

### 지원 근거의 부분 비교

현재 I21이 허용하는 부분 순서는 일간의 동류 뿌리·비겁 지원 범위에만 적용한다.

- 강한 출생·록·왕 뿌리 후보 > 묘고·여기 잔여 뿌리 후보 > 천간에 드러난 비겁 지원
- 이 순서는 해당 지원 종류의 제한된 비교다.
- 인성 지원, 토 뿌리, 관계 이후 뿌리 상태, 반복 횟수에는 전역 우선순위를 확장하지 않는다.
- 반복된 같은 근거를 합산하지 않는다.

### 최종 강약을 보류하는 조건

현재 I23 v2는 다음을 결정적 보류 사유로 유지한다.

- 입력 또는 출생 시나리오 미확정
- 특수격·종격·화격 검토 신호
- 합충 등 관계 이후 뿌리 효과 미해결
- 비교할 수 없는 지원 근거의 공존
- 인성 지원 효과 및 우선순위 미해결
- 토 뿌리 분류 미해결
- 구응 효과 미해결
- 식상·재성·관성 제약 작용의 효과 및 상호작용 미해결
- 강약 분류 방법 자체의 미승인

따라서 현재 T2의 실행 결과는 다음 세 가지 준비 상태 중 하나로 끝난다.

- 입력 미확정 → 해당 명식/시나리오 판단 중지
- 특수격 신호 → 별도 특수격 검토로 전달
- 그 외 → 방법론 미해결 사유를 남기고 최종 강약 판정 중지

이는 사용자를 위한 최종 사주 결론이 아니라, 현재 계산 근거로 어디까지 판단할 수 있는지를 관리하는 내부 규칙이다.

## 4. 반드시 금지할 계산

- 오행 개수 합산으로 강약 산출
- 지원 개수 - 제약 개수로 강약 산출
- 월령만으로 신강·신약 확정
- 모든 지장간에 같은 가중치 적용
- 통근 개수·반복 횟수로 강도 산출
- 합·충 존재만으로 뿌리 파괴·보존·강화·합화 확정
- 인성·비겁·식상·재성·관성을 하나의 가산·감산 점수로 환산
- 미확정 용신·희기·격국을 강약 결과의 숨은 입력으로 사용
- LLM이 신강·신약 또는 용신을 새로 판정
