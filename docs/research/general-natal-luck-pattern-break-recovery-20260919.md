## Case families

### C1 — luck exposes a damaging natal hidden relation
丁生辰月、透壬用官; luck exposing 戊 can make the hidden 傷官 operative and harm the 官 relation.

### C2 — natal rescue protects against apparent break
For the same family, if natal 甲 is present, the source gives an example of the apparent harmful luck becoming non-harmful because 印 protects 官.

### C3 — luck meeting changes structure, natal counterforce blocks it
壬生亥月、透己用官; 卯未 luck can complete a wood meeting and change the 建祿 configuration. Natal 申酉 / 庚辛 can counter-clash so the meeting/change does not settle.

### C4 — apparent completion can still be unfavorable
`逢成格而不喜`: a luck-supplied 官 can be immediately attacked or can bind away the natal useful relation.

### C5 — apparent change can be non-harmful
`逢變格而不忌`: natal rescue can prevent the apparent structural change from becoming harmful.

## Boundary

Break/recovery is not a two-state global toggle. It requires:
- natal structure;
- exact luck interaction;
- rescue/blocking material;
- sufficiency/settlement evaluation.
