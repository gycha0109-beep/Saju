# 관계 비교: 기존 연구 재사용과 확인된 방법론 공백 (2026-11-11)

> 범위: 2026-11-06 승인된 '두 사람의 관계 보기'를 위한 **연구 보강**. 연구용 후보는 공식 T10이나 판매 허가가 아니다. 기존 Saju 해석 품질 7단계 로드맵의 별도 완료 선언으로 사용하지 않는다.
> 구현 위치: Saju PR #2763 `feat/saju-cross-chart-structural-evidence-20261109`. 구매·권한 연동은 별도 MyeongHa PR #3174이며 해당 경로를 수정하지 않았다.

## 추가 확인한 동일 논문의 근거 — 이번 구현

- **자료**: 남기동·김만태(2018), 「한국사회 이혼현상에 따른 부부궁합의 명리학적 고찰」, *인문사회 21* 9(2), 105–116, DOI 10.22143/HSS21.9.2.9. [KCI 논문·초록](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002338687).
- **확인된 텍스트 수준**: KCI **초록**. 이 논문은 이별한 부부 사례를 분석했으며, 일간과 일지의 오행이 같은 **간여지동(干與支同)**을 배우자궁 관련 관찰 요소로 언급한다. 논문이 명시하는 배우자성(남편 재성·아내 관성) 관련 약함은 원국 성별·강약 계산 계약이 추가로 필요하므로 이번에 구현하지 않는다.
- **실제 코드**: `src/research/compatibility-marital-palace-intra-chart-research.ts`는 각 Canonical 명식의 **일간 오행과 일지 오행이 같은지**만 관찰하고 두 명식을 독립적으로 보존한다. `compatibility-two-birth-research-runtime.ts`의 기존 명시적 `candidateScope` 연구 요청에서만 이 관찰을 내부 반환한다.
- **결과의 한계**: 간여지동은 **한 사람의 원국** 요소다. 두 사람 간 합충이나 궁합 판정이 아니다. 논문 초록은 인구집단에 일반화한 인과적 미래 예측을 입증하지 않는다. 현재 구현은 '이혼', '배우자 불안정', '잘 맞는다' 같은 결과를 생성하지 않는다.
- **추가 확인 필요**: 논문 본문의 표본·방법·반례·가중치, 해로 부부와의 대조, 고전별 간여지동 적용 차이. 초록만 확인한 상태에서 조건·강약 기준을 지어내지 않는다.

## 정확히 남은 T10 연구 공백

1. **직접적인 두 명식 종합판정 방법론**: R068/R069/R070의 개별 원국 Claim을 두 사람 T10으로 전환할 수 있는 규칙과 출처가 없다. `family-pair-source-scope-handoff.ts`의 `EXACT_CROSS_CHART_T10_RULE_WITH_DIRECT_PAIRWISE_SOURCE_NOT_ESTABLISHED`는 유지한다.
2. **여러 요인의 상충 조정**: 일지 육합과 다른 위치의 충, 각자의 원국 관계 해석이 상반될 때 우선순위·강약·적용 관계 유형을 결정할 출처 규칙이 없다. `TWO_PERSON_METHOD_CONTEXT_AND_CONFLICT_SETTLEMENT_NOT_ESTABLISHED` 유지.
3. **관계 유형 확장**: 부부 사례 중심 문헌을 연인·가족·동료·친구 전반으로 넓힐 근거가 없다. 서비스의 관계 유형 입력은 명리 권위가 아니다.
4. **음성 근거의 해석**: 일지 육합·충 요인이 없다는 것은 '관계가 좋다/나쁘다'가 아니라, **해당 문헌에 연결 가능한 관찰 요인이 없음**이다.
5. **원국 배우자성 약함의 정의**: 논문 초록의 재성·관성 약함은 명시적 강약·시대·성별 조건이 필요하다. 기존 T5 십신 존재만으로 '약하다'를 주장하지 않는다.
6. **개인별 검증**: 실제 두 명식의 역할 반전, 출생시각 미상, 원국 요소가 상충하는 경우를 연구 후보 수준에서 검증. 연구 후보를 고객 결과로 승격하지 않는다.

## 구현·검증 범위와 다음 단계

- **구현함**: 두 명식 각각의 일간/일지 오행 동일성 관찰과 정확한 계산 해시·명식 결속; 기존 연구 opt-in만 사용; 원래 소비자 Preview HTML 불변. 실명/운영 데이터 불필요.
- **테스트 추가**: 실제 Canonical 계산의 원본 요소값 일치, 독립 참조, 미상 시각, 기존 Preview 불변, T10/공개/판매 권한 불허.
- **미수행**: 새 T10 Rule/Claim·공식 판독 발급, 판매/운영 변경, 유료 API, 500명 새 감사. CI 최종 통과 확인은 별도.
- **다음 조사**: 기존 원전/논문의 비교 **방법**을 실제 문구 단위로 검토하고 ① 두 사람 직접 규칙 ② 상충 우선순위 ③ 관계 유형 적용 범위를 각각 출처와 독립 검증에 결속한다. 인정 근거 없는 빈칸은 남긴다.

## 문헌 탐색 참고(아직 해석 근거로 미승격)
