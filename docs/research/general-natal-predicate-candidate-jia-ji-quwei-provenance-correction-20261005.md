# R186 — 甲己 direct-rule provenance를 曲炜 《四柱详真》으로 교정

> 날짜: 2026-10-05  
> 상태: 연구 완료 후보  
> 트랙: saju-research

## 목적

R185는 동일 문구군을 최소 2011-10-06 宋坤 명의 공개 표면까지 추적했다.

R186에서는 그보다 앞선 named-work 후보가 발견되어 chronology를 교정한다.

## 1. 더 이른 저작 후보

공개 PDF/OCR 표면의 曲炜 《四柱详真》에는 다음 문구군이 존재한다.

    若合而不化，就以正常的生克论
    例甲与己合而不化，以甲木合克己土来论
    甲还是原来的甲，己还是原来的己
    甲己也因合双方均减力，合为绊住
    自身生克权受到制约

이는 R184/R185에서 추적한 direct-rule family와 실질적으로 동일한 핵심 구조다.

## 2. 연대

曲炜 공식 저자 이력은 2001년에:

    《四柱详真》
    《六爻详真》

이 면세했다고 서술한다.

따라서 현재 조사 범위에서 chronology는:

    2001 曲炜《四柱详真》 work candidate
      ↓
    2011-10-06 宋坤 attributed web/index surface
      ↓
    2019/2021 이후 재게시 표면

으로 수정된다.

단, 아래는 아직 확정하지 않는다.

    2001 = 이 규칙의 최초 창안 시점
    曲炜 = 이 규칙의 최초 창안자
    宋坤 2011 = 曲炜 저작의 직접 복제

## 3. PDF/OCR 권한 경계

공개 색인 표면은 《四柱详真》의 해당 문구를 보여주며,
다른 PDF 색인에서는 page label 50 / total 118 같은 locator도 관찰된다.

그러나 PDF 원본의 page screenshot 접근은 실패했다.

따라서:

    indexed text = yes
    indexed page locator candidate = yes
    physical visual page binding = no
    printed page binding = no

이다.

R186은 이 locator를 실물 page 50으로 승격하지 않는다.

## 4. R185 재분류

R185의 宋坤 2011 표면은 삭제하지 않는다.

관찰 사실:

- 宋坤 표시
- 2011-10-06 표시
- 동일/근접 direct-rule family

는 그대로 유지한다.

다만 status는:

    earliest attributable candidate

에서

    later attributable transmission candidate

로 내려간다.

그 두 표면의 직접 복제 계보는 아직 미확정이다.

## 5. direct non-day-master 사례는 여전히 별도 문제

Read01에서 확보한:

    日元 = 庚
    甲 / 己 both non-day-master
    甲己相合
    甲 = 克 위치
    己 = 被克 위치

사례의 원출전은 이번 교정으로 해결되지 않는다.

《四柱详真》의 direct-rule provenance가 더 이르다는 사실만으로
그 사례가 같은 출전이라고 볼 수 없다.
