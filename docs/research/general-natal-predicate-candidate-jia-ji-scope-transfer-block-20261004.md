# R178 — 甲己 비일간 오합의 scope-transfer 차단 라우팅

> 날짜: 2026-10-04
> 상태: 연구 완료 후보
> 트랙: saju-research

## 목적

R177은 壬 일간 사례의 甲–己 쌍에 두 관계 표면이 동시에 있음을 확인했다.

    甲(木)剋己(土)
    甲己合 구조 후보

R178은 이 오합 후보에 기존 I42/I76의 결과 범위 제한을 적용한다.

## exact pair

대상 구성:

- 일간: 壬
- 조합 참여 천간: 甲 / 己
- 甲 != 壬
- 己 != 壬

즉 조합 참여 두 천간 모두 일간이 아니다.

## I42의 기존 범위 제한

I42는 전통 化氣 결과 계약의 직접 적용 범위를 다음처럼 제한한다.

핵심 근거는 《三命通會》의:

    大凡化氣，只取日干而言配合之神

이라는 scope다.

현재 저장소의 해석은 다음과 같다.

- 전통 化氣 결과 주체는 일간 중심
- 비일간 challenge-target stem에 일간 化氣 결과를 직접 전이할 수 없음
- 비일간 천간의 transformed element를 자동 방출할 수 없음
- scope transfer 차단을 "변화 없음"으로 해석할 수도 없음
- generic binding verdict도 별도 근거 없이 전이할 수 없음

따라서 壬 일간의 甲–己에:

    甲己合이므로 化土

를 바로 적용할 수 없다.

## I76 stem-five route

I76의 stem_five_combination 정책은:

    STRUCTURAL_INTERACTION_ONLY_SCOPE_TRANSFER_BLOCKED

상태다.

허용되는 것은 구조 관계 후보의 보존이다.

허용되지 않는 것은:

- transformation outcome
- binding verdict
- direct interaction outcome
- no-effect conclusion
- post-combination subject replacement

이다.

## R178 판정

甲己의 구조 오합 후보는 유지한다.

그러나 pair-local 결과는 모두 미결정이다.

    transformation = not_determined
    binding = not_determined
    interaction outcome = not_determined
    neutralization = not_determined
    no effect = not_determined
    post-combination subject identity = not_determined

R177의 木剋土 표면도 동시에 유지한다.

즉 현재 상태는:

    剋 표면 있음
    合 구조 후보 있음
    合 결과 미결정
    剋/合 settlement 미결정

이다.

## 중요한 금지

다음 등식은 모두 금지한다.

    甲己合 구조 후보 = 甲己化土
    일간 化氣 규칙 = 비일간 pair 결과
    化氣 scope 차단 = 아무 효과 없음
    化氣 scope 차단 = 합이 안 됨
    구조 조합 존재 = binding
    구조 조합 존재 = transformation
    scope 차단 = 剋 승리
    scope 차단 = 合 승리

## 다음 연구

다음 단계는 generic 化氣 문헌을 더 수집하는 것이 아니다.

필요한 것은 비일간 천간 오합의 실제 interaction effect에 대한
source-bounded 근거다.

특히 甲–己에 대해:

1. 비일간 甲己가 함께 있을 때 실제로 어떤 상호작용을 한다고 기술하는가
2. binding / non-binding을 구분할 근거가 있는가
3. 합 이후 두 천간의 기능을 어떻게 취급하는가
4. 木剋土 관계와 合이 함께 있을 때 둘을 어떻게 공존시키는가
5. pair-local outcome이 먼저 확정된 뒤에야 cross-relation precedence를 논할 수 있는가

이 다섯 항목이 다음 근거 frontier다.
