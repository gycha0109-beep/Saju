# R157 — Temporal Trigger-Matching Provenance Boundary Corpus

> Date: 2026-09-29  
> Status: RESEARCH COMPLETE CANDIDATE  
> Scope: temporal trigger classes vs executable trigger-matching predicates  
> Track: saju-research

## 1. Research question

R156 separated duration and expiry from temporal semantic authority.

The next unresolved frontier is trigger matching.

Existing source assets already contain several trigger-shaped observations:

- transparency / exposure;
- natal–luck meeting;
- meeting or clash participating in structural change;
- break trigger;
- natal rescue;
- counterforce blocking change.

But those observations do not automatically supply executable predicates.

R157 asks:

> Which temporal trigger classes can be preserved as research observations without converting them into runtime trigger resolvers?

## 2. Core distinction

R157 enforces:

    trigger class observation
    != trigger predicate authority
    != runtime activation fact
    != event authority

A source can describe a trigger-shaped mechanism without authorizing a generic engine rule.

## 4. R073 activation trigger gap

R073 explicitly retains:

    ACTIVATION_TRIGGER_MATCHING

as an execution gap.

Therefore the states:

- ACTIVATED_BY_TRANSPARENCY
- ACTIVATED_BY_NATAL_LUCK_MEETING

can be preserved as trigger classes, but not as universal matching predicates.

R157 keeps:

    triggerPredicateAuthorized = false
    executableTriggerResolverAuthorized = false

## 5. R072 interaction matching gap

R072 explicitly retains:

    LUCK_TO_NATAL_INTERACTION_MATCHING
    CHANGE_SUFFICIENCY

as unresolved.

Therefore a source class such as:

    運可因會合或沖而使格局變換

supports a structural-change trigger class only.

It does not authorize:

    ANY_MEETING_OR_CLASH_CAUSES_STRUCTURAL_CHANGE

## 6. R076 break / rescue / counterforce gaps

R076 retains configuration-specific cases while leaving unresolved:

- BREAK_TRIGGER_MATCHING
- RESCUE_TRIGGER_MATCHING
- COUNTERFORCE_PRECEDENCE
- CHANGE_SETTLEMENT

R157 preserves three separate trigger classes:

- break;
- rescue;
- counterforce.

It does not create a global break/recovery toggle.

## 7. Hidden-stem activation provenance guard

R146 establishes several critical separations:

- hidden membership != activation;
- manifestation != activation;
- configuration interaction != per-member activation;
- source-bounded interaction != runtime activation;
- temporary operative state != permanent natal mutation.

R157 therefore does not emit runtime activation facts.

It also keeps false:

    perMemberActivationResolverAuthorized
    effectiveForceAuthorized
    fixedPolarityAuthorized
    concreteEventAuthorized

## 8. Trigger matching is separate from duration

R156 established that:

- generic activation duration remains unresolved;
- break/rescue duration remains unresolved;
- the source-bounded five-year observation cannot be generalized.

R157 therefore rejects:

    TRIGGER_MATCHING_INHERITS_R073_FIVE_YEAR_DURATION

A trigger predicate and a duration policy are separate authorities.

## 9. Rejected shortcuts

R157 explicitly rejects:

- transparency always activates every hidden member;
- natal–luck meeting always activates every hidden member;
- any meeting or clash causes structural change;
- one break case generalizes to all similar symbols;
- one rescue symbol always rescues;
- counterforce presence always blocks change;
- interaction presence equals runtime activation;
- hidden membership equals trigger match;
- trigger class equals executable predicate;
- trigger match equals fixed polarity;
- trigger match equals concrete event;
- trigger count as severity;
- trigger score as numeric weight;
- trigger matching inherits the R073 five-year duration;
- trigger matching as InterpretationClaim authority.

## 10. What R157 establishes

R157 establishes only that:

- multiple trigger classes are source/provenance-observable;
- those trigger classes remain distinct;
- the corresponding matching gaps remain explicit;
- generic interaction activation remains rejected;
- trigger matching remains distinct from runtime activation;
- trigger matching remains distinct from duration.

## 11. What R157 does not establish

R157 does not authorize:

- executable trigger predicates;
- per-member hidden-stem activation;
- automatic structural change;
- automatic break;
- automatic rescue;
- automatic counterforce;
- fixed polarity;
- deterministic events;
- numeric trigger scores;
- InterpretationClaim emission;
- engine admission;
- production authority.
