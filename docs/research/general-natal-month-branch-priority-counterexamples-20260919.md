## Research result

"월령이 중요하다"를 하나의 보편 규칙으로 만들면 안 된다.

The current evidence separates at least four claims:

```text
A. month branch / month command is an important chart context
B. month branch is especially weighty inside Tonggen
C. month command is the exclusive authority for the whole chart
D. month branch has a numeric multiplier
```

Current disposition:

```text
A = SUPPORTED_BOUNDED
B = SUPPORTED_BOUNDED
C = REJECTED_AS_OVERGENERALIZATION
D = UNSUPPORTED
```

## 子平真詮 / 子平真詮評註

Selected review surface:

https://www.ncc.com.tw/fate/paleo/bg/bg_032.htm

The later commentary says:

```text
通根之中，尤以月令之支為最重也
```

The scope marker `通根之中` is retained as part of the proposition. The artifact therefore does not rewrite the statement as "the month branch always overrides every other chart fact."

The same passage supplies no numeric coefficient.

## 淵海子平 counterexample boundary

Directly indexed scan-text surface:

https://upload.wikimedia.org/wikipedia/commons/1/11/NLC416-15jh007754-99036_%E6%B7%B5%E6%B5%B7%E5%AD%90%E5%B9%B3_%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE.pdf

The bounded sequence includes:

```text
以日為主，年為本，月為提綱，時為輔佐
後看月令中金木水火土何者旺
此非是拘之一隅之說也
論命者切不可泥之月令消詳
```

Independent transcription cross-check:

https://www.donglishuzhai.net/chapter/12812.html

The passage explicitly tells the reader to examine the rest of the chart and not rigidly adhere to month-command examination. That is a counterexample to **exclusive/rigid** month-command authority.

It does not contradict the narrower Ziping-commentary proposition about positional priority **inside Tonggen**. The scopes differ.

## Why this matters

The following inference is forbidden:

```text
month branch is important
+ month branch is heaviest inside Tonggen
=> assign month branch a universal numeric multiplier
=> month branch always wins every root comparison
=> final strong/weak result
```

No source reviewed here supplies that chain.

## Source-stratum boundary

The Ziping priority sentence used here is from the later commentary surface and must not be silently attributed to the base text.

The Yuanhai indexed PDF surface is stronger than an unpinned web paraphrase, but this workbench still marks glyph-exact direct-visual closure as open. Search/index extraction is not substituted for visual inspection when an exact-glyph claim is promoted.
