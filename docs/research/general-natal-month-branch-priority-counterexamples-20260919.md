# R012 — Month-branch priority claims and counterexamples

Date: 2026-09-22  
Issue: #937  
Status: VERIFIED BOUNDED / DIRECT-VISUAL YUANHAI CLOSURE COMPLETE

## Research result

"month branch / month command is important" must not be normalized into a universal override rule.

The evidence supports four separate propositions:

```text
A. month branch / month command is an important chart context
B. month branch is especially weighty inside Tonggen
C. month command is the exclusive authority for the whole chart
D. month branch has a numeric multiplier
```

Disposition:

```text
A = SUPPORTED_BOUNDED
B = SUPPORTED_BOUNDED
C = REJECTED_AS_OVERGENERALIZATION
D = UNSUPPORTED
```
