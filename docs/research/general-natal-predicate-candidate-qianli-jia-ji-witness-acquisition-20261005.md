# R181 — 《千里命稿》 甲己 비일간 witness 후보 취득

> 날짜: 2026-10-05  
> 상태: 연구 완료 후보  
> 트랙: saju-research

## 목적

R180의 결론은 명확했다.

현재 저장소는 甲己 pair-local outcome을 위한 구조 substrate와 governance는 충분하지만,
normative source authority는 0/6이다.

R181은 외부 source discovery를 실제로 시작하고,
1935년 韋千里 《千里命稿》에서 발견된 비일간 甲己 문장을
검증 가능한 후보 자산으로 결속한다.

## 물리 출판물 후보

공개된 National Library of China 스캔 메타데이터:

- 서명: 《千里命稿》
- 저자: 韋千里
- 발행: 韋氏命苑
- 발행연도: 民國24 [1935]
- NLC file id: `NLC416-01jh000372-10197`
- 공개 PDF: 123 pages
- catalog carrier: 116頁

이 단계에서 physical edition identity는 결속한다.

그러나 목표 문장이 실린 정확한 스캔 페이지는 아직 직접 시각 검증하지 못했다.

따라서:

    physical edition identity = bound
    target page visual verification = incomplete
    target printed page = unbound
    primary target surface = unbound
    normative authority = not acquired

## 핵심 문장 후보

공개 전사본들은 「干合而化」에서 다음 두 표면을 일관되게 보고한다.

### 비일간 甲己 원국

    若甲年己月，只合而不化也

이 문장은 적어도 후보 수준에서는:

    甲/己 = 合 표면 존재
    非日干 pair = 不化

를 동시에 표현한다.

중요한 제한:

    不化 != 無效
    不化 != generic 羈絆 확정
    不化 != 주체 소멸
    不化 != 剋/合 precedence

### 비甲 일간 + 甲 원국 + 己 운/세운

    若日干非甲，他干有一甲者，逢一己運己歲，尤不能化

이 문장은 R172의 壬 일간 + natal 甲 + luck 己 문맥과 매우 가깝다.

다만 현재 단계에서는:

- 《子平真詮》 사례와 동일 명식이라는 뜻이 아님
- 回剋을 설명하는 문장도 아님
- 合의 실제 기능 효과를 확정하는 문장도 아님

따라서 직접적인 outcome settlement로 승격하지 않는다.

## 「干克干合並見」 후보

같은 《千里命稿》의 별도 절은 천간에서 克과 合이 함께 나타날 때
다음 조건을 비교한다.

- 地位
- 主克 / 受克
- 勢力

그리고 사례별로 合을 취하거나 克을 취하는 방향을 기술한다.

그러나 현 공개 전사에서 제시되는 예시는 乙庚 계열이며,
R177의 exact 甲己 pair를 직접 판정하지 않는다.

따라서 R181에서 이 표면은:

    generic method candidate = yes
    exact Jia-Ji settlement = no
    direct transfer = forbidden

으로 둔다.

## R179/R180 요구조건 재평가

| 요구조건 | R181 진전 | 현재 상태 |
|---|---|---|
| exact non-day-master 甲己 interaction source | exact 문장 후보 발견 | 실물 목표 페이지 미결속 |
| 克/合 coexistence semantics | generic 방법론 후보 발견 | exact 甲己 근거 아님 |
| binding/non-binding | 只合而不化 문장 후보 | 不化와 binding 의미 분리 필요 |
| post-combination identity | 신규 근거 없음 | open |
| context/exception conditions | 時令·賓主·明暗·地位·歲運 후보 | exact 충분조건 아님 |
| pair-local vs cross-relation precedence | 신규 전통 근거 없음 | repository governance만 유지 |

따라서 normative authority 충족은 여전히 0/6이다.
