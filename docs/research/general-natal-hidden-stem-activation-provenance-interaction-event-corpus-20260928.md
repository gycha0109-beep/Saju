# R146 — Hidden-stem activation provenance under interaction events

Date: 2026-09-28  
Track: saju-research  
Status: research-only

## Purpose

R146 freezes provenance boundaries around hidden-stem activation language.

It does not decide that a hidden stem is active.

Instead, it separates:

1. hidden membership
2. manifestation / tou-gan
3. branch interaction or configuration
4. source-bounded activation language
5. temporary operative state
6. contest topology
7. unresolved evidence gaps
8. runtime activation authority

The final layer remains closed.

## R060 mechanism boundary

R060 already distinguishes:

- hidden membership
- stem manifestation / tou-gan
- branch meeting configuration
- clash movement or disruption

R146 preserves those mechanisms as separate provenance states.

It explicitly rejects:

- hidden membership implies activation
- clash reveals all hidden stems
- clash equals tou-gan
- meeting activates every hidden stem independently

## R073 temporal boundary

R073 preserves latent, transparency-linked, natal-luck meeting, temporary operative, and position-modulated states.

R146 keeps temporal activation language non-executable.

In particular:

- activation does not permanently mutate the natal chart
- activation does not guarantee a concrete event
- temporary operative state does not persist after the bounded context by default

The transparency case also preserves the exact 寅 source observation that a transparent 丙 may 作主 when 甲 is not transparent.

That observation is bounded to the exact source context and does not authorize a generalized all-branch role selector.
