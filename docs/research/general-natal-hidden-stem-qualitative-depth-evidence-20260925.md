## 1. Research question

R123 audits whether hidden-stem evidence supports a single semantic depth hierarchy or numeric weight model.

The reviewed evidence does not support this shortcut:

```text
hidden-stem membership/order
-> main / secondary / residual semantic depth
-> numeric strength weight
```

Instead, the governed corpus separates multiple qualitative dimensions.

## 2. Evidence dimensions

```text
membership
exact role
transparency substitution
temporal command
temporal variability
qualitative root-class language
interaction state
```

These dimensions must remain distinct unless a source explicitly binds them.

## 3. Hidden-stem membership is not semantic rank

The canonical calculation layer exposes branch-to-hidden-stem membership.

Its source is the classical 又地支藏遁歌 surface, but the repository explicitly canonicalizes the arrays into a deterministic stem storage order.

Therefore:

```text
hiddenStems[0]
!= primary hidden stem
!= 本氣
!= strongest hidden stem
```

Array order is storage only.

## 4. Exact 寅 evidence: 本主

The governed 子平真詮 source chain preserves an exact 寅 example:

```text
甲 = 本主
丙 / 戊 = separately described subordinate roles
```

This is genuine qualitative role differentiation.

But the admissible inference is only:

```text
within this exact 寅 discussion
甲 has an explicit primary-role description
```

It is not:

```text
本主 = generic 本氣 category
hiddenStems[0] = 本主
all 12 branches have the same admitted three-level role table
```

## 5. Transparency can change role in the exact 寅 example

The same source says that when 甲 is not transparent while 丙 is transparent, 丙 may 作主.

This matters because it shows:

```text
static hidden membership
!= fully settled active role
```

However, this remains an exact-example observation.

It does not provide a generalized selector for every branch, every multiple-transparency state, or every interaction configuration.

## 6. Generalized all-branch mapping remains unresolved

The current governed evidence does not admit:

```text
all-branch primary hidden-stem mapping
universal 本氣 / 中氣 / 餘氣 ontology
generalized month-order hidden-stem selector
```

The exact 寅 evidence is deliberately not extrapolated.

## 7. 人元司令 timing is a separate qualitative axis

The selected later-commentary source preserves day-count sequencing for 人元司令.

The same commentary also warns against treating that table rigidly.

Therefore:

```text
temporal command sequence
!= fixed hidden-stem depth
!= exact runtime strength curve
!= numeric multiplier
```

Timing evidence is kept separate from static membership and role labels.

## 8. 餘氣 is temporally contextual

R015 already preserves selected-source variation around:

```text

vs
土旺之後
```

This supports a context-sensitive qualitative observation.

It does not support:

```text

```

## 9. Exact 辰 本氣 / 餘氣 commentary remains exact-example evidence

The selected commentary describes a bounded 辰 context using 本氣 and 餘氣 terminology.

That exact terminology is preserved, but it is not promoted into a complete twelve-branch mapping.

Therefore:

```text
one exact 辰 example
!= all-branch 本氣/中氣/餘氣 table
```

## 10. Root-class 重 / 輕 is not hidden-stem depth

R017/R020 preserve qualitative root-class language such as heavier and lighter root classes.

This is a different semantic axis from hidden-stem storage or hidden-member role.

Therefore:

```text
根之重 / 根之輕
!= hidden-stem array depth
!= numeric coefficient
```

## 11. Hidden membership is not activation

R060 already separates:

```text
hidden membership

```

R123 carries that boundary forward.

Rejected shortcuts include:

```text

clash => reveal every hidden stem
meeting => activate each hidden stem independently
```
