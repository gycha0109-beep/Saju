## 2. 실제 엔진에서 재사용하는 근거

- **계산**: 두 사람의 독립 `CanonicalSajuSnapshot` → 기존 `evaluatePairwiseSourceScopeV1`의 `crossChartStructuralMatches`. 각 매칭에 `kind`(천간합/육합/충), 사람별 `factPath`, 원본 값, `sourceIds`, 구조정의 해시를 보존한다.
- **연구 가능한 좁은 후보**: `buildMaritalDayBranchCandidateV1`은 **두 사람의 일지끼리** 확인된 육합/충만 문헌 후보로 취급. 본문 검토/공식 권한을 통과하지 않았다.
- **개인 원국**: `buildMaritalPalaceIntraChartResearchV1`는 각각의 **일간·일지 오행** 관찰을 보존. R069 배우자성 연구는 역사적 성별/원국 범위만 보존. 용신 상호보완 직접 방법론은 확인되지 않았다.
- **새 2단계 코드**: `src/research/compatibility-t10-coexisting-evidence-review.ts`. `src/preview/compatibility-two-birth-research-runtime.ts`의 기존 명시적 비공개 연구 요청에서만 세부 확인 자료를 반환. **새 T10 Claim, 가중치, 점수, 공식 해석, 공개 API는 추가하지 않음**.

## 3. 상충처럼 보이는 두 구조적 사실을 **분리**해서 기록

실제 명식 예시들은 모두 **합성 연구 입력(개인 사용자 데이터 아님)**이며 서울의 기존 계산 정책을 사용한다. 아래 기대치는 회귀 테스트에서 실제 `CanonicalSajuSnapshot` 계산으로 확인한다.

| 실제 계산 재현 입력(양력, 각 14:30) | 기대 구조 관찰 | 취급 |
| --- | --- | --- |
| A=1990-05-15, B=1996-06-05 | **A 일지 辰↔B 일지 酉: 육합**과 **A 연지 午↔B 연지 子: 충**이 동시에 존재 | 전자는 **일지 한정 미검토 연구 후보**, 후자는 **다른 위치의 구조적 사실**. 서로 상쇄·가산하지 않음 |
| A=1990-05-15, B=1996-08-05 | **A 일지 辰↔B 일지 戌: 충**과 **A 연지 午↔B 월지 未: 육합**이 동시에 존재 | 위와 반대 방향의 구조적 병존. 다른 위치의 육합에 임의로 관계 긍정 의미를 부여하지 않음 |
| A=1990-05-15, B=1990-05-08 | 일지 육합 가능하더라도 다른 위치의 충이 없다면 **서로 다른 관계 구조가 병존했다는 기록을 강요하지 않음** | 단일 관찰조차 전체 궁합 판단으로 승격하지 않음 |

- 일지 연구 후보의 `supportive_factor`/`challenging_factor`는 **그 한 요인에만** 속한 전통적 연구 후보 레이블이다. 다른 위치 구조의 장단점이나 실제 관계를 뜻하지 않는다.
- 모든 다른 위치의 육합·충은 계산 사실로 기록하고, 타인명식 간 해석 가능 허가를 `false`로 보존한다.
- 실제로 육합과 충이 함께 관측되어도 **그 사실은 종합판정의 모순과 동의어가 아니다**. 이는 *서로 다른 해석 범위가 병존하므로 상충 검토가 필요한 입력*이다.
- 상충 해소가 필요한 예외/맥락(원국 희신·기신/강약, 실제 관계 유형, 기간, 학파 간 차이)을 원본 소스로 증명하지 못하면 `unresolved_no_source_qualified_pairwise_precedence`로 종료한다. **일률적 우선순위와 임의 점수는 금지**.

## 4. 재현·보류·안전 조건

- `test/compatibility-t10-coexisting-evidence-review.test.ts`는 서로 다른 양력 실제 계산 입력의 두 가지 병존 방향, 비병존, 명식 역할 반전, 시각 미상, 잘못된 원본 해시, 기존 공개 Preview/HTML 불변 등을 확인한다.
- `sourceReview`에는 각 문헌을 **초록/원전 본문**으로 구분하며, 실제 규칙의 적용 범위를 자동으로 확장하지 못하도록 고정.
- `synthesis`는 항상 **근거 있는 T10 우선순위 미확립**을 표시한다. 두 사람 사건·길흉·점수·용신 상호보완을 생성하지 않는다.
- 현재 2단계 검증 성공 전에는 '테스트 통과', '우선순위 확정', '관계 비교 상품 준비 완료'를 선언하지 않는다.

## 5. 2단계 결과 판정 및 3단계로의 이관

- **구조 계산은 재사용 가능**하며, 서로 다른 위치의 육합과 충 병존을 구분하는 추적 코드를 추가했다.
- **종합 우선순위는 현재 확인한 문헌에서 미성립**. 초록과 고전 원국 문맥을 두 사람 관계 일반 규칙으로 오인하지 않는다. 향후 확인되는 직접 출처에 따라 좁은 규칙을 추가할 수 있지만, 근거를 찾을 때까지 무한 보강하지 않는다.
- 3단계에서 실제 명식쌍·출처값·입력 시각 미상 등 경계 검증과 고객 결과/보류 기준을 정리한다. **연구 범위 완료와 상용화 승격은 별도 판정**한다.
