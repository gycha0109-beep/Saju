## Core distinction

A 六合 relation must not be represented by one boolean that silently means both:

```text
binding / combination
and
transformation
```

The source surfaces preserve separate outcomes.

### Binding / conflict-resolution example

A 子丑 combination is used to resolve a 子午 clash in a rescue configuration.

This verifies that a 六合 can have a relational effect without requiring a transformation claim.

### Transformation example

A separate 寅亥 example is described as transforming toward Wood in a rescue configuration.

The transformation discussion also requires additional support beyond branch-pair presence.
