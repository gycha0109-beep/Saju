R011 / #934 is important, but it is **not** a global prerequisite for every strength-related research primitive.

The current repository already contains bounded evidence sufficient to move several narrow capabilities to Authority Bridge review without waiting for R011:

- month-branch importance without exclusivity;
- already-governed positive Tonggen observations;
- 透干 / 通根 non-equivalence;
- bounded non-Earth 墓庫 positive root evidence;
- bounded non-Earth 餘氣 positive root evidence;
- Yang 長生 positive root evidence;
- bounded 祿 / 旺 positive evidence;
- bounded 比劫 support-constituent evidence;
- 得時 / 失時 anti-deterministic strength observations.

R011 remains materially relevant to **global negative/absence Tonggen semantics**, **canonical 四柱有根 settlement**, and therefore to a future whole-chart 強弱/旺衰 classifier.

Even there:

```text
R011 closure
!= final strength classifier
```

because final strength also depends on unresolved support aggregation, Yin/Earth root gaps, methodology composition, and preserved cross-school/textual-dependency conflicts.

## 2. Why this map exists

Two failure modes must be prevented.

### Failure A — over-blocking

```text
R011 unresolved
→ no strength-related capability can advance
```

This is false. Multiple bounded positive propositions have their own source-scoped evidence and do not require a universal cross-source root definition.

### Failure B — overgeneralization

```text
many bounded root findings
→ universal Tonggen resolver
→ final 強弱 classifier
```

This is also false. Positive bounded evidence does not establish global negative absence semantics, complete 四柱有根 settlement, aggregation policy, or final methodology composition.

## 5. R011-dependent capabilities

Only three current rows require R011.

### 5.1 Global negative / absence Tonggen resolver

R013 explicitly preserves:

```text
NO_POSITIVE_TONGGEN_EVIDENCE
!=
NOT_TONGGEN
```

The repository can represent some exact negative exclusions, but one exact exclusion is not a global negative resolver.

R011 is relevant because a cross-source comparison of 根 / 有根 / 無根 / 根氣 / 通根 semantics is needed before attempting global normalization.

However, R011 is not sufficient because current canonical root-presence completeness also has Yin/Earth gaps.

### 5.2 Canonical 四柱有根 resolver

Existing bounded positive root surfaces do not cover all cases.

The repository explicitly records unresolved areas including:

- Yin 長生;
- Yin 祿;
- Earth 祿;
- Earth 餘氣;
- global negative absence semantics.

Therefore:

```text
bounded positive root set
!= complete 四柱有根 resolver
```

R011 is necessary for the generalized root-semantic boundary but cannot alone fill all remaining primitive gaps.

### 5.3 Final whole-chart 強弱 / 旺衰

A final classifier would require more than root semantics:

- canonical root presence/absence;
- support aggregation;
- opposition/drain/control context;
- methodology composition policy;
- handling of cross-school disagreement;
- explicit authority admission.

R019 and R020 already show that season alone is not final:

```text
得時 != always 旺
失時 != always 弱
```

Therefore R011 closure cannot be treated as a hidden shortcut to final strength classification.

## 6. R011-independent bounded evidence

## 7. Research gap vs Authority gap vs Engine gap

### Research gap

Current genuine research gaps include:

- global negative/absence Tonggen semantics;
- complete 四柱有根 settlement;
- Yin 長生 conflict;
- Yin/Earth 墓庫 and 祿/餘氣 completion;
- support aggregation;
- final methodology composition.

### Authority gap

Several bounded primitives already have adequate research evidence for a **bounded candidate**, but remain research-only.

Those should move next to Authority Bridge rather than being researched again:

- month-branch bounded importance;
- known positive Tonggen cases;
- 透干/通根 non-equivalence;
- bounded 墓庫/餘氣 positives;
- Yang 長生;
- bounded 祿/旺;
- bounded 比劫 support;
- 得時/失時 anti-determinism.

### Engine implementation gap

R121 deliberately records **zero current pure Engine-gap rows**.

Reason:

```text
research-supported primitive
!= Authority-admitted governed primitive
```

The generic interpretation runtime can execute governed rules and evidence, but no research-only primitive should be labeled an Engine implementation gap before Authority Bridge admits the exact bounded proposition/methodology.

After such admission, if runtime materialization is still missing, that later state becomes an Engine implementation gap.
