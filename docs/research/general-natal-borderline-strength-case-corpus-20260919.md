## Source

https://www.ncc.com.tw/fate/paleo/bg/bg_032.htm

## Why these cases

The seed corpus targets simple rules that are easy to overgeneralize:

```text
得時 => automatically strong
失時 => automatically weak
many visible peer stems => automatically strong
```

The selected source supplies counterexamples to all three simplifications.

## Cases

### spring-wood-heavy-metal

Source surface:

```text
春木 ... 干庚辛而支酉丑，無火制 ...
是以得時而不旺也
```

This is stored as a partial configuration. Missing pillars are not invented.

### autumn-wood-deep-root

Source surface:

```text
秋木雖弱，木根深而木亦強
干甲乙而支寅卯 ...
是失時不弱也
```

Again, this is partial. It is evidence against a season-only rule, not a complete natal fixture.

### 四辛卯

Commentary surface:

```text
四辛卯，金不通根，雖天元一氣，仍作弱論
```

This is retained as an exact repeated-pillar pattern.

### 四丙申

Commentary surface:

```text
四丙申，火不通根，雖天元一氣，仍作弱論
```

This is also retained as an exact repeated-pillar pattern.

## Semantic boundary

The corpus stores the source's own result phrases.

It does not normalize:

```text
得時 / 失時
旺 / 衰
強 / 弱
有根 / 通根
```

into one scalar.

The corpus is designed for later replay/falsification. It is not itself a final strength classifier.

## Next expansion

Useful additions are cases that isolate one variable at a time:

- same season, root added/removed;
- same root, opposition added/removed;
- 比劫 count changed while root remains absent;
- month-branch context changed while non-month roots remain fixed.

Those belong to corpus expansion, not to invented completions of these four historical examples.
