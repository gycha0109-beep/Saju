# 명하 개인별 연운 해석 설계 v0.1 — 원국·대운·연운 3층 근거 게이트

상태: **DESIGN ONLY / SEMANTIC AUTHORITY HOLD**  
대상: 일반 연운 (General Annual)  
기반: #2476(세 층의 계산 사실), #2473(14개 해석 후보), R139(방법론 합성 가능성), R154(시간층 충돌·순서 민감도).

## 1. 설계 목표

**연운 해석을 생성하기 전에 반드시 판단해야 할 항목과 그 근거 계약을 정의**합니다.
이번 단계에서 운세 문장을 생성하거나 기존 연구 후보의 전통 의미가 입증된 것처럼 승인하지 않습니다.

현재 연운 14개 규칙(십신 주제 10개, 지지충 긴장 해석 4개)은 모두 직접적인 현대적 의미의 근거가 부족합니다.
이는 해당 전통적 개념이 존재하지 않는다는 부재 증명이 아니며, **현재 후보 문장의 연운 범위가 직접 증명되지 않았다**는 뜻입니다.

## 2. 입력 층위 및 사실 계약

| 층위 | 사용 입력 | 허용 정보 | 금지 |
|---|---|---|---|
| 원국 | Canonical Snapshot 4주·일간 | 실제 계산된 사주 기둥과 일간 | 임의 원국 변경, 시주 보간 |
| 대운 | dayun-temporal-context | 연도 전체를 덮는 단일 대운 구간 | 두 대운 중 임의 하나 선택 |
| 연운 | 00:00 KST 입춘일 정책, E1 입춘일 근거 | 연주·십신 계산값 | 천문학적 입춘 순간이 00:00이라는 주장 |
| 층간 비교 | structural-relations | 천간 오합, 지지 육합/충의 매칭 여부 | 합화 성립, 작용 강도·결과 |
| 연구 권한 | SA-7D, R139, R154 | 근거 부족 판정 및 미해결 이유 | 무증거의 현대 의미·우선순위·월운 승인 |

3층의 9쌍 비교는 **관계 관측**입니다. 같은 쌍에서 여러 구조적 관계가 발견돼도 먼저 검사된 항목이나 나중에 계산한 항목을 승자로 삼지 않습니다.

## 3. 개인별 해석의 6개 필수 결정 슬롯

| 슬롯 | 향후 필요한 판단 | 현재 게이트 |
|---|---|---|
| **연간 십신 테마** | 특정 일간·연간 관계가 어떤 해석 의미를 갖는가 | 현대적 테마 10개 직접 근거 미확보 |
| **원국·대운·연운 합성** | 동일 관계가 개인 원국 구조 및 대운과 만나 어떤 조건에서 성립하는가 | 방법론 합성·전역 우선순위 미승인 |
| **동시 발생 관계 처리** | 합·충과 다른 조건이 함께 관측되면 무엇이 제약·예외가 되는가 | 충 의미와 복수 관계 처리 근거 부족 |
| **작용 시기 및 지속** | 어떤 기간에 의미 있는 작용이 성립·종료되는가 | 기간별 효과와 대운 교체 시점의 검증 부족 |
| **직업·재물·관계 등 생활 영역** | 어떤 영역까지 설명할 수 있는가 | 구체적 사건·결과 근거 미확보 |
| **학파·반례·예외** | 선택한 방법론의 조건·반례·상충 규칙은 무엇인가 | 학파 범위와 조건의 독립 검토 필요 |

**현재 슬롯 6/6은 RESEARCH_HOLD**입니다. 실제 해석 문장·InterpretationClaim·LLM 호출은 하지 않습니다.

## 4. 출력 계약

연구 시제품 상태는 다음 두 가지뿐입니다.

- **INPUT_UNAVAILABLE:** 입춘일 근거 없음, 대운 다중 구간, 원국 미확정 등 입력 부족. 해석 금지.
- **FACTS_READY_SEMANTICS_BLOCKED:** 세 층의 계산 사실은 확인됨. 6개 의미 게이트의 근거가 부족하여 해석 금지.

FACTS_READY는 상품 사용 승인이나 전통 해석의 정확도 보증이 아닙니다.

두 번째 상태는 다음을 보존합니다.

1. threeLayerCorpusHash, fourteenRuleDecisionHash, dayunContextId, 구조 관계 정의 해시
2. 확인된 연도·대운·원국 비교 쌍의 관계 목록과 개별 증거 해시
3. 복수 관계 공존 여부 (우열 순위는 null)
4. 6개 해석 슬롯의 미해결 근거 코드
5. 해석·모델·공식 리딩·결제·운영 금지 플래그

## 5. 검증 시나리오

1. 2026년 2월 4일 **00:00 KST** 전후 연주가 바뀌지만 대운 우선순위가 갑자기 승인되지는 않음.
2. 같은 원국에 연운↔대운 충과 연운↔원국 충이 공존해도 첫 관계가 승자가 아님.
3. 원국이 같아도 대운이 다르거나 입춘 경계 전후면 근거 해시/관측값이 달라짐.
4. 대운이 연중 교체되거나 일부 기간만 확정되면 전체 연운 합성 중단.
5. 출생 시간 등 원국 입력이 불명확하면 유리·불리한 해석을 임의 보간하지 않음.
6. 관계 관측이 0개이더라도 **'좋은 해'**로 결론 내리지 않음.
7. 연운 해석으로 월운·결제·공식 리딩 권한을 자동 부여하지 않음.

## 6. 해석의 승인 기준 — 후속 단계

규칙마다 다음 조건을 **독립적으로** 만족해야 합니다.

1. **출처:** 특정 사주 관계와 의미를 직접 지지하는 원문/학술 근거 + 위치·판본·해시 확인.
2. **학파:** 해석 방법론의 범위, 적용할 기둥과 대운·연운 층, 반대 견해를 명확히 구분.
3. **전제:** 일간·연간·원국 구조 등 필수 계산 입력과 미확정 때의 처리 명시.
4. **상호작용:** 합·충·대운 등 복수 조건에서 적용/상쇄/보류를 결정하는 근거. **기본 '연운 우선' 같은 지름길 불가.**
5. **범위:** 계산 사실 → 제한된 구조 의미 → 현실 영역 설명 → 구체적 사건이라는 의미 강도의 상한 표시.
6. **검증:** 반례·충돌·경계·불명확성 테스트, 서로 다른 학파 방법의 권한 분리, content-addressed review.
7. **권한:** 별도 Bridge/Methodology/Rule/Composition 검토와 승인 없이 연구 코드를 Engine/Official Reading/Production으로 승격 금지.

### 후속 구현 순서

**A.** 6개 슬롯별 근거 출처 및 대조 사례 수집 →  
**B.** 학파·조건별 해석 후보와 반례를 작은 원자 규칙으로 정의 →  
**C.** 원국·대운·연운 복합 상황에서 **보류가 우선**인 충돌 해결 계약 검증 →  
**D.** 승인된 원자 규칙에 한하여 사용자에게 설명 가능한 문장 생성 구조 정의 →  
**E.** 별도 권한 게이트와 상품·UX 적용 심사.

이번 PR은 **A~E를 승인하지 않고, A~E를 진행할 수 있는 입력·출력·차단 조건의 실행 가능한 설계 계약**만 추가합니다.
