## Direct source surfaces

### 淵海子平 — 論大運
`子平之法，大運看支，歲君看干`

This directly records a Dayun branch-emphasis formulation.

### Transmitted Dayun rule in the 三命 tradition
`凡行運在干，兼用地支之神，在支則棄天干之物。蓋大運重地支`

This formulation distinguishes a stem period that still consults branch influence from a branch period that can discard the stem, while explicitly stating that Dayun emphasizes the branch.

### 三命通會 卷十二
`運行十載數，上下五年分`

This directly records a ten-year / upper-lower five-year split surface.

## What is not directly settled

The selected surfaces do not by themselves justify an executable universal formula such as:
- 50% stem / 50% branch
- 30% stem / 70% branch
- first five years = stem only, second five years = branch only
- branch always completely overrides stem for all schools and contexts.

The five-year verse is preserved without silently assigning `upper = stem` and `lower = branch` unless that operational mapping is directly sourced.
