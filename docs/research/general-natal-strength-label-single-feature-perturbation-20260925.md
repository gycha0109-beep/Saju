# R127 — Strength-label instability under single-feature perturbation

Date: 2026-09-25
Issue: #1536
Track: saju-research
Status: RESEARCH SINGLE-FEATURE STRENGTH-LABEL INSTABILITY AUDIT COMPLETE

## 1. Research question

R127 asks whether a day-master strength label can safely be changed, preserved, or inferred when one strength-relevant feature is perturbed.

The strongest supported boundary is:

~~~text
one feature changed
!= opposite label proven
~~~

The corpus keeps direct source labels separate from synthetic counterfactuals.

## 2. Corpus

~~~text
cases             = 24
comparison groups = 12
~~~

Coverage includes season, root presence/quality/position, Yuqi timing, Yin/Yang source-policy divergence, hidden-stem transparency, support-family swap, support multiplicity, output presence, relation-chain mediation, challenging-family swap, and wealth-capacity remedy.

## 3. Direct source-label anchors

R127 preserves source labels only where the source actually gives them:

~~~text
得時而不旺
失時而不弱
四辛卯 ... 仍作弱論
四丙申 ... 仍作弱論
比印重疊 + rooted support ... 不弱
財多身弱
~~~

These are source anchors, not reusable classifier outputs.

## 4. No exact one-feature opposite-label pair

The reviewed corpus does not provide an exact pair where only one feature changes and both sides receive opposite strength labels.

~~~text
exact single-feature opposite-label pair
= NOT ESTABLISHED

exact single-feature label flip
= NOT ESTABLISHED
~~~

Therefore a label on one side cannot be copied or inverted into the missing counterfactual.

## 5. Season perturbation

得時 can coexist with 不旺, and 失時 can coexist with 不弱 in the reviewed bounded examples.

Therefore neither 得時 => 旺 nor 失時 => 弱 is an authorized one-feature classifier.

## 6. Root-presence perturbation

Exact source seeds preserve 四辛卯 and 四丙申 as weak when repeated visible peers lack root.

R127 probes adding one applicable root but withholds the post-perturbation label because the source does not provide that exact counterpart.

~~~text
root addition is semantically material
!= automatic 強
~~~

## 7. Root-quality perturbation

R124 preserves bounded qualitative comparisons in which applicable rooted support can exceed one, two, or three visible peer supports depending on root class.

These are qualitative orderings. They do not authorize exchange rates, numeric deltas, or strength-label thresholds.

## 8. Root-position perturbation

The selected commentary states that within Tonggen scope the month branch is especially important.

Moving a root relation into the month position therefore changes qualitative evidence, but does not establish a universal override or label flip.

## 9. Yuqi temporal perturbation

The selected Yuqi commentary distinguishes 清明後十二日 from 土旺之後.

Temporal context changes qualitative root evidence. No final strength-label transition is supplied.

## 10. Source-policy perturbation

R122 preserves unresolved treatment differences for Yang versus Yin Muku and Yang versus Yin Changsheng.

A polarity change can therefore cross a methodology/source-policy boundary. Silent rule copying or automatic label preservation is forbidden.

## 11. Hidden-stem transparency perturbation

R123 preserves the exact 寅 example where 甲 is 本主, while under the stated transparency condition 丙 may 作主.

That is a qualitative role change, not a strength-label flip.

## 12. Storage-order negative control

R123 also states that canonical hidden-stem array order is non-semantic storage order.

Therefore reordering the same membership set must not create a semantic or strength change. This is the explicit negative-control perturbation in R127.

## 13. Peer/resource family swap

R125 established broad support overlap but distinct mechanisms for peer and resource support.

Therefore peer-to-resource or resource-to-peer substitution cannot assume either one-for-one equivalence or label invariance.

## 14. Root removal from mixed support

The bounded 比印重疊 plus Tonggen configuration reaches 黨眾 / 不弱.

Removing Tonggen is a valid research probe, but the source does not supply the opposite chart. The resulting label remains COUNTERFACTUAL HOLD.

## 15. Resource multiplicity

R124/R125 preserve both favorable greater 印 presence and adverse 多 / 太過 contexts.

More resource is not monotonic, and no exact count threshold is supplied.

## 16. Output and relation-chain perturbations

R126 supplies local changes such as:

~~~text
身印兩旺 + 食傷洩氣
七煞 + 食神 => 食神制煞
食制煞 + 印 => contamination
食制煞 + 印 + 財 => 財去印存食 rescue
~~~

These are semantic relation-chain reconfigurations. They are not direct ordinary-strength label flips.

## 17. Wealth-capacity remedy

三命通會 preserves 財多身弱，要印扶身.

The baseline contains a direct weak label and a source-stated remedy, but no exact post-remedy opposite label. R127 therefore withholds the post-remedy strength label.

## 18. Challenging-family swap

I13 collects output, wealth, and officer under a broad challenging direction, while R126 demonstrates distinct mechanisms.

Replacing one challenging family with another cannot be treated as swapping equal negative units.

## 19. Main finding

R127 observes substantial feature-semantic sensitivity, source-policy sensitivity, and local relation-chain sensitivity, but zero directly established exact one-feature opposite-label pairs.

~~~text
evidence is sensitive
but
the label transition function is not established
~~~

## 20. Fail-closed rule

A later classifier must follow:

~~~text
feature state changed
=> recompute evidence semantics
=> do not invent a final label
~~~

not:

~~~text
feature state changed
=> apply hidden +/- score
=> force opposite label
~~~

## 22. Rejected derivations

R127 explicitly rejects one-feature opposite-label inference, synthetic counterfactual inheritance, deterministic season labels, one-root binary flips, numeric root-quality thresholds, silent Yang-to-Yin rule copying, transparency-to-strength conversion, peer/resource equivalence, equal challenging units, and local-chain-to-final-strength promotion.

## 23. R128 handoff

R128 should compare cross-school borderline-strength adjudication without first inventing hidden feature scores. It should preserve source-local labels, methodology-specific unresolved states, explicit disagreements, and policy-sensitive perturbations.
