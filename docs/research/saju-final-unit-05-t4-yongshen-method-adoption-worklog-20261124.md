## 이번 단위의 결정

1. 용신은 하나의 전역 알고리즘으로 취급하지 않는다.
2. 월령 격국·扶抑·調候·通關·病藥·특수격을 독립 방법으로 유지한다.
3. 방법론 간 공존은 허용하되 자동 우선순위와 최종 승자는 만들지 않는다.
4. 확정 용신·희기 역할은 현재 근거만으로 자동 지정하지 않는다.
5. 현재 코드의 roles.yong/xi/ji와 fuyi 방향은 확정 의미로 노출되지 않도록 후속 코드 수정 대상으로 지정한다.
