## 목적

R184에서 확보한 핵심 direct-case는 다음 구조다.

    日元 = 庚
    甲 / 己 모두 비일간
    甲己相合
    甲 = 克 위치
    己 = 被克 위치
    甲偏财微损
    己正印全失

R185/R186은 direct-rule 계보를 추적했지만
이 **사례문 자체의 provenance**는 별도 미해결로 유지했다.

R187은 그 사례문의 source family를 추적한다.

## 1. Read01 표면

Read01 공개 글은 다음 metadata를 표시한다.

- 제목: 「命理基础——合、刑、冲、克的相互制约」
- 표시일: 2015-08-26
- 표시 출처: 星座123

본문은:

- （一）合力与分力
- （二）合、刑、冲、生、克的相互作用
- 天干部分
- 地支部分

으로 전개되며 exact 비일간 甲己 사례가 포함된다.

따라서 2015 Read01은 사례문을 보존하는 확실한 web witness지만,
원저자나 최초 출전은 아니다.

## 2. 2004 《四柱博观》 후보

공개 도서 metadata/목차 표면은 다음을 표시한다.

    书名 = 四柱博观
    张志春 主编
    凌志轩 编
    页数 = 530
    SS号 = 11570065
    出版日期 = 2004年06月第1版

그리고 목차에서:

    第五章 重点操作原理
      第一节 关于合、冲、刑、生、克、破、害
        五、合、刑、冲、生、克的相互制约
          （一）合力与分力
          （二）合、刑、冲、生、克的相互作用

이 확인된다.

이 구조는 Read01 글의 제목과 하위 절 구조에 직접 대응한다.

## 3. 무엇이 진전됐는가

이전:

    Read01 exact direct-case = yes
    book/printed source = unknown

R187:

    earlier named-work source-family candidate = 四柱博观
    edition-year candidate = 2004
    section hierarchy match = yes
    exact case body collation = no
    physical page binding = no
    direct copy chain = no

즉 사례문 provenance는
**출전 후보가 전혀 없는 상태**에서
**2004 named-work source-family 후보가 있는 상태**로 진전했다.

## 4. 왜 아직 provenance resolved가 아닌가

현재 확보된 것은:

- 2004 책 metadata
- 해당 절 제목
- 두 하위 절 제목
- 2015 Read01의 동일 구조와 exact 사례문

이다.

아직 확보되지 않은 것은:

- 《四柱博观》 본문에서 exact 甲己 사례문이 보이는 page
- 실물/스캔 page visual verification
- 2004 책과 2015 星座123 사이의 직접 전재 관계
- 원저자/최초 창안자

따라서:

    section hierarchy match != exact body identity
    chronology != direct derivation

이다.

## 5. R186과의 관계

R186은 direct-rule 문구를 曲炜 《四柱详真》 2001 후보까지 추적했다.

R187은 다른 가지다.

- R186: generic/direct rule provenance
- R187: exact non-day-master case provenance

둘은 관련될 수 있으나,
현재 증거만으로 동일 계보라고 합치지 않는다.
