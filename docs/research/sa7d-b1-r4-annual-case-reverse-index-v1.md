## 1. 조사 규격

먼저 장의 `逐年太歲 / 流年 / 歲運 / 行運`을 식별하고, 그다음 **日主 → 운의 시간 범위 → 특정 연도 天干 → 정확한 十神 이름** 순서로 같은 문맥을 검증. `原局年柱`의 年과 `大運`의 干은 **流年의 年干과 구분**. 특정 연도가 실제로 등장해도 그 연간에 해당 十神 이름이 붙지 않았다면 **historical annual case만**, 직접 ten-god case 아님.

| 증거 상태 | 판정 |
|---|---|
| `PRINT_DIRECT_ANNUAL_TENGOD` | 동일 인쇄 저본/명례에 甲日 + 특정 遊行太歲/流年 + 정확 十神 이름과 역할을 직접 결속 |
| `ANNUAL_CASE_WITHOUT_NAME` | 甲日 + 특정 유년 확인되나 십신 정확 명칭 없음 |
| `OTHER_DAY_STEM` | 특정 유년+이름은 있으나 일간이 甲이 아님 |
| `NATAL_OR_LUCK_SCOPE` | 원국 연주·시간·대운의 十神/연도, 유년 직접 아님 |
| `TRANSCRIPTION_UNBOUND` | 전사/현대 해석에만 있고 인쇄 저본·정확 쪽 미결속 |

## 3. 조사 결론

- 네 저술 모두에서 **실제 太歲/流年 분석 문맥**은 찾을 수 있다. 그러나 `연운 해석이 존재한다`는 사실만으로 `甲→丙/丁/壬/癸/甲/乙/己` 각각의 **단일 명칭 직접 L2-C**가 입증되지는 않는다.
- 기존 甲일간 직접 사용례 1건 `QL-GEORGE-01` 및 기존 A2의 제외 대상 2건을 재확인. **R4 신규 대상 7건 중 직접 사용례 추가 0건**.
- R4에서 외부 PDF 웹 렌더(127쪽 중 해당 2쪽)를 눈으로 확인했으나 **새 GitHub Actions·CI는 실행하지 않음**. 원본 PDF의 전체 해시·제본 동일성 미입증.
- 추가 스캔 기준은 구체적인 **같은 명례 안의 정확 일간·유년·십신이 모두 지목된 전사 및 서지**가 발견되는 경우에 한정. 명칭 없는 `甲子太歲` 또는 다른 일간 사례를 반복 스캔하지 않음.
