# 재물운 지장간 별도 관측 채널 — 실행 기록 (2026-11-21)

> 상태: **연구 전용 구현 및 동일 500건 중간 재검증 완료 / 재물 해석 품질·상용화 완료 아님**
> 기준: `docs/ROADMAP.md` 단계 1~2와 `docs/product/wealth-interpretation-coverage-remediation-policy.md`
> 범위: 기존 원국 재물 해석의 근거 관측 범위 확장. 별도 엔진·AI Claim 생성·판매 권한 변경 없음.

## 1. 변경 전 기준

동일 브랜치에서 지장간 채널을 추가하기 직전의 고정 500건 실행은 계산 오류 0건, 재물 해석 섹션 483건, 불충분 17건이었다.

17건의 당시 원인은 다음과 같이 분류됐다.

- 1건: 재성 T5는 지지 대표 십신 채널에 존재하지만, 해당 채널 안에서 등록된 재물 T8 조합이 성립하지 않음.
- 16건: 천간·지지 대표 십신 두 관측 채널에서 활성 재성 T5가 확인되지 않음.

이 기록은 2026-10-25 원본 기준의 111건 전체에 대한 개별 추적이 완료됐다는 뜻이 아니다. 현재 코드에서 남아 있던 17건의 재현 원인을 별도로 분류한 결과다.

## 2. 구현 내용

- 기존 `visible_stems`(천간), `branches`(지지 대표 십신)에 더해 `hidden_stems`(지장간)을 **세 번째 독립 관측 채널**로 추가했다.
- 확정된 일간과 Canonical Snapshot의 지장간 천간을 대조해 비겁·인성·식상·재성·관성의 T5 계열 존재 여부를 기록한다.
- 지장간 T5와 같은 지장간 채널에서 관측된 T5만 재물 T8 조합의 입력으로 사용한다. 천간·지지 대표 십신과 교차 조합하지 않는다.
- 재물 T8의 9개 기존 패턴을 세 관측 채널에 각각 적용한다. 새 패턴 의미를 만들거나 기존 문장을 다른 채널의 근거인 것처럼 섞지 않는다.
- 보고서에는 지장간의 실제 위치·천간·십신·Canonical fact path를 표시한다.
- 다섯 분야 Reader와 공통 근거 연결기가 지장간 fact path를 검증·표시할 수 있도록 허용 경로를 확장했다.
- 출생시각 미상 또는 필요한 Canonical 사실 미확정 시 지장간 T5를 만들지 않는 회귀 검사를 추가했다.
- 500건 감사 스크립트는 실제 Reader가 표시하는 `missing` 지원 사유도 결과 텍스트에 포함하도록 수정했다. 따라서 '읽을 수 있는 텍스트'와 '재물 종합 해석 섹션'을 구분해 기록한다.

### 남은 2건

두 명식 모두 천간·지지 대표 십신·지장간 세 채널에서 활성 재성 T5가 확인되지 않았다. 따라서 재물 T8 종합 결론을 억지로 만들지 않는다. Reader에는 실제 관측된 다른 십신 관점과 재물 T8 조합을 적용할 수 없는 이유, 그리고 이것이 재성이 없거나 돈이 없다는 판정이 아니라는 한계를 표시한다.

## 4. 근거·권한 경계

- 지장간 목록의 교차 참조로 `淵海子平` Wikisource 전사본을 등록했다. 해당 페이지는 전사본이 불완전하고 스캔 원본이 확인되지 않았다고 표시하므로, 이 출처는 **cross-reference**로만 취급한다.
- 이 출처는 지장간의 구성·위치 확인에만 사용한다. 지장간의 강약·우세·득령·통근·길흉·재물 결과를 정당화하는 근거로 사용하지 않는다.
- 방법론 품질은 `secondary_only`, `contested`, `unreviewed` 상태다.
- T5/T8 및 보고서는 연구 전용이다. `mayPublish: false`, `maySell: false`, `mayGenerateClaims: false` 경계를 유지한다. Product/Commerce 또는 Official Reading으로 승격하지 않았다.
