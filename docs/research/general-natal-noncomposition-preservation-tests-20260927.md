# R140 — Non-composition preservation tests for incompatible methodologies

Date: 2026-09-27  
Track: saju-research  
Status: research-only

## Purpose

R139 defined a methodology-composition admissibility matrix. R140 does not extend that matrix and does not decide new cross-method outcomes.

R140 takes every R139 probe already classified as:

- PARALLEL_PRESERVATION_ONLY
- COMPOSITION_UNRESOLVED
- NON_COMPOSITION_BOUNDARY

and verifies that these states remain non-composed under adversarial pressure.

## Source surface

R139 contributes:

- 8 parallel-preservation probes
- 12 composition-unresolved probes
- 5 non-composition-boundary probes

R140 therefore has 25 source probes.

Every source probe is exercised against nine pressure families, producing 225 preservation vectors.

## Pressure families

1. reverse input order
2. methodology-count majority
3. source-count majority
4. numeric priority injection
5. weighted priority injection
6. semantic role collapse
7. final-Yongshen collapse
8. automatic special-pattern transition
9. automatic conflict tie-break

These pressure families are rejection tests, not supported resolution mechanisms.

## Preservation contract

For every vector R140 preserves:

- canonical methodology pair identity
- both methodology identities
- both semantic roles
- both evidence values
- the R139 non-composition state class

R140 emits no:

- method winner
- numeric priority
- final Yongshen
- merged semantic role
- special-pattern transition
- executable cross-method result
- production authority

## Order invariance

Each of the 25 source probes has a reverse-input-order vector.

Reversing the evidence order must not change the canonical pair key or create precedence. Evidence identity is checked as a set, while the perturbed input order may reverse.

## Same element, different role

R139 contains four same-element/different-role probes. R140 retains all four as explicit role-identity controls.

An identical element value across methodologies does not authorize:

- role equivalence
- role merge
- composition proof
- final Yongshen emission

## Special-pattern preservation

R140 includes all R139 non-composition source probes involving SPECIAL_FOLLOW.

Ordinary-path damage, climate urgency, Tongguan mediation, or Bingyao disease/remedy evidence cannot become an automatic special-pattern transition through cross-method composition pressure.

## Tongguan and Bingyao

The two R139 FLOW_TONGGUAN × BINGYAO source probes remain parallel or unresolved.

R140 applies all nine adversarial pressures to both cases and still emits no winner, tie-break, final Yongshen, or executable result.

## Boundary

R140 is a preservation and regression artifact.

It does not:

- create a new compatibility classifier
- establish a methodology precedence order
- introduce majority voting
- score methodologies
- infer final Yongshen
- establish special patterns
- admit research evidence into engine authority

The next frontier begins a different group: R141 — Multi-relation stem/branch graph order-sensitivity corpus.
