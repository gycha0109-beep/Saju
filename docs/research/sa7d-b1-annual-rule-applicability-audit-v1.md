# SA-7D-B1-R2 — 流年 규칙 적용·증거 합성 가능성 감사 v1

> 2026-10-09 · Watchtower-Track: `saju-research`. **연구 방법론 감사 전용**: 규칙을 제품 엔진에 반영하는 사양이 아니며, 직접 사례 `L2-C`의 수를 변동시키지 않는다. `sourceSupportGrade='INSUFFICIENT'` 8/8, `bridgeReentryReady=false`, `Production=HOLD`.

## 1. 네 가지 명제를 혼동하지 않는다

| 종류 | 검증해야 하는 명제 | 직접 원전 예시 | 독립 주장으로 허용되는 범위 |
|---|---|---|---|
| **L1-EXACT** | 甲 일간에 비춰 특정 干의 **십신 명칭** | 明刻 『三命通會』 第9冊 p32 `正財者乃甲見己乙見戊之例` | **甲日→己 正財** 명칭, 유년 특정 불가 |
| **L2-M** | 流年의 어느 요소를 日干과 어떻게 비교하는가 | 明刻 『三命通會』 第19冊 p2 `日取天干，流歲取天干` | **유년 天干 입력 방법**, 8개 십신명 개별 출력 불가 |
| **L2-C** | 특정 日干과 실제 특정 유년의 십신명 **동일 인쇄 문맥 직증** | 1935 『千里命稿 第一集』 `NLC416-17jh002565-109431` p67 `夫甲木日元` + `辛亥年又屬正官之鄉` | **甲日×辛亥年 正官** 역사적 1개 사례 |
| **L2-D** | 서로 다른 원전의 L1·L2-M·명칭 규칙 등을 **조합하는 현대 분석자 추론** | `甲見己正財` + `流歲取天干` | 재현 가능한 *도출 후보*일 뿐 **원전 직접 사례가 아님** |

**추가 직접 사례로 세면 안 되는 반례:** 民國26[1937] 『命理探源』 PDF p79–80에는 `庚日×乙卯流年 正財`라는 직접 L2-C가 있으나 대상은 **庚日**이어서 갑일간 8종의 카운트는 증가하지 않는다.

## 2. 일반 방법에 관한 세 원전은 서로 다른 범위를 가짐

| 출처 | 실제 원문 확인 내용 | 허용되는 방법론 | 금지 |
|---|---|---|---|
| 『三命通會』 明刻 第19冊 卷十上 p2 `看命口訣` | `流歲取天干`, `日取天干`, `年取天干`, `大運取支神` | `流歲`에서 天干을 본다는 서술 | 天干만으로 유년 전체 吉凶/현대 연운 전망 확정 |
| 『刻京臺增補淵海子平大全』 明刻 第2冊 卷三 p15–16 `六親總篇` | `甲日爲主`의 육친 설명과 `此必以歲運見何字則剋何人` | 명식의 육친과 `歲運`의 연결 | `歲運` 일반범위를 임의로 `流年天干` 단일 명제로 변경 |
| 『命理探源』 民國26[1937] PDF p79–80 `推流年法` | `凡推流年即以所值本流年干支爲主` + `庚金日主，於乙卯年推...陽見陰爲正財` | 특정 다른 日主·流年에서의 관계/십신 이름 계산 **실제 예시** | 이 예시를 `甲日×己流年正財` 혹은 다른 甲日 7쌍 직접 용례로 소급 |
| 『精選命理約言』 民國24[1935] PDF p88–89 `流年賦` | `先觀歲與日干`, `犯必日之財官`, `合必日之正配，非官即財` | 유년과 일간 비교 일반 방법 | 복합 `甲見己／乙見庚`와 財官 이름을 분리해 `甲己 正財` 직접 인용으로 합성 |

## 3. 합성 추론을 고려하려면 필요한 독립 조건

**증거를 합칠 수 있는 후보**의 필수 구성:

1. `dayStem`이 문헌에서 명시되어 있고 역할이 `natal day stem`으로 식별되어야 함. 사주 원국 年柱의 천간은 비교 기준인 일간이 아니다.
2. `annualStem`과 `annualBranch`의 출처가 명확하고 대운/소운/원국 연주와 구별되어야 함.
3. 관계 `comparedStem`의 음양·생극 방향이 정확해야 하고 **A2 편관/편재**의 별도 두 관계를 甲 기준 다른 이름에 상속하지 않음.
4. L1 명칭의 **역사적 생략/복합/방향별 다의**(대표 `劫財/敗財`)를 보존해야 하며, 서로 다른 출판본의 이름들을 silently 동일시하면 안 됨.
5. 1935/1937 편집본은 명대 본문과 **독립 사본·시대·서술 목적**을 갖고 있다. 같은 표현을 사용해도 당시의 십신 정의/적용 범위가 호환된다는 별도 근거가 필요.
6. 年干 적용에서 年支·藏干·원국의 合冲刑害·용신 논의 등 **원문에 포함된 다른 조건을 제거하지 않음**. 계산된 십신 이름이 해당 년도의 직업·재물·건강 사건을 결정한다는 주장이 아님.
7. 직접 인쇄 `L2-C` 판정은 반드시 **원본 서명+editionId+archiveId+PDF one-based page+quoted text/맥락+원본에서 파생한 이미지 sha256**을 확인한 동일 저본의 정확한 직접 명명 문장에만 부여.
8. 이 모든 합성 전제와 결과는 `L2-D-UNREVIEWED`로 분리. 어느 후보도 현재의 공식 `sourceSupportGrade` 또는 Bridge/Production 자동 변경 불가.

## 5. 단계별 종료·반환 계약

- 연구 B1 원장과 판본별 문서를 **증거로 반환**하는 것은 허용. 이 문서는 인쇄 원전의 믿음·분류체계에 관한 역사적 자료 기록이지 실제 인과효과/미래 사건의 실증적 검증이 아님.
- 신규 L2-C가 나타나면 (i) 원본 판면 결속 (ii) 독립 방향/명칭 감사 (iii) 기존 권한 경계 확인 후 **그 짝의 역사적 직접 근거 집계만** 업데이트.
- Production 진입 여부·현대 테마·Bridge 해석·월간 재사용은 **다른 트랙의 명시적 승인 전까지 불허**.
