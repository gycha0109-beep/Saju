## 1. Question

R135 asks whether the repository supports a monotonic transition model from ordinary-pattern failure toward special/follow-pattern establishment.

It does not.

The governed boundary is qualitative:

```text
ordinary path available
ordinary path broken
ordinary path absent
special prerequisite observed
special prerequisite unresolved
special path research-plausible
special path blocked
indeterminate
```

These states do not form a scalar "specialness" axis.

- R029 — follow/external entry propositions, exclusions, execution gaps;

## 4. Non-monotonicity result

The same perturbation does not imply the same result.

For example:

```text
REMOVE_ORDINARY_PATH
+ all bounded special prerequisites observed
-> SPECIAL_PATH_RESEARCH_PLAUSIBLE
```

but:

```text
REMOVE_ORDINARY_PATH
+ unresolved 日元臨絕
-> INDETERMINATE
```

and:

```text
REMOVE_ORDINARY_PATH
+ unresolved transformation validity
-> INDETERMINATE
```

Thus:

```text
ordinary blocker removed
!= special pattern established
```

## 5. Broken ordinary counterexample

Every R029 target receives a negative-control transition:

```text
ORDINARY_PATH_AVAILABLE
-> BREAK_ORDINARY_PATH_WITHOUT_PROVING_ABSENCE
-> ORDINARY_PATH_BROKEN
```

This is deliberately not:

```text
ORDINARY_PATH_BROKEN
-> SPECIAL_PATH_RESEARCH_PLAUSIBLE
```

The R029/R030/R134 boundary is preserved: damaged ordinary logic remains an ordinary-path problem unless ordinary-path absence and the special target's own prerequisites are independently supported.

## 6. Opposite-direction probes

Each target has a structural opposite-direction pair:

```text
ordinary path available
-> remove ordinary path
-> special path may remain research-plausible or indeterminate
```

versus:

```text
special path research-plausible
-> add ordinary path
-> special path blocked
```

These are paired probes, not a reversible numeric axis.

There is no hidden coordinate such as:

```text
ordinary = 0
special = 1
```

and no distance between the states is defined.


## 8. Structural is not temporal

R135's "transition" means a research comparison between two bounded structural configurations.

It does not mean:

- natal -> Dayun;
- Dayun -> annual;
- luck-cycle entry/exit;
- time-dependent 格局 conversion.

Those belong to later temporal frontiers.

## 9. Rejected monotonicities

R135 rejects:

- ordinary failure = special progress;
- ordinary-path removal = special establishment;
- more one-sidedness = higher special score;
- special-path plausibility = special candidate;
- opposite-direction pair = reversible numeric axis;
- same perturbation = same outcome across contexts;
- broken ordinary = absent ordinary path;
- unresolved prerequisite = negative prerequisite;
- structural transition = temporal transition;
- non-monotonicity = randomness.
