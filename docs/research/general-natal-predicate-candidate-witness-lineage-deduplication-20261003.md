# R170 — 보관 스캔과 독립 텍스트 근거 분리

> 날짜: 2026-10-03
> 상태: 연구 완료 후보
> 트랙: saju-research

## 목적

R169는 1926년 文明書局 판본을 독립 역사 판본 후보로 남겼다.

R170의 목적은 공개 스캔 파일 수와 실제 독립 textual witness 수를
혼동하지 않도록 계보를 고정하는 것이다.

## 확인된 공개 기록

### 국가도서관 1926 第2卷

- 파일: NLC416-13jh002326-46443
- 서명: 淵海子平 子平真詮
- 권: 第2卷
- 교감: 秦慎安校勘
- 발행: 文明書局
- 연도: 民國十五年[1926]

### 국립대만도서관 계열 1926 v.2

- 파일: NTL-9900014380
- 서명: 淵海子平子平真詮 v.2
- 교감: 秦慎安 校勘
- 발행: 文明
- 연도: 1926

두 기록은 발행자·연도·교감자·권 정보가 강하게 겹친다.

하지만 이것만으로:

- 같은 물리본인지,
- 같은 판본인지,
- 본문이 완전히 같은지

확정하지 않는다.

따라서 현재 분류는:

    BIBLIOGRAPHIC_MATCH_CANDIDATE

이다.

서로 다른 기관에서 별도 스캔이 존재한다는 사실은 기록하되,
독립 텍스트 근거 두 개로 계산하지 않는다.

따라서:

    SEPARATE_CATALOG_RECORD_CANDIDATE

로만 기록한다.

## 독립 witness 판정 규칙

다음은 독립 textual witness의 증거가 아니다.

- 파일 식별자가 다름
- 보관기관이 다름
- 스캔 파일이 두 개 존재함
- 같은 발행자와 연도가 기재됨
- 별도 카탈로그 레코드가 존재함

독립 보강 근거로 계산하려면 최소한:

1. 목표 문구를 각 스캔에서 직접 확인
2. 각 스캔의 실제 인쇄면 위치 기록
3. 후보 문구와 주변 문맥 대조
4. 판본/물리본 관계 검토
5. 의미 있는 본문 계통 독립성 판정

이 필요하다.

## 현재 결과

공개 보관 스캔 기록: 3개

보관기관: 2개

확정된 독립 textual witness: 0개

따라서 R169에서 남긴 독립 역사 witness 공백은 아직 닫히지 않았다.

## 의미론 경계

witness 개수는 의미론 가중치가 아니다.

향후 독립 witness가 여러 개 확보되더라도 이를 곧바로:

- 확률
- 강도 점수
- 기제 우선순위
- 충분조건
- 자동 판정

으로 변환할 수 없다.
