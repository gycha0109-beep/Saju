# 연운·월운 십신 계열별 위치 정합성 수정 및 3,000명 감사 — 2026-11-22

## 범위
- 기준: 최신 `main`의 2026-11-22 PR #2800, #2801, #2802 및 `docs/ROADMAP.md` 기존 7단계.
- 기존 원국 T8 및 기간 T9 연구 근거의 **실제 동시 관측 표시와 의미 차이 검증** 범위만 수정한다. 별도 해석 엔진·신규 T9 Claim·길흉·미래 사건·Official/판매 권한을 만들지 않는다.
- 기존 500건 고정 시드 `0x5a1a2026`, 메뉴 8개, 참조시각 `2026-10-25T00:00:00.000Z`를 유지하고, 같은 결정론적 표본의 앞 500건을 포함한 3,000건 추가 감사를 별도 옵션으로 실행했다.

## 실제 수정
1. 원국의 한 T8 다중 계열 패턴은 여러 십성의 관찰 위치를 포함한다. 기존 기간 비교는 **해당 기간과 같은 십신 계열만 선택하면서도 위치는 다른 계열까지 한꺼번에 표시**했다.
2. 이제 원국 T8의 **전체 출처·관찰 위치는 그대로 보존**하되, 기간별 비교 표시에는 해당 계열에 속하는 정확한 십신의 원국 위치만 전달한다. 선택 기간의 십신 원형(정재 vs 편재 등)도 명시한다. 2026년 연운과 절입 전·후 월운에 동일하게 적용한다.
3. 반복 원인 감사는 독자가 **실제로 보는 기간별 근거**와 내부에 함께 보존된 다른 계열의 위치를 구분한다. 내부 참고 위치만 다른 것을 '기간 차이 누락'으로 잘못 계산하지 않되, 실제 표시 근거나 기간 출처 규칙이 달라졌는데 문장이 같으면 기존대로 실패한다.
4. 기존 500건 감사는 인수 없는 실행으로 보존한다. `--count 3000` 옵션만 추가했다. 3,000건 생성 원천 자료와 반복 그룹 상세는 사용자 PC의 비공개 결과 폴더에만 보관한다.
