# Saju Final — T6 천간·지지 상호작용 방법 채택 v1

- 결정일: 2026-11-24
- 적용 범위: 여섯 메뉴 공통 원국 판단의 연구·Reader 경로
- 근거: 기존 T6 source-bound relation reviews, I18~I26, R139 및 관계별 interaction corpus
- 상태: **관계 종류·참여 위치·맥락별 검토 채택 / 일반 효과·우선순위 resolver 미채택**

## 1. 결정 요약

T6는 천간합, 지지의 합·충·형·파·해·회합 등 구조 관계의 존재와 참여 위치를 보존한다. 관계가 있다는 사실만으로 실제 효과, 승패, 뿌리 파괴·보존, 합화, 구응, 일간 강약을 확정하지 않는다.

천간과 지지, 드러난 글자와 지장간의 관계는 서로 다른 입력·출처·적용 범위를 가진다. 한쪽의 규칙을 다른 쪽에 자동 전용하지 않는다.

## 2. 채택하는 관계 표현

- 관계 종류
- 참여한 기둥·글자·위치
- 관계를 만든 정확한 입력 fact path
- 해당 관계에 적용 가능한 출처와 규칙
- 관계가 닿는 통근·월령·지원·제약 대상
- 추가 검토가 필요한 효과와 입력

관계 후보는 각기 독립 식별한다. 동일 위치에 여러 관계가 닿으면 모두 보존하고, 배열 순서로 승자를 선택하지 않는다.

## 3. 효과 판단 원칙

| 관계 | 현재 채택 | 자동 확정 금지 |
|---|---|---|
| 천간 오합 | 정확한 참여 글자·위치와 source-bounded 후보 | 합화, 역할 변경, 최종 효과 |
| 지지 충 | 참여 지지·위치 및 계절·지원·구응 검토 필요성 | 뿌리 파괴, 충의 승자, 일간 약화 |
| 육합 | 참여 지지와 관계 후보 | 합화·구속·중화·지원 지속 |
| 삼합·방합 | 구성 관계와 필요한 추가 구성 | 국 형성·변화·월령 후보 승격 |
| 형·파·해 | 정확한 관계 종류·참여 위치 | 자동 손상·불리함·효과 크기 |
| 복수 관계 | 각각의 관계 ID와 접점 보존 | 다수결·점수·전역 우선순위·반복 합산 |

## 4. 지장간 상호작용 경계

- 지장간 구성원과 십신은 위치별로 계산·보존한다.
- 지장간이 존재한다는 사실은 상호작용의 활성화나 효과를 뜻하지 않는다.
- 천간 투간에서 확인한 효과 규칙을 지장간에 그대로 복사하지 않는다.
- 지장간 상호작용은 정확한 글자·관계·출처가 허용하는 범위에서만 관측한다.
- 숨은 글자와 드러난 글자 사이의 관계를 동일한 강도·노출로 취급하지 않는다.

## 5. 관계 이후의 효과와 정산

I18~I26 및 관련 하위 검토가 확정한 경계를 그대로 유지한다.

- I18D: 근 위치에 구조 관계가 닿는지와 실제 뿌리 효과를 분리
- I19: 관계 이후 뿌리 상태는 상대 세력·계절·지원·합화 조건에 의존
- I20: 계절 단계·지원 위치·구응 후보를 관측하되 승패·효과는 확정하지 않음
- I21~I22: 제한된 지원 부분 순서와 비교 불가 상태를 유지
- I23 v2: 신강·신약 최종 판정 대신 중지·검토 사유를 반환
- I24~I25: 식상·재성·관성 제약 메커니즘을 구분하고, 메커니즘별 필요한 맥락을 분리
- I26 v24: 정확한 일부 관계의 현재 명식 근거가 확인돼도 실제 관계 정산 결과는 미해결로 남김

## 6. 금지할 자동화

- 관계 존재 → 뿌리 파괴·보존·강화
- 육합·삼합 존재 → 합화·국 성립
- 충 존재 → 무조건 손상 또는 승자 결정
- 구응 후보 존재 → 자동 복구
- 관계 개수·출처 개수 → 강도 점수
- 복수 관계 → 우선순위·다수결
- 천간 관계 규칙 → 지장간 관계 효과로 무단 전용
- 관계 효과를 최종 강약 판정으로 순환 계산
- 미해결 관계를 LLM이 임의 정산

## 7. 구현 완료 조건

- 관계별 입력 fact path와 참여 위치가 보존된다.
- 같은 명식에서 복수 관계가 공존할 수 있다.
- 관계 존재와 관계 효과가 서로 다른 상태로 기록된다.
- 적용 범위가 확인되지 않은 규칙은 사용하지 않는다.
- 지장간 상호작용은 별도 source applicability가 있는 경우에만 사용한다.
- 메뉴별 해설은 관계 종류와 검토 근거를 설명하되, 미확정 효과를 확정 결론으로 쓰지 않는다.
