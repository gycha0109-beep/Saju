# Saju Final — T4 용신·희기 방법 채택 v1

- 결정일: 2026-11-24
- 적용 범위: 여섯 메뉴 공통 원국 판단의 연구·Reader 경로
- 근거: R034/R035/R037/R038/R137/R138/R139 및 기존 용신·방법론 연구
- 상태: **복수 방법론 병렬 보존 채택 / 단일 용신·희기 결정기 미채택**

## 1. 결정 요약

용신을 하나의 규칙으로 선택하지 않는다. 현재 저장소가 구분해 온 방법론을 독립적으로 유지한다.

- 格局·월령 중심의 용신 논리
- 扶抑
- 調候
- 通關
- 病藥
- 從格·化格 등 특수 구조 검토

각 방법론의 근거가 함께 존재할 수 있다. 공존은 승자 선택을 뜻하지 않으며, 서로 다른 방법론의 후보를 숫자나 전역 우선순위로 합치지 않는다.

## 2. 채택하는 방법별 범위

| 방법 | 채택 근거 | 적용 경계 |
|---|---|---|
| 月令·格局 용신 | 월령에 따라 후보가 달라지고 복수 후보가 공존할 수 있다는 子平真詮 계열 근거 | 월령 신호만으로 최종 용신을 확정하지 않음 |
| 扶抑 | 일간 강약에 따라 돕거나 억제하는 후보 계열이 달라진다는 徐樂吾 評註의 구절 | 최종 강약과 실제 후보 선택이 해결되지 않으면 실행하지 않음 |
| 調候 | 계절·기후를 함께 참작해야 한다는 근거 | 조후 필요성이 다른 방법을 항상 덮어쓰지 않음 |
| 通關 | 서로 대립하는 두 힘이 균형을 이루는 조건에서 조화 매개를 검토 | 단순히 두 오행이 상극한다는 이유로 매개 오행을 자동 선택하지 않음 |
| 病藥 | 이미 채택된 필요·억제 관계를 해치는 요소와 이를 제거하는 요소를 별도 검토 | 선행 필요·억제 판단 없이 병·약을 새로 만들지 않음 |
| 特殊格 | 종·화·전왕 등 별도 구조 가능성을 독립 검토 | 일반 강약 경로의 실패를 특수격 성립 증거로 쓰지 않음 |

## 3. 방법론 간 공존 정책

R139의 6개 방법론 계열과 21개 방법론 쌍의 검토 결과를 재사용한다.

허용:
- 서로 다른 방법의 근거를 동시에 보존
- 조건부 공존 또는 병렬 검토 상태
- 적용 불가·미확정 상태의 명시
- 동일 오행이 서로 다른 방법론에서 다른 역할을 하는 경우 역할 구분

금지:
- 방법론 수 또는 출처 수가 많은 쪽을 승자로 선택
- 배열 순서·enum 순서로 우선순위 생성
- 扶抑이 항상 格局보다 우선, 調候가 항상 모든 방법보다 우선 같은 전역 규칙
- 通關과 病藥을 하나의 보편 해결법으로 합침
- 미해결 충돌을 임의 tie-break
- 자동 최종 喜神·用神·忌神 지정

## 4. 명하의 현재 코드에 적용할 경계

현재 whole-chart-judgment의 roles.yong / roles.xi / roles.ji는 이름만으로 최종 用神·喜神·忌神 역할처럼 읽힐 수 있다. 이 속성은 확정 역할이 아니라 월령 후보, 지원 후보, 제약 후보, 구응 후보를 담는 Preview 표현으로 재구성해야 한다.

또한 현재 fuyi conditional direction은 기존의 간략한 strength state에 의존한다. T2의 최종 강약 준비도와 방법론 조건을 연결하기 전까지 이를 최종 扶抑 선택으로 사용하지 않는다.

## 5. T4 완료 조건

- 월령 후보와 扶抑·調候·通關·病藥·특수격 후보를 구별한다.
- 같은 명식에서 복수 방법이 공존할 수 있다.
- 방법별 필요한 입력과 미해결 조건을 별도로 추적한다.
- 최종 용신·희기 역할은 채택된 규칙과 입력이 모두 충족된 경우에만 생성한다.
- Reader가 후보를 확정 용신·희기라고 표현하지 않는다.

이 문서는 T4 방법 경계를 채택한다. 최종 용신·희기 선택 로직을 새로 승인하지 않는다.
