## Direct source

子平真詮評註 — 論支中喜忌逢運透清  
https://www.ncc.com.tw/fate/paleo/bg/bg_034.htm

## Core source proposition

`原局支中所藏之神不一，為喜為忌，靜而待用，逢運引出，其用方顯`

This directly distinguishes natal latent material from a later operative state.

## Verified state transitions

### 1. NATAL_LATENT
A hidden natal component exists but is described as `靜而待用`.

### 2. ACTIVATED_BY_TRANSPARENCY
Luck can `引出` / `透清` the natal latent component.

### 3. ACTIVATED_BY_NATAL_LUCK_MEETING
`命與運二支會局，亦作清論` records a second activation mechanism.

### 4. TEMPORARY_OPERATIVE_STATE
The commentary explicitly notes cases where the effect is confined to the relevant five-year luck period and afterward returns to the prior condition.

### 5. POSITION/CONTEXT MODULATION
The source distinguishes urgency/effect by natal position/context, e.g. year/day/hour placement.

## Boundary

Activation is not automatically:
- permanent natal mutation;
- a concrete real-world event;
- favorable or unfavorable;
- guaranteed merely because a hidden stem exists.
