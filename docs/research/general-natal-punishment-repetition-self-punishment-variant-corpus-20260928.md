# R144 — Punishment repetition and self-punishment variant replay

Date: 2026-09-28  
Track: saju-research  
Status: research-only

## Purpose

R144 replays the R056 punishment taxonomy under repeated-branch topologies.

The target question is narrow:

> when the same directed 刑 relation or a self-punishment branch appears repeatedly, what structural multiplicity can be preserved without silently converting multiplicity into severity, harm, precedence, or an executable effect?

R144 does not create a branch-punishment production resolver.

## Upstream boundary

R056 verifies:

- 8 directed non-self punishment relations
- 4 self-punishment branches: 辰, 午, 酉, 亥
- self-punishment as SAME_BRANCH_REPETITION

R056 explicitly leaves open:

- punishment context effect
- self-punishment multiplicity
- relation competition
- role context
- time-layer activation

It also explicitly denies:

- structural presence implies harm
- self-punishment implies harm
- numeric severity
- an executable effect resolver

The existing Gyeokguk primitive review additionally records that canonical production branch_xing input is still unavailable.

## Directed repetition corpus

All 8 directed R056 relations are replayed under three topologies:

1. one source branch instance with two repeated target branch instances
2. two repeated source branch instances with one target branch instance
3. two repeated source and two repeated target branch instances

This produces:

- 24 directed cases
- 64 structural directed candidate edges
- 48 participant instances with candidate degree greater than one

Candidate degree is topology only.

It does not authorize:

- participant priority
- repeated-source priority
- repeated-target priority
- severity
- harm
- effect

## Self-punishment variants

All 4 R056 self-punishment branches are replayed at repetition counts:

- 2
- 3
- 4

This produces 12 self-punishment cases.

For descriptive topology only, R144 records the number of same-branch unordered pairs:

- 2 repetitions -> 1 pair
- 3 repetitions -> 3 pairs
- 4 repetitions -> 6 pairs

Across all four self-punishment branches this is 40 pair-topology observations.

The pair count is arithmetic topology, not a severity scale.

- four repetitions are automatically stronger than three
- relation count as numeric weight
