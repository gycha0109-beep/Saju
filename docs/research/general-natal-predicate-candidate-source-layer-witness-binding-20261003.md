# R168 — 후보별 출처 층위 근거 결속

> 날짜: 2026-10-03
> 상태: 연구 완료 후보
> 트랙: saju-research

## 목적

R167은 命有甲, 庚辛, 申酉 세 후보에 실제 근거가 들어오기 전까지
predicate 연구 진입을 차단했다.

R168은 공개된 고전 전사본을 대조해 실제 문구를 결속한다.
단, 웹 전사본을 역사적 비판판이나 독립 원전으로 과대평가하지 않는다.

## 확인한 본문 층

《子平真詮》 공개 전사본의 「二十六、論行運成格變格」에서 다음이 확인된다.

- 命有甲: 沈氏 본문 층에서 직접 확인된다.
- 庚辛: 沈氏 본문 층에서 직접 확인된다.

사용한 공개 전사 witness:

- 東里書齋: https://donglishuzhai.net/chapter/3739.html
- 天涯書庫: https://www.tianyashuku.com/yijing/9643/814127.html

두 사이트에서 같은 후보 문구를 확인했지만, 이것을 서로 독립된 역사적 원전 두 개로
계산하지 않는다.

## 申酉의 출처 층

申酉는 동일한 방식으로 沈氏 본문 후보 문구에서 직접 확인되지 않는다.

대신 《子平真詮評注》의 徐樂吾 평주 층에서:

    庚辛，即申酉也

라는 설명이 직접 확인된다.

사용한 공개 전사 witness:

- ncc.com.tw 《子平真詮評注》: https://ncc.com.tw/fate/paleo/bg/bg_034.htm
- 萬法歸宗 전사본: https://wx.masterkuo.com/thread-89-1-1.html

따라서 R168은 다음을 분리한다.

- 庚辛 = 沈氏 본문 직접 witness
- 申酉 = 徐樂吾 평주 직접 witness
- 두 층을 같은 원문 층으로 합치지 않음

## 命有甲와 짝 사례

같은 절에는 丁生辰月, 透壬用官에 운에서 戊가 나타나는 break 사례와,
변격이지만 꺼리지 않는 사례에서 命有甲가 명시된 문장이 함께 존재한다.

이로써 다음은 직접 텍스트 차이로 보강된다.

- rescue 쪽에는 甲가 명시된다.
- break 쪽에는 甲가 명시되지 않는다.

하지만 break 쪽의 미기재는 여전히 甲의 부재를 증명하지 않는다.

## 현재 확보된 것

- 작품 식별
- 절 단위 위치 식별
- 주변 문맥
- 命有甲 본문 직접 witness
- 庚辛 본문 직접 witness
- 申酉 평주 직접 witness
- 공개 전사본 간 교차 확인

## 아직 확보되지 않은 것

- 역사적 비판판 결속
- 구체 판본 식별
- 쪽/권차/folio 수준 위치
- 독립 역사 witness
- 최소조건/충분조건을 판정할 별도 근거
- 申酉가 沈氏 본문 층에 직접 존재한다는 witness

따라서 세 후보 모두 predicate contract 연구 진입은 계속 차단한다.

## 권한 경계

R168은 다음을 확립하지 않는다.

- 命有甲가 rescue의 최소조건 또는 충분조건이라는 규칙
- 庚辛 또는 申酉 개별 원소의 충분조건
- 庚辛/申酉 그룹의 충분조건
- 기제 우선순위
- 최종 변화 판정
- 실행 resolver
- 해석 claim 권한
- 제품 권한

## 다음 작업

다음 연구는 공개 웹 전사본을 넘어 판본/위치 provenance를 강화하는 방향이어야 한다.

특히 申酉는 평주 층과 沈氏 본문 층을 계속 분리한 채,
원문 계통에서 직접 witness가 존재하는지 여부를 별도로 조사해야 한다.
