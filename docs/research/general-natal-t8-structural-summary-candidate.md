# General Natal T8 Structural Summary Candidate

Status: `RESEARCH_CANDIDATE_DOMAIN_REVIEW_REQUIRED`

This candidate is the smallest evidence-preserving bridge from the existing I18A month-branch strength evidence into the frozen consumer `general / natal` reading profile.

It is **not** production authority.

## Purpose

The consumer reading selector requires at least one active T8 claim for a `general / natal` reading. Existing I18A evidence is T2 and therefore cannot by itself satisfy that product-domain contract.

This candidate adds one narrow T8 synthesis layer without adding personality, event, career, wealth, relationship, health, timing, or future semantics.

```text
Canonical facts
→ I18A T2 month-branch elemental relation
→ I18A T2 scope guard
→ General Natal T8 structural summary candidate
```

The T8 rule requires **both** upstream claim types:

```text
DAY_MASTER_MONTH_BRANCH_EVIDENCE
DAY_MASTER_MONTH_BRANCH_SCOPE_GUARD
```

If the scope guard is missing, the T8 rule does not execute.

The candidate does not introduce a new source proposition. It inherits the exact I18A source set and requires the I18A claims as upstream dependencies.

The candidate therefore cannot be production-authorized independently of the I18A substrate. A future production review surface includes:

1. the I18A month-branch methodology;
2. the I18A relation rules and scope-guard rule;
3. the new T8 domain-synthesis methodology;
4. the five new T8 relation mappings;
5. the shared source bindings;
6. exact content-addressed domain review attestations and reviewer-trust pins.

No status field should be promoted before that review is complete.
