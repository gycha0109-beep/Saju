# I27 Challenge Mechanism Structural-Force Evidence Review v1

## Purpose

I27 establishes source-bounded structural evidence for the target element of each challenge mechanism before any effective-force or usefulness/harmfulness verdict is attempted.

It does **not** determine mechanism strength, challenge effect, day-master strength, or a numeric magnitude.

## Mechanism target contract

For each day-master element, I27 derives the target element for:

```text
OUTPUT_LEAKAGE              = element generated by the day master
WEALTH_EXPENDITURE_CONTROL  = element controlled by the day master
OFFICER_CONTROL_PRESSURE    = element controlling the day master
```

The target mapping is relation-specific and deterministic. It is not a score.

## Structural evidence channels

For each resolved mechanism target element, I27 preserves the following channels separately:

```text
seasonalPhase
visibleStemPositions
branchMainElementPositions
hiddenMembershipPositions
```

These channels answer where and under what seasonal phase the target element is structurally evidenced in the resolved four pillars.

They must not be collapsed into a single magnitude or interpreted as intrinsic root quality.

## Fail-closed boundary

I27 requires all four resolved pillars. If the pillar set is incomplete:

```text
status                 = PILLARS_UNRESOLVED
mechanisms             = []
challengeEffectVerdict = not_determined
classificationAuthorized = false
```

No partial chart is promoted to resolved mechanism-force evidence.

## Hard guards

```text
effectiveForce                  = not_determined
numericMagnitude                = not_assigned
challengeEffectVerdict          = not_determined
relativeForceVerdictAuthorized  = false
classificationAuthorized        = false
numericScoringAuthorized        = false
```

## Prohibited equivalences

```text
seasonal phase evidence          != effective mechanism force
visible target stem              != intrinsic root quality
branch-main target element       != effective mechanism force
hidden target membership         != effective mechanism force
structural presence              != usefulness/harmfulness
mechanism-force evidence         != strong/weak classification
```
