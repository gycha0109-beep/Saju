# R125 — Peer-support versus resource-support discriminant corpus

Date: 2026-09-25  
Issue: #1494  
Track: saju-research  
Status: RESEARCH PEER / RESOURCE DISCRIMINANT CORPUS COMPLETE

## 1. Research question

R125 asks whether 比劫 and 印綬 should be treated as one semantically interchangeable support primitive.

The reviewed corpus supports a narrower statement:

~~~text
比劫 and 印綬
can share a broad 黨眾 / support context

but

same broad support context
!= same mechanism
!= free substitutability
!= numeric equivalence
~~~

## 2. Corpus size

~~~text
cases             = 18
comparison groups = 9
~~~

The corpus includes peer-only, resource-only, mixed/comparative, opposition, excess, and substitution-audit rows.

## 3. Broad support overlap

The governed 子平真詮評註 surface names:

~~~text
比劫
印綬
通根扶助
~~~

inside 黨眾 composition.

This establishes broad support overlap only.

R125 does not infer that these families are identical units.

## 4. Peer-support mechanism

The selected 子平真詮 surface describes 比劫 through a friend-like mutual-support analogy.

The bounded interpretation is:

~~~text
peer support
= same-kind assistance / mutual support
~~~

The passage does not define peer support as a generating relation.

## 5. Resource-support mechanism

三命通會 / 論印綬 and 淵海子平 define 印綬 through:

~~~text
生我
我氣之源
生氣
~~~

This is a different semantic mechanism from same-kind peer assistance.

Therefore:

~~~text
PEER SUPPORT
!= RESOURCE GENERATION
~~~

## 6. Resource-specific dependency: 官生印

三命通會 preserves the bounded relation:

~~~text
官 can generate 印
~~~

inside the 印綬 context.

This supplies a resource-specific dependency axis.

R125 does not find a corresponding rule that 官 generates peer support.

## 7. Resource-specific opposition: 財破印

三命通會 and 淵海子平 preserve 財 damaging or breaking 印.

The source relationship is therefore:

~~~text
resource support
can be damaged by 財
~~~

This is not the same semantic mechanism as 比劫 competing with 財.

## 8. Peer-specific opposition: 爭財 / 分財

Selected 子平真詮評註 material preserves 財 contexts where peer support can be adverse because it competes for 財.

The same broad family can become remedial in another context:

~~~text
財旺身弱
→ 比劫 can divide/share 財
~~~

Therefore peer support is context-dependent.

It is not a fixed positive scalar.

## 9. Peer support can protect resource support without replacing it

Another bounded commentary context gives:

~~~text
財 too strong
→ 印 is damaged
→ 比劫 can remove/divide 財
→ 印 is protected
~~~

This is composition.

It is not substitution.

~~~text
peer protects resource
!= peer replaces resource
~~~

## 10. 三命通會 mixed peer/resource context

In the 印綬 chapter, the source preserves cases where 比劫/body-strengthening can become beneficial when 財 damages 印.

It also preserves 比劫 assisting the body and interacting with 煞 in quoted traditional material.

These contexts support:

~~~text
peer and resource support can cooperate
~~~

They do not support:

~~~text
peer = resource
~~~

## 11. Resource support in weak-body contexts

Selected 子平真詮評註 material uses 印 in bounded weak-body contexts where the role includes:

- generation/support of the day master;
- mediating 官/煞 relations;
- controlling 傷官 in selected structures.

The reviewed corpus does not state that 比劫 can globally substitute for these resource-specific functions.

## 12. Peer support does not universally replace root

R019/R122 preserve exact examples:

~~~text
four Xin over Mao
four Bing over Shen
~~~

where repeated visible peer support remains weak when root is absent.

This supplies a bounded peer/root discriminant.

It does not establish the same limitation for resource support.

## 13. Resource multiplicity has its own excess profile

三命通會 / 論印綬 preserves both:

- contexts where more 印 can be favorable;
- contexts where many/excessive 印 is adverse.

Therefore resource support has an explicitly context-dependent excess profile.

R125 does not find an equivalent universal peer-support excess law.

Thus:

~~~text
COMMON PEER/RESOURCE EXCESS BEHAVIOR
= NOT ESTABLISHED
~~~

## 14. Mixed 比印 support

The governed out-of-season Wood example contains repeated 比/印 plus additional rooted support and reaches a bounded 黨眾 / 不弱 conclusion.

The valid inference is:

~~~text
peer + resource cooperation exists
~~~

The invalid inference is:

~~~text
peer and resource are commensurable units
~~~

## 15. Substitution audit

Across the reviewed source package, R125 did not find a direct statement establishing:

~~~text
1 比劫 = 1 印綬
2 比劫 = 1 印綬
peer support globally substitutes resource support
resource support globally substitutes peer support
~~~

This negative audit is important.

Lack of a direct conversion rule is preserved as:

~~~text
FREE SUBSTITUTABILITY
= NOT ESTABLISHED

NUMERIC EQUIVALENCE
= NOT ESTABLISHED
~~~

## 16. Textual provenance

Source strata remain separated:

!= 徐樂吾 later commentary

!= 淵海子平 transmission
!= repository research synthesis
~~~

Repeated or quoted traditional material is not counted automatically as independent corroboration.
