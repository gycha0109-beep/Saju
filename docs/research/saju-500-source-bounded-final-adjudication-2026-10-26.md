## 1. 원인 분류 및 재물 개선의 실제 결과

처음 누락 111명은 출처 연결 재성 T5가 발견되지 않는 109명과 조합 불일치 2명이었다. 엔진 실행 실패/선택기 누락으로 조사된 사례는 0명이다.

현재 500명의 재물 설명 상태를 **중복 없는 5개 범주**로 분류한 결과는 다음과 같다.

| 연구 결과 | 명식 수 | 무엇을 말할 수 있는가 |
| --- | ---: | --- |
| 출처 있는 직접 재물 T8 구조 중심 근거 | **382** | 자원·교환·관리 같은 제한적 명리 구조의 중심 관점을 다룸; 소득·재산 예측이나 제품 사용 적합성은 확인되지 않음 |
| 구조적 긴장만 있음 | **7** | 비겁·재성의 긴장 질문만 가능하며 종합 중심 결론은 보류 |
| 재물과 간접 관련된 주변 설명만 있음 | **94** | 관성·인성 등 맥락만 확인됨. 이를 직접 재물운으로 집계하지 않음 |
| 출처 있는 재성 T5 단독 관측 | **1** | 재성의 존재와 관측 채널만 설명, T8 종합은 보류 |
| 출처 있는 재물 문단도 없음 | **16** | 등록된 연구 조합 적용 불가. 재물운이 없다는 뜻이 아님 |
| **합계** | **500** | 모든 케이스를 분류; 근거 없는 문장으로 채우지 않음 |

따라서 **직접 중심 재물 T8이 충분하지 않은 명식은 118명**이다. 종전 빈 문단 111명과 달리, 이 수치에는 원래부터 풀이가 있던 **긴장 구조만 확인된 7명**도 포함된다. 94명의 간접 문단은 여전히 직접 재물풀이가 아니다. 처음 없던 문단 95명(94간접·1단일)을 직접 재물운 개선 95건으로 계산해서는 안 된다.

## 2. 올해와 이번 달의 실제 해석 의미

| 고정 입력 500건 | 개선 전 | 이번 연구 구현 |
| --- | ---: | ---: |
| 올해의 실행 패턴·원국 구조를 포함한 의미 프로필 | 56종 | **281종** |
| 이번 달 절입 구간·원국 구조를 포함한 의미 프로필 | 131종 | **308종** |
| 출처 있는 연운 대 원국 고전 육합 짝 | 미구현 | **146명, 구조 관측 169건** |
| 출처 있는 월운 대 원국 고전 육합 짝 | 미구현 | **260명, 구조 관측 330건** |
| 원국 T8을 별도로 확인한 명식 | 이전에는 시기 출력에 반영 부족 | 연운 293명, 월운 322명 |

고전 육합은 `src/calculation/structural-relations.ts`가 이미 인용하고 있는 **乙巳占 卷十** 및 **選擇要略 上**의 지지 짝 목록에 근거하여, 실제 연·월주와 원국 지지가 일치할 때만 T9 구조 관측 Claim으로 표시한다. 기존 절입 전후·연운 기준 연도 계산을 유지했다.

- 육합 짝이 **실제로 합화함**을 증명하지 않는다.
- 결혼, 재물, 사업, 건강, 좋은 운, 결과의 발생 여부나 시기를 예측하지 않는다.
- 연운의 민간 달력 연도와 입춘 효력 간지를 하나로 혼동하지 않는다.
- 월운은 절입 구간별로 별도의 출처와 계산 경로를 사용하며 연운 의미를 상속하지 않는다.
- 의미 프로필 수치에는 **T9 중심 테마 10종 + 출처 확인된 구조 관측 + 별도로 확인된 원국 T8**이 함께 들어 있다. 이는 미래 운명 해석이 281종·308종 검증되었다는 뜻이 아니다.

같은 시기 테마를 공유하면서 실제 원국 근거가 다른 명식 쌍을 코드로 검증했으며, 중요한 근거가 달라도 동일한 의미가 나오는 것은 허용했다.

## 3. Claim / Rule / Methodology / Source와 한글 출력 검사

- 실제 소비한 명식별 T8 Claim의 적용 Rule·Methodology·Source·상위 Claim 연결을 500건 실행 중 검증.
- T9 Claim은 고정 시기·각 절입 구간·실제 Rule/Source와 함께 출력하며, 신규 육합 관측도 고전 출처 2종과 시기 계산 경로를 요구.
- 출처가 확인된 규칙·출처의 서로 다른 사용 프로필 **186종**, 실행·계산 오류 **0건**, 추적한 누락 근거 경로 **0건**.
- 한국어 본문은 중심 근거·독립 보조 근거·긴장 또는 부분 지원을 구분하고, 부족하면 부족하다고 출력한다.
- `im-not-ai` 문체 규칙은 원문의 의미를 바꾸지 않는 작은 교정으로만 적용. 캐릭터·LLM 윤문으로 새로운 해석이나 운명을 생성하지 않는다.

## 4. 최종 연구 판정과 남은 명리 근거의 한계

**연구 재검사:** 통과. **상품 수준 개인화 종합해석:** 근거 부족으로 미승인.

이 단계에서는 확보한 근거가 허용하지 않는 재물 T8 직접 종합 결과를 생성하지 않으며, 문헌의 지지 짝 일치 사실을 인생 사건의 확정 해석으로 승격하지 않는다. 삶의 단계 500가지 원문은 여전히 대운 계산구간 500가지이며 **실질적 생애 단계 해석이 500개라는 뜻이 아니다.**

남은 차이는 코드가 누락돼서 미완료인 것이 아니라 **적용 가능한 명리 방법론의 근거가 충분히 검증되지 않아 제품 완결성을 승인할 수 없다는 별도의 품질 판정**이다. 향후 독립 출처 확보 없이는 동일 연구 범위에서 규칙을 임의 확대하지 않는다.

`mayPublish=false`, `maySell=false`, `usefulComplete=false` 및 Official 권한 차단은 유지한다. 이번 7단계 연구 결과에 별도 UI·결제·관상·캐릭터 범위 확장은 포함되지 않는다.

