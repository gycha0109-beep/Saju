# T10 1단계 — 직접 두 명식 궁합 방법론의 공개 자료 원문 층위 및 재현 가능성 감사 (2026-11-11)

> **자료 접근 범위:** 아래 연구들은 서지·**공개 초록**을 직접 대조했다. 학위논문의 유료/제한 **전문 본문·정확한 표본표·쪽별 규칙은 아직 열람하지 않았다**. 초록을 전문으로 표시하지 않는다. 고전의 직접 본문은 기존 연구와 구별한다.
> **적용 범위:** 사주 체계 안의 전통적 해석 방법 조사. 결혼 지속·이혼·성향·행복 등의 과학적으로 검증된 개인 예측 정확도를 입증했다는 뜻이 아니다.

## 2. 2016 네 칸 연구틀 × 기존 코드의 정확한 지원 범위

2016 초록은 일간의 세 요인(상생·상비·합)을 한 쪽, (상극·충)을 다른 쪽으로 묶고, 일지의 세 요인(상생·상비·합)과 다섯 요인(충·극·형·파·해)을 교차시켜 **네 비교 범위**를 만든다. 이는 **분류 설계**이지 동일 점수나 인과 예측 공식이 아니다.

- **현재 계산하여 추적 가능한 부분:** 두 사람 일간의 천간오합, 일지 육합, 일지 충. 출처·양쪽 명식 위치·계산 해시를 기존 `crossChartStructuralMatches`에서 재사용.
- **현재 직접 교차 비교에 사용할 수 없는 부분:** 일간/일지의 오행 상생·상극·상비, 형·파·해, 일부 일간 충 등의 계산/직접 출처 조건. 기존 원국 정보가 있다 하더라도 이 2016 네 칸 분류를 전부 구현한 것으로 취급하지 않는다.
- **별도 유의:** 실제 60갑자의 일주 간지 음양 연동으로 천간오합과 일지충이 동시에 성립하는 조합은 존재하지 않을 수 있다. 현재 좁은 구조 관측만으로 네 칸이 모두 채워지는지 평가하면 **연구의 범위 자체를 잘못 평가**할 위험이 있으므로, 누락 요인을 명시한다.
- **코드:** `src/research/compatibility-t10-direct-day-comparison.ts`은 원문 확인 층위를 `DBPIA_PUBLIC_ABSTRACT`로 고정하고 두 명식의 직접 일간/일지 관측 일부만 연결한다. `test/compatibility-t10-direct-day-comparison.test.ts`에서 실제 날짜 명식·역순·보호 Preview 유지 확인. **공식 T10 Claim/Rule·점수·사건/판매 권한을 발급하지 않음.**

## 3. 이후 원문 검증의 우선순위와 연구 질문

1. **이창임 2016 본문 9–17, 17–33, 35–68쪽**: 일간/일지 생비합·충극형파해를 각 명식에 어떻게 계산하는지, 네 경우를 조합하는 예외/유불리 조건, 인터뷰 연구의 내적 한계 확인.
2. **나혁진 2017 본문과 원자료**: 남녀 각각의 십성코스 공식·서로 다른 명식 간 연동의 정의·점수 산출·표본 편향·지표의 독립 검증 가능성 감사.
3. **남직호 2019 본문**: 변수별 정확한 측정(개인 원국/두 사람 사이), 효과크기·표본·회귀·복수 비교 보정, 해당 방법을 해석 근거로 인정할지 결정.
4. **박병근 2021 본문 53–76쪽**: '복식 종합 판단법'의 실제 단계·제외 조건·충돌 해결을 읽고 2016/2017/2019 논문과 모순 사례를 대조.
5. **홍승필 2017**: 용신·상신 방법론의 학파별 차이와 본문 반례를 확인. 강한 긍·부정 해석·직접 연애/이혼 예측으로 단축하지 않음.
6. 모든 논문의 **전문 접근이 확보되기 전**에는 유료 PDF 구매, 기관 문의, 외부 API, 상품 공개/판매 승격을 임의로 수행하지 않는다.

## 4. 현재 판정

- **1단계 진행 중**: 직접 두 명식을 비교하는 공개 초록 4개(D01~D04)와 방법론 상충·주의 문헌(D05~D07)을 분리했고, 최초로 2016년 네 칸 연구 틀과 기존 엔진의 **정확한 일부 구조 대응**을 구현한다.
- **미충족**: 공개 초록은 본문이 아니다. 원문 규칙·예외·반례·독립적 예측 타당성·적용 대상 검증이 남아 있으므로 1단계 완료 선언 금지.
- **T10 종합 해석/실제 고객 Reading/Official/판매는 여전히 HOLD**. 개별 구조를 관찰하는 것과 '잘 맞는 관계'라는 결론은 다르다.
