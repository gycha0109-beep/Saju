# 원국·대운·연운 3층 관계 계산 연구 v1

## 범위
기존 #2473의 연운 계산 사실 전용 시제품을 확장합니다. 본 산출은 **연구용**이며 실제 상담·상품·Official Reading은 변경하지 않습니다.

- 원국: 정규 Canonical Snapshot의 4주와 일간. 원본 불변
- 대운: 기존 `resolveDayunTemporalContext`로 **양력 연도 전체를 덮는 대운 1개**만 허용. 두 구간 또는 일부 구간이면 계산 중단
- 연운: 기존 입춘일 **00:00 KST** 연구 정책과 E1 확인 대상(2026·2027년) 준수
- 관계: 기존 `deriveStructuralRelationCandidates`에서 **천간 오합 / 지지 육합 / 지지 충 매칭 관계 사실**만 추출. 합화 성립·효과·강도는 인정하지 않음
- 관계 비교: 연운↔대운 1개, 연운↔원국 4개, 대운↔원국 4개 = **9개 쌍**
- 추가 계산: 일간과 연운/대운 천간의 십신 **분류명**만 기록. 결과나 성향을 추론하지 않음

## 해석 금지 조건
1. 원국 구조를 변경하거나 대운의 임시 상태를 영구 속성으로 바꾸지 않음
2. 한 쌍의 충·합만으로 길흉, 사고, 이별, 재물 손실, 성과를 예언하지 않음
3. 여러 관계가 공존한다고 우선순위, 유불리, 점수, 희기신 변경을 임의 결정하지 않음
4. 연운 현대적 해석 14개 규칙의 승인 **0/14** 유지
5. 학파별 판정을 거치지 않고 월운·상품·운영으로 확대하지 않음
