# SA-7D-B1-R13 — 甲日 직접 流年 L2-C 필요성·제한적 외부 후보 감사 v1

> 2026-10-09 · Watchtower-Track: saju-research · Research-only. 신규 직접 인쇄 L1=0건, L2-C=0건. 기존 L2-C=1/8. D1/D2/D3 미승인, Production HOLD. 이 문서는 R4·R12의 연구 근거를 보존하고 새 판면을 확보한 것으로 주장하지 않는다.

## 1. 연구 질문과 결정

[R4 증거 충분성 및 반환 계약](sa7d-b1-r4-evidence-sufficiency-and-handoff-v1.md) 및 [R12 정책 패킷](sa7d-b1-r12-naming-and-annual-temporal-owner-decision-packet-v1.md)을 비교한 결론:

| 경로 | 심사할 주장 | 역사적 L2-C 8/8의 필요 여부 |
|---|---|---|
| T-COMP | 日干×비교干 → 十神 분류계산의 일관성 | **필수 논리적 선행조건이 아님.** L1·L2-M 일반 방법, 음양·오행, 시대별 라벨 가교, D1 명명규약, D2 기간·회귀 검증은 별도 필요. 계산 승인 자체는 HOLD |
| T-HIST | 특정 고전 인쇄본에서 甲日과 특정 실제 流年을 정확한 십신명으로 **직접** 명명했는가 | **직접 역사 주장마다 그 대상 L2-C가 필요.** 현재 甲→辛 正官만 1/8, 나머지 7/8 미확보 |
| T-TEMP | 특정 시각의 연간/연주 효력기간 | L2-C 증가로 해결되지 않음. 공식 관보 원문·D2 소유자 기간 정책·정밀도 HOLD |
| T-SEMANTIC | 현대 Annual 개인 사건·주제 의미 | 고전 사례 8/8 확보해도 자동 승인 불가. Annual-specific source authority와 reviewer·Bridge·Engine 심사가 독립 요구 |

따라서 **7건 일괄 스캔을 실행하지 않는다.** 필요한 역사적 직접 인용은 사건별 원전 검증하되 계산 계약과 제품 의미에 대한 별도 결정은 소유자에게 반환한다. 일반 역사적 十神 명칭 L1 + 流年 방법 L2-M의 논리적 합성은 L2-D 연구 추론일 뿐 L2-C로 올릴 수 없다.

## 3. 제한적 외부 검색 — 전사는 L0 단서이며 인쇄 직접 증거가 아니다

검색은 해당 甲日×연간+명칭이 한 구절에 공존하는지 좁게 확인했다. 원본 PDF 판면과 원본 전체 해시는 이번에 새로 대조하지 않았다.

| 후보 | 웹 전사에서 관찰한 문구·역할 | 정확히 부족한 것 / 판정 |
|---|---|---|
| C13-01 **우선 검증 후보, 甲→壬** | [『淵海子平』 현대 전사](https://www.chinese-classics.org/read/shushu/mingli/yuan-hai-zi-ping/001) 正財論에 戊子·丁巳·甲辰·丙寅 명식, “六十五歲，逢壬辰年死矣”. 甲辰日과 **특정 壬辰年**은 같은 이야기에 있다 | 해당 壬辰 流年을 정확히 “偏印”이라 부르는 인쇄 문구 **미확인**. 인접 癸亥身旺運·印綬는 대운이나 일반 인성 해석이지 壬辰年 명칭이 아님. **ANNUAL_CASE_WITHOUT_TARGET_LABEL / L0**, 신규 L2-C 0 |
| C13-02 **甲→丁 일반 대응** | [『千里命稿』 편집 전사](https://www.gujifu.cn/wen/130.html) 起例問答에 “甲木日干，遇丁火 … 即傷官也”, 十神 검사표 | 특정 丁流年이라는 **유년 시간역할 없음**. L0 general pair. 이 편집본을 1935 第一集 동일 판면으로 재단정 금지 |
| C13-03 **甲→己 다른 시간 역할/텍스트 상이** | [『三命通會』 卷五 전사](https://www.shidianguji.com/zh/book/HY1521/chapter/1knwennx4qwp8)의 歲帶正馬 절: “甲日午年己”로 표기, [『欽定古今圖書集成』 관련 전사](https://zh.wikisource.org/wiki/欽定古今圖書集成/博物彙編/藝術典/第605卷)는 “甲日午年巳” 형태 | **年柱/歲帶 문맥**과 **흐르는 연도 流年**을 혼동하면 안 됨. 서로 다른 전사 글자 己/巳의 직접 인쇄 판면도 미대조. L0 NATAL_OR_UNRESOLVED_TEXT, L2-C 0 |
| C13-04 **다른 일간** | [『命理探源』 推流年法 전사](https://tianjihq.com/zh-CN/learn/books/mingli-tanyuan/2)의 庚金日主×乙卯年×正財主事; R4의 1937 NLC PDF p79-80 직접 판면 기록과 교차 | **庚日은 甲日이 아니므로** B1에 포함 금지. L2-M 방법 및 OTHER_DAY_STEM |
| C13-05 **기존 한 건 중복** | [『千里命稿』 應運篇下 전사](https://www.suanzhun.net/book/250.html)의 英王 甲木日元·辛亥年正官 | 기검증 1935 인쇄 甲→辛 직접 사례의 또 다른 전사. **같은 사건 재게시를 +1 하지 않음** |

**추가 시간계약 단서, T-TEMP가 아닌 Natal 한정:** [『千里命稿』 온라인 起例問答](https://www.gujifu.cn/wen/130.html)에는 “推年以立春為標準”와 **출생 시점의 年柱를 입춘 전·후에 나누는 사례**가 보인다. 이 온라인 편집 전사는 **출생 연주 계산의 L0 후보**로만 보존하며, 현대 명하의 연운 목표시점에 대한 D2 입춘 기간정책의 승인이나 2026 공식 관보 시각 검증으로 승격하지 않는다.

**신규 고전 인쇄 L1 = 0, 신규 B1 L2-C = 0.** C13-01의 壬辰年을 “偏印”이라고 **고전이 직접 말했다는 식으로 바꾸지 않는다**.

## 4. 재진입 및 정지 규칙

| 우선순위 | 신규 연구 진입 조건 | 제한된 수행 범위 | 중단 조건 |
|---|---|---|---|
| P0 계산 계약 | D1/D2/계산 owner가 구체 승인 심사 목적을 지정 | R4 T-COMP, R12 13개 미실행 fixture, 입력의 role/timezone 및 역사 raw label 차이 전달 | 정책 미승인 시 연구반환; TS 타입·제품·Monthly 수정 금지 |
| P1 甲→壬 사례 | **정확한 책·판본·쪽**과 壬辰流年에 “偏印”을 직접 붙이는 유력 문구/판면 리드가 확보 | 그 한 명례에서 甲辰日·실제 壬辰年·偏印의 동일 맥락, 인쇄판 면/해시/판본을 제한 검증 | 정확 十神 단독 표기 없으면 ANNUAL_CASE_WITHOUT_TARGET_LABEL로 종료 |
| P2 甲→乙 이름 | D1 lexical owner가 특정 학파·시대의 명칭 비교를 요청 | 명대 劫財敗財/敗財, 후대 劫財 별개 저본 비교 및 특정 年干 직접 인용 유무 | 일반 甲乙 劫財 L1을 유년 직접 L2-C로 자동 치환 금지 |
| P3 甲·丙·丁·己·癸 | 日干과 특정 年干+정확 十神 이름 **동시 위치**가 제시된 실제 소스 리드 | 해당 서지와 소수 판면만 심사 | 일반 분류/원국/大運/歲運 합성만 발견되면 제외 |

검색은 **원전 리드 1개·한 서지 객체·필요 최소 페이지 단위**가 기본이다. 원본 다운로드 HTTP 429 등 차단 시 대형 CI나 반복 재시도 금지. 소유자 결정 이전에는 8/8을 출시 조건으로 삼지 않는다.
