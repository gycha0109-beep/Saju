# R147 — Interaction directionality counterexample registry

Date: 2026-09-28  
Track: saju-research  
Status: research-only

## Purpose

R147 separates four concepts that must not be collapsed:

1. directed relation identity
2. source-bounded actor→target direction
3. directional effect asymmetry observation
4. symmetric structural pair identity

The registry is a counterexample set, not a direction resolver.

## Registry shape

R147 contains 32 rows:

- 8 R056 directed punishment relations
- 6 R059 source-bounded actor→target cases
- 1 R057 directional-asymmetry observation
- 17 symmetric structural-pair controls
  - 5 heavenly-stem combination pair identities
  - 6 branch-clash pair identities
  - 6 branch-harm pair identities

## Directed punishment

R056 records eight directed non-self punishment relations.

Two are the reciprocal 子→卯 and 卯→子 edges. The reverse exists because both directions are separately present in governed data.

The remaining six relations belong to directional cycle structures:

- 寅→巳
- 巳→申
- 申→寅
- 丑→戌
- 戌→未
- 未→丑

R147 does not infer the missing reverse edges.

An explicitly stored reverse relation and an inferred reverse relation are different things.

## Source-bounded actor→target direction

R059 records six direct interaction cases with actor and target roles.

R147 preserves the source direction exactly.

It does not authorize:

- actor/target reversal
- actor relation kind as universal precedence
- a total relation order
- first-match settlement
- executable conflict resolution

A source says that one relation resolves or affects another in a bounded case. That does not establish that relation kind as globally stronger.

## Structural symmetry versus effect symmetry

R051 five-combination identities, R055 clash pairs, and R057 harm pairs are used as symmetric structural controls.

The stored order of pair members is not semantic direction.

This is especially important for 酉戌.

R057 has:

- a symmetric structural 害 pair identity: 酉戌
- a separate source-bounded DIRECTIONAL_ASYMMETRY_OBSERVED modifier

Therefore:

> symmetric pair identity does not imply symmetric effect.

The opposite shortcut is also rejected: one directional-asymmetry observation does not establish a universal directional-effect resolver.

## Input order

R141 already demonstrates 60 order variants where representation is invariant to input enumeration.

R147 therefore rejects:

- array order creates actor/target direction
- first enumerated relation gains precedence
- left/right storage order becomes relation direction

Direction must come from governed relation identity or source-bounded evidence, not implementation order.

## Rejected collapses

R147 explicitly rejects:

- directed punishment as unordered pair
- missing reverse edge as implicit reverse
- separately explicit reverse edge as derived reverse
- R059 actor/target reversal
- R059 actor direction as global precedence
- pair storage left/right as interaction direction
- symmetric pair identity implies symmetric effect
- directional asymmetry observation as universal directional effect
- directional relation implies harm
- directional relation implies severity
- array order creates direction
- first enumerated relation creates precedence
- direction as numeric weight
- direction as executable settlement
