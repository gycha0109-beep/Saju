## 1. Purpose

R131 opens the R131–R140 Structure / methodology composition group.

Its purpose is not to derive a new 格局 candidate or decide whether a 格局 is established.

Its purpose is to formalize the semantic boundaries that the governed repository evidence already requires.

## 2. Why this boundary is necessary

The repository contains source-observed material at several different levels:

```text
canonical chart substrate

source selection signal

source semantic use

source pattern wording

canonical candidate identity

source establishment clause

canonical executable establishment predicate

source outcome layer

canonical terminal establishment state

emitted pattern fact
```

These levels are not interchangeable.

The most dangerous shortcut is:

```text
source evidence exists
-> therefore canonical candidate exists
-> therefore establishment can be decided
```

R131 rejects that shortcut.
