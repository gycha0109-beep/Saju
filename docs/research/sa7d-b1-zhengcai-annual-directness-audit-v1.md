## 1. 검증 주장 분해

**검증하고 싶은 한 명제:** `甲`인 일간이 **구체적인 `己`천간 유년**을 만날 때 그 해당 유년을 `正財`로 판정했다는 **같은 역사적 원전 문맥**의 직접 판면 증거.

`甲日` 출생 원국의 己는 正財라는 일반 L1만으로 이 요구를 만족하지 않는다. 반대로 `先觀歲與日干`이라는 유년 해석 지침만으로 대상 이름 `正財`를 결정할 수도 없다.

## 4. 다음 직접 증거 검색의 중단 기준

### 목표 검색 단위

- 가능성 높은 범위: `甲日 / 甲木日主 / 日元甲`와 구체 연도의 `己巳 / 己卯 / 己丑 / 己亥 / 己酉 / 己未年`를 결속한 명례, 같은 문맥의 `正財` 직접 명칭.
- 정확한 년도만으로 `己`天干 유년인지를 분리하고, 해당 세운과 대운/출생 年柱를 혼동하지 않는지 판별.

### 허용 결과

- **DIRECT-PASS**: 특정 판본의 같은 인쇄문맥에서 `甲日 + 己干 유년 + 正財` 결속 및 소장본·쪽수·원문·SHA 검증 성공.
