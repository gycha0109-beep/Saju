## 1. 발견한 문제

공통 판단은 월령에서 복수 신호가 확인되면 다음을 보존한다.

- 각 지장간 신호와 정확한 십신
- 천간에 같은 글자가 드러났는지
- 통근·지원·제약·구응 후보
- 천간합 및 월지에 닿는 지지 관계
- 복수 신호의 우선순위·격국 성립을 확정하지 않는 상태

하지만 Reader의 최종 분야 문단은 pattern.anchor가 없을 때 chart.month.god 하나를 기본값으로 사용했다. 이 때문에 앞부분에서는 복수 신호를 설명하면서, 정작 직업·사업·재물·관계의 분야별 핵심 문장은 지지 대표 십신 한 가지로 다시 축약될 수 있었다.

## 2. 수정 내용

파일: src/preview/whole-chart-reading.ts

1. 월령 상태가 competing_month_signals이고 실제 신호가 둘 이상이면, monthStemObservations의 모든 십신을 분야별 관점으로 변환한다.
2. 동일 십신 계열은 묶되 서로 다른 계열은 각각 문장으로 유지한다.
3. 복수 신호 상황에서는 월지 대표 십신 하나의 분야 문단을 대체 문단으로 사용하지 않는다.
4. 의미 서명도 단일 family 대신 실제 관측된 복수 계열을 기록한다.
5. 기존 단일 후보·단일 투간·국소 구응 경로는 그대로 둔다.

출력 예시의 구조:

- 정인(학습과 지원) 관점의 직업 해석
- 정관(책임과 규범) 관점의 직업 해석
- 두 관점 중 하나를 대표 격국이나 최종 우선 결론으로 선택하지 않음

## 3. 회귀 테스트

파일: test/whole-chart-judgment.test.ts

기존 복수 월령 신호 fixture를 재사용해 다음을 추가 확인한다.

- 복수 신호의 십신별 분야 관점이 모두 Reader 문장에 포함된다.
- 월지 대표 십신에서 비롯된 단일 fallback 문장이 섞이지 않는다.
- 의미 서명에 복수 월령 계열이 기록된다.

이 테스트는 새 명리 효과나 우선순위를 만들지 않는다. 이미 관측된 신호가 최종 분야 문단에서 사라지지 않는지 확인한다.
