# SA-7D-B1 — 『千里命稿』 1935년 원본·전사판 본문 대응 감사 (Fail-closed)

> Watchtower-Track: `saju-research` · Research evidence only. 甲→乙 劫財의 **명대 인쇄 직접 명칭 L1 및 개별 연운 L2에 승인 권한 없음**. `bridgeReentryReady=false`, `Production=HOLD`.

## 1. 새로운 저술 내 정확한 현대 명칭 문장과 소스 수준

- **『千里命稿』**(韋千里, 1935년 출판으로 알려진 저술)의 온라인 전사문 `比劫祿刃篇 > 劫財之構成`에: `與我同類而異性者是也。如甲日遇乙，甲為木，乙亦為木，是同類了。甲為陽性，乙為陰性，是同類而異性也。故乙為甲之劫財。`라는 문장이 기재됨.
- 서로 다른 공개 전사 출처: [중국철학서 전자화계획 CText](https://ctext.org/wiki.pl?chapter=447084&if=gb) · [온라인 전사 2026](https://libokang.com/zh-hant/guji/bazi/千里命稿/4/) · [『千里命稿』 정리 출판의 서지(2011년)](https://books.google.com/books/about/千里命稿.html?id=0NRnAgAAQBAJ). **이 전사 일치는 1935년 원본 인쇄 판면의 확인과 동등하지 않음**.
- 본문 수준 판정: `L0_LATER_AUTHORIAL_TEXT_TRANSCRIPTION_LOCATOR` — `甲→乙`에 `劫財` 단독 명칭을 붙이는 **근현대 명칭 관행의 문헌 추적 단서**. 1935년 해당 초판 판면과 실제 페이지 결속 전까지 `L1_VERIFIED`로 올리지 않음.

## 2. 1935년 국가도서관 실물판본 확인 및 비교

- 별도 인쇄 증인: **『千里命稿』 韋氏命苑, 民國24[1935]**. 국가도서관 PDF `NLC416-01jh000372-10197_千里命稿.pdf`; Wikimedia Commons [원전 서지 및 123페이지 PDF](https://commons.wikimedia.org/wiki/File:NLC416-01jh000372-10197_千里命稿.pdf).
- Commons 선언 원본 SHA-1 `24d0916963de2f7571075af78c16c337cdbdad25`; 123 PDF 페이지. **원본 PDF 전체를 내려받아 로컬 SHA를 검증한 것이 아니라 Commons imageinfo에 수록된 선언값이다**.
- Commons 공식 API가 발행한 PDF 페이지 JPEG 22쪽을 실제 수신, 사진별 SHA-256과 아티팩트 manifest를 대조한 뒤 수동 판면 판독:
  - 첫머리 6쪽: PDF **3, 12, 22, 32, 42, 50쪽**.
  - 중간 8쪽: PDF **56, 62, 68, 72, 76, 80, 84, 88쪽**.
  - 뒷부분 8쪽: PDF **94, 99, 104, 108, 112, 116, 120, 123쪽**.
- 실제 확인한 1935년 인쇄본: 서문에 이어 `千里命稿 第一集` 표제를 달고 팔자 명례·간지별 사례 풀이를 전개. PDF 약 **120쪽에서는 권말 출판 관련 광고·안내**, 123쪽에서는 소장·끝장 정보. 위 22쪽에서 온라인 전사의 `比劫祿刃篇` 표제 또는 `故乙為甲之劫財` 정확한 문장은 발견되지 않음.
- 그러나 **22/123쪽만 직접 열람했으므로**, 저술 전체에 그 문구가 없다고 **전면적인 부재를 주장해서는 안 됨**. 온라인 전사본과 1935년 이 PDF가 같은 편집 상태·수록 범위를 가진다고도 증명되지 않음. 명칭 일치만으로 본문을 원본에 가상 결속하지 말 것.

## 3. 서로 다른 시대의 명칭을 억지로 합치지 않는 계약

| 주장 | 근거 상태 | 허용된 판단 |
|---|---|---|
| 명대 『刻京臺增補淵海子平大全』 제1책 PDF 10쪽 `甲→乙 爲劫財敗財` | **명대 실물 인쇄 L1 복합 명칭 VERIFIED** | 그대로 `劫財敗財` 역사적 복합 범주 유지 |

| 『千里命稿』 온라인 전사 `故乙為甲之劫財` | **텍스트 단서 L0 VERIFIED; 1935 인쇄 판면 未BOUND** | 후대/근현대 용어 선택의 후보증거로만 기록 |

| `甲→乙 劫財` 명대 일간 **독립 이름** L1 | **INSUFFICIENT** | 기존 7/8 유지 |
| 특정 `甲日 × 乙流年` → `劫財` 직접 L2 | **INSUFFICIENT** | 대상 8/8 Annual HOLD 유지 |

**정책적 결론:** 명대 `敗財`를 현대 `劫財`로 별도 용어 정책 없이 강제 대체하지 않는다. 단일 정확 이름 검증은 *작품·판본·인쇄 구절·방향·관계 범위*가 모두 결속될 때만 승인. 일간 L1이 승인돼도 Flow-year 직접 의미론 L2 및 현대 예측 테마는 별개 증거가 필요하다.

## 4. 재개 조건과 권한 경계

- 1935년 전사 `比劫祿刃篇`을 실제 소장본의 **정확한 인쇄 페이지**에 맞추거나, 동일한 저술의 독립 출판본을 서지·페이지 단위로 확보할 때만 print-bound L1 재검토.
- 별개 고전의 태세·유년 조항에서 8개 대상별 날짜 방향과 **정확한 개별 十神 名**을 검증한 뒤에만 Annual L2 재검토. 이미 직접 검증된 `庚年剋甲日爲偏官`, `甲日剋戊年爲偏財` 2개 관계는 다른 대상이므로 8개에 상속 금지.
- `MING_L1=7/8`, `TARGET_ANNUAL_L2=0/8`, `sourceSupportGrade=INSUFFICIENT` for all 8, `bridgeReentryReady=false`, `Production=HOLD`. Reader/Engine/Bridge/Monthly 권한 승격 없음.
- PDF 추적용 임시 워크플로는 실행 후 **실험 브랜치에서 삭제**. 본 clean PR에 새로운 CI·scripts·제품코드 반영 없음.
