## Concrete completion examples

The commentary gives bounded rescue examples:

```text
癸生亥月 + 卯未來會
庚生申月 + 子辰會局
```

Each example contains the third member already supplied by the month branch. These are evidence for a **complete three-member configuration**, not proof that `卯未` or `子辰` alone universally has the same effect.

## Partial-combination result

The selected direct source does not establish a complete universal taxonomy for every two-of-three subset.

Later/public descriptions are not uniform:
- some reserve 半合 for pairs containing the middle/旺 branch;
- some call the pair missing that branch 拱合;
- some use 半合 more broadly.

R053 therefore records all two-of-three subsets as inventory only and leaves their exact taxonomy/effect unresolved.
