# R169 — 카탈로그 및 인쇄면 provenance 결속

> 날짜: 2026-10-03
> 상태: 연구 완료 후보
> 트랙: saju-research

## 목적

R168은 命有甲와 庚辛을 《子平真詮》 본문층에, 申酉를 徐樂吾 평주층에
분리해 결속했다.

R169은 그 가운데 沈氏 본문층 두 후보를 국가도서관 소장 스캔의
카탈로그 식별 정보와 실제 인쇄면 위치에 연결한다.

## 인쇄면 위치

스캔 직접 확인 결과:

- 「論行運成格變格」 시작: 인쇄면 四十九
  - PDF 0기준 인덱스 57
  - PDF 1기준 순번 58
- 후보 문구가 있는 면: 인쇄면 五十
  - PDF 0기준 인덱스 58
  - PDF 1기준 순번 59

인쇄면 번호와 PDF 내부 순번은 서로 다른 식별자이므로 별도로 보존한다.

인쇄면 五十에서 다음 후보 표면을 직접 확인했다.

- 命有甲
- 命有庚辛

따라서 R169에서 命有甲와 庚辛은:

- 소장 스캔 witness 식별자 결속
- 절 위치 결속
- 실제 인쇄면 위치 결속

까지 진전한다.

## 申酉

같은 인쇄면에서 申酉를 沈氏 본문 후보 표면으로 확인하지 않았다.

R168에서 확인한 대로 申酉는 徐樂吾 평주층의 설명으로 유지한다.
이를 沈氏 본문층으로 자동 승격하지 않는다.

## 별도 역사 판본 후보

국가도서관에는 다음 별도 판본도 공개돼 있다.

- 파일 식별자: NLC416-13jh002326-46443
- 서명: 淵海子平 子平真詮
- 권: 第2卷
- 교감자: 秦慎安校勘
- 발행자: 文明書局
- 간행: 民國十五年[1926]
- 소장정보: MG/B992.3/33
- 카탈로그 설명에 論行運成格變格 절 수록

그러나 R169에서는 아직 이 스캔에서 목표 문구와 실제 인쇄면을 직접 확인하지 않았다.

따라서 이 판본은 독립 역사 witness가 아니라
'검증 대기 중인 독립 판본 후보'로만 기록한다.

## 현재 진전

命有甲 / 庚辛:

- 작품·소장 스캔 식별: 결속
- 발행자 표기: 결속
- 절 위치: 결속
- 인쇄면 五十: 결속
- 직접 본문 표면: 결속

아직 미확보:

- 비판판 지위
- 현재 소장본의 정확한 간행연도
- 별도 역사 판본에서 같은 후보 표면의 직접 검증
- 최소조건·충분조건을 판정할 근거
- 申酉의 沈氏 본문층 직접 witness

## 권한 경계

위치와 판본 provenance가 강화됐다고 해서 의미 규칙이 자동으로 강화되지는 않는다.

R169은 다음을 승인하지 않는다.

- 命有甲의 rescue 최소조건/충분조건
- 庚辛의 counterforce 충분조건
- 申酉 개별 또는 그룹 충분조건
- 기제 우선순위
- 최종 변화 판정
- 실행 resolver
- 해석 claim
- 제품 권한

## 다음 작업

다음 우선순위는 1926년 文明書局 第2卷 스캔에서
해당 절의 실제 목표 문구와 인쇄면을 직접 찾는 것이다.

그 확인에 성공해야만 별도 역사 판본을 독립 보강 witness 후보로
다시 평가할 수 있다.
