# R171 — 후대 인쇄 전승 witness 결속

> 날짜: 2026-10-03
> 상태: 연구 완료 후보
> 트랙: saju-research

## 목적

R170은 서로 다른 도서관·파일·카탈로그 기록을 곧바로 독립 textual witness로
계산하지 않도록 차단했다.

R171은 별도 후대 인쇄 자료인 袁樹珊의 《命理探源》에서
「論行運成格變格」 문단이 어떻게 재수록되는지 기록한다.

## 자료

국가도서관 소장 공개 스캔:

- 파일 식별자: NLC416-07jh011647-5318
- 서명: 命理探源
- 저자: 袁樹珊
- 발행: 星相研究社
- 간행: 民國26[1937]
- 대상 위치: 卷下 / 評斷 / 論行運成格變格

공개 URL:

https://commons.wikimedia.org/wiki/File:NLC416-07jh011647-5318_%E5%91%BD%E7%90%86%E6%8E%A2%E6%BA%90.pdf

## 확인된 전승 표면

검색 인덱스에 잡힌 해당 절 전사에서 다음 문구가 재수록된다.

- 運逢戊而命有甲
- 命有庚辛之類是也

따라서 命有甲와 庚辛은 1937년 별도 인쇄 자료에서도
동일 절의 전승 표면으로 확인된다.

그러나 이 사실만으로 《命理探源》을 沈氏 원본과 독립된 원전으로
계산하지 않는다.

현재 분류는:

    LATER_PRINTED_TRANSMISSION_WITH_EDITORIAL_PROVENANCE_NOTE

이다.

## 편집 주석

같은 절 뒤의 편집 주석은 다음 전승 정보를 언급한다.

- 原刊
- 闕文
- 嘉慶年間抄本

즉 후대 편집자가 기존 간행본의 결락을 문제 삼고
嘉慶 연간 필사본을 입수해 보완했다는 전승 설명이 존재한다.

하지만 현재 연구 자산에는 그 嘉慶 필사본 자체가 없다.

따라서:

- 필사본 실물 witness: 미결속
- 소장처/청구기호: 미결속
- 쪽/folio: 미결속
- 독립 textual witness: 미승인

으로 유지한다.

## OCR/검색 인덱스 경계

이번 단계에서 문구 재현은 검색 인덱스/OCR 전사를 통해 확인됐다.

대용량 PDF의 목표 판면 직접 렌더링은 안정적으로 완료되지 않았으므로
시각적 판면 검증 완료로 기록하지 않는다.

즉:

    OCR/검색 추출 확인 != 목표 판면 직접 검증

이다.

## 申酉

이번 沈氏 본문 전승 표면에서도 申酉를 별도 후보로 승격하지 않는다.

R168 이후와 동일하게 申酉는 徐樂吾 평주 층과 분리한다.

## 현재 의미

R171은 텍스트 전승을 한 단계 보강한다.

하지만 다음은 여전히 확립되지 않는다.

- 命有甲가 rescue의 최소조건이라는 주장
- 命有甲가 rescue의 충분조건이라는 주장
- 庚辛이 counterforce의 충분조건이라는 주장
- 申酉의 沈氏 본문층 존재
- 기제 우선순위
- 최종 변화 판정
- 실행 resolver
- 해석 claim
- 제품 권한

## 다음 작업

다음 단계는 두 갈래다.

1. 《命理探源》의 대상 판면을 직접 렌더링해 인쇄면 위치까지 결속
2. 편집 주석이 언급한 嘉慶年間抄本의 실제 계보·소장정보를 추적

둘 중 어느 것도 확보되기 전에는 독립 역사 witness 수를 증가시키지 않는다.
