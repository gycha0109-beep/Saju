## Source-stratum boundary

It does not, in the cited wording alone, fully specify a modern implementation contract for:
- exact Heavenly-Stem comparison;
- exact Earthly-Branch comparison;
- whether both stem and branch must match/oppose;
- whether one component is sufficient;
- whether the same rule automatically applies to 年/月/時 pillars.

Therefore R078 preserves the literal relation wording and target scope instead of backfilling a modern algorithm.

## Effect boundary

The adverse wording is retained as source evidence, but not promoted to:
- guaranteed disaster;
- guaranteed death;
- guaranteed financial loss;
- guaranteed family event;
- fixed severity score.

The broader source itself repeatedly requires context, rescue, luck/natal composition, and developed/not-developed state in temporal judgment.
