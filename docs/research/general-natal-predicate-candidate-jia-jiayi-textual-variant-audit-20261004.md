# R173 — 壬生午月 사례의 甲 / 甲乙 텍스트 변이 감사

> 날짜: 2026-10-04
> 상태: 연구 완료 후보
> 트랙: saju-research

## 목적

R172는 동일한 甲가 서로 다른 구성에서 반대 역할로 설명된다는 점을 확인했다.

그러나 부정 사례 자체의 공개 전사본을 더 대조하면 표면이 하나로 고정되지 않는다.

일부 witness:

    本命有甲乙之類是也

다른 witness:

    本命有甲之類是也

R173은 이 차이를 보존하고, 특정 표면을 임의로 정본으로 선택하지 않는다.

## 현재 확정 가능한 것

두 변이 모두 다음 구성은 공유한다.

- 壬 일간
- 午 월
- 운에서 己官 투출
- 원국에 최소한 甲 표면 존재
- 成格而不喜 계열

따라서 R172의 핵심 대조:

    동일 甲가 다른 구성에서 같은 역할을 하지 않는다.

는 유지된다.

왜냐하면 甲는 현재 관찰된 모든 변이에 공통으로 존재하기 때문이다.

## 현재 확정할 수 없는 것

乙는 다르다.

- 甲乙형에서는 乙가 보인다.
- 甲형에서는 乙가 보이지 않는다.

그러므로 현재 자산만으로는:

- 乙가 원문에 반드시 포함되는지
- 甲乙가 하나의 묶음 조건인지
- 乙가 甲와 같은 역할을 갖는지
- 乙 단독으로도 같은 결과가 가능한지

확정할 수 없다.

또한 甲형 witness에서 乙가 적혀 있지 않다는 사실을
실제 원국에 乙가 없다는 뜻으로 해석할 수도 없다.

## 다수결 금지

현재 공개 전사 수만 보면 甲乙형이 더 많다.

그러나:

    공개 전사 수가 많다 = 정본

은 성립하지 않는다.

여러 사이트가 같은 현대 전사를 재복제했을 수 있고,
판본 계통의 독립성도 아직 결속되지 않았다.

따라서 witness 개수를 정본 투표나 의미론 가중치로 사용하지 않는다.

## 후속 필요 근거

다음이 필요하다.

1. 甲형 witness의 실제 판본 식별
2. 甲乙형 witness의 실제 판본 식별
3. 각 변이의 인쇄면/folio
4. 판본 계통 대조
5. 해당 사례에서 乙의 역할을 설명하는 별도 자료
6. 甲와 乙의 기능 차이를 검증할 대조 사례

## 권한 경계

R173은 다음을 확립하지 않는다.

- 甲형 정본
- 甲乙형 정본
- 乙의 독립 의미 predicate
- 甲乙 묶음 predicate
- 甲/乙 상호교환 가능성
- 정확한 최소조건
- matching 충분조건
- 결과 충분조건
- 실행 resolver
- 해석 claim
- 제품 권한

## 다음 작업

다음 우선순위는 의미론 추론을 더 하는 것이 아니라,
두 변이가 실제 어떤 인쇄 판본에 대응하는지를 결속하는 것이다.

그 뒤에야 乙가 단순 전사 차이인지, 실제 판본 차이인지,
그리고 의미 연구 대상으로 남겨야 하는지를 판단할 수 있다.
