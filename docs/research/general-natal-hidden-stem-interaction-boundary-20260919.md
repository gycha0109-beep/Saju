## Verified distinctions

### 1. Hidden membership
A branch can contain multiple hidden stems. Membership alone does not establish a usable interpreted role.

### 2. 透干
The commentary states 透則用清 and explains 透干 as a hidden branch stem appearing in the Heavenly Stems.

Bounded meaning: manifestation / clearer usable surface.

### 3. 會支
The commentary states 會則力大 and gives branch-meeting examples that form a larger configuration.

Bounded meaning: configuration-level force can increase or the branch configuration can change.

### 4. 沖 / interaction movement
The 辰戌 example describes 土動 under clash, but the result is not 'all hidden stems become visible'. Instead, the exposed 壬 loses effective connection to the month-command context.

Bounded meaning: interaction can move, disrupt, resolve, or reconfigure context.

## Rejected generic activation model

- interaction event -> all hidden stems activated
- clash -> hidden stem equals visible stem
- meeting -> each contained hidden stem independently active
- hidden membership -> usable role
- activation -> fixed strength score
