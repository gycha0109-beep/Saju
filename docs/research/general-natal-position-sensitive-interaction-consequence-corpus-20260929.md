# R149 — Position-sensitive interaction consequence corpus

Date: 2026-09-29  
Track: saju-research  
Status: research-only

## Purpose

R149 records a narrow but important fact:

> the same structural interaction family can lead to different bounded consequence classes when its positional topology changes.

It does not create a general position-strength formula.

## Corpus shape

R149 contains 20 rows:

- 16 three-combination placement replay rows
- 4 position-boundary controls

The 16 replay rows cover all four canonical three-combination families across four I46/I47 placement classes:

- embedded within bureau span + tight adjacency
- embedded within bureau span + non-tight
- outside bureau span + tight adjacency
- outside bureau span + non-tight

Each family therefore has four placement variants.

## Three-combination positional consequence

The consequence classes are:

- embedded+tight → DETERMINISTIC_SOURCE_BOUNDED_BREAK
- embedded+non-tight → CONTEXTUAL_INTACT_OR_DAMAGED_UNRESOLVED
- outside+tight → CONTEXTUAL_INTACT_OR_DAMAGED_UNRESOLVED
- outside+non-tight → NO_DIRECT_SETTLEMENT

This is replayed for:

- 申子辰
- 巳酉丑
- 亥卯未
- 寅午戌

The deterministic result is narrow.

It does not mean:

- adjacency always means stronger
- embedded always means break
- outside always means survival
- clash always wins
- position has a numeric force value

## I47 boundary

I47 makes the positional classification executable only inside its specific challenge-root evidence contract.

It classifies:

- whether the external clash counterpart is embedded in the min/max bureau-participant span
- whether it is immediately adjacent to the directly clashed bureau participant

Only one source-bounded embedded+tight break can emit BROKEN_BY_TIGHT_EMBEDDED_CLASH.

I47 still blocks:

- generic post-interaction bureau state
- damage magnitude
- multiple-clash aggregation
- root destruction
- effective mechanism force
- usefulness/harmfulness
- numeric scoring
- strong/weak classification

R149 preserves the same boundary.

## Four position controls

### R055 — position distance

R055 verifies POSITION_DISTANCE as a material clash-context axis.

It does not authorize a proximity classifier, numeric weight, or clash-effect resolver.

### R057 — palace position

R057 preserves PALACE_POSITION among Liu Hai context axes.

This does not establish a universal palace-position effect table or severity ladder.

### R059 — position and nature

R059 C6 states that a structural match may be ineffective depending on position and nature and that there is no single fixed mode.

R149 therefore rejects position-only deterministic settlement.

### R073 — temporal position modulation

R073 preserves a bounded position-context modulation for latent temporal activation.

R149 keeps this as a cross-domain control.

It cannot be reused as:

- interaction strength
- year/month/day/hour global severity
- event prediction
- clash/combination settlement

## Position versus precedence

R148 already blocks a global precedence ladder.

R149 keeps position consequence separate from precedence.

A positional topology can make a bounded consequence available without creating:

- relation-kind priority
- global clash precedence
- numeric relation weight

## Rejected shortcuts

R149 rejects:

- raw pillar distance as interaction strength
- adjacency always stronger than non-adjacency
- embedded always breaks
- outside always preserves
- palace position as a universal effect table
- year/month/day/hour as a global severity ladder
- R073 temporal modulation as interaction strength
- position alone as relation effectiveness
- position alone as favorable/harmful polarity
- position as root destruction
- position as effective mechanism force
- position as event prediction
- I46 placement result generalized to other relation families
- position class as global precedence
- position class as numeric weight
- multiple-clash distance aggregation
- no direct settlement as intactness
- contextual unresolved as damaged or intact

## Authority

R149 remains research-only.

It observes:

- same structure + different position can produce different bounded consequence classes
- bureau-span embeddedness can matter
- tight adjacency can matter
- position distance can matter
- palace position can matter as context
- position and relation nature can jointly matter

It does not authorize:

- generalized position resolver
- raw-distance scoring
- palace-position effect table
- pillar severity ladder
- polarity from position
- root destruction from position
- mechanism force from position
- event prediction from position
- numeric position weight
- global position precedence
- executable generic settlement
- engine admission
- InterpretationClaim emission
- preview promotion
- production promotion

R150 should next derive the minimal interaction predicate set required for executable claims while preserving the unresolved boundaries accumulated through R141–R149.
