## What the actual body establishes

### 1. The Day Branch spouse-palace location is genuinely role-neutral

Printed p.53 places the Day Branch at the spouse position / spouse palace. More importantly, printed p.56 explicitly states that **both male and female charts use the Day Branch as spouse palace**.

This means the source does not make the *location* of spouse palace depend on native sex.

```text
male chart   -> Day Branch spouse palace
female chart -> Day Branch spouse palace
```

That is a real role-neutral positional rule.

### 2. The position is operational, not merely a label

The worked cases use the actual Day-Branch content as spouse-relationship evidence even when that content is not the inherited spouse star.

Examples directly reviewed include:

- a female case where a Day-Branch `比肩` is interpreted as the spouse-palace relationship and as an equal relationship with the spouse;
- a male case where the Day-Branch same-element relation is read as a spouse who helps the native and as evidence of a strong spouse palace;
- other cases where Day-Branch competition or support is directly carried into spouse-relationship judgment.

Therefore this source is stronger than a source that merely says `日支 = 배우자궁` without using that location operationally.

```text
role-neutral spouse-palace location = ESTABLISHED AS SOURCE FACT
operational Day-Branch spouse reading = ESTABLISHED AS SOURCE FACT
```

## Why this still does not establish one complete role-neutral spouse method

The same body immediately overlays native-sex-conditioned rules on that role-neutral location.

### 3. Spouse-palace evaluation itself remains sex-conditioned

On the same printed p.56 passage, after stating that both sexes use the Day Branch as spouse palace, the source gives different favorable spouse-palace contents by native sex:

```text
male chart:
  財星 or 食傷 in spouse palace -> favorable example

female chart:
  官星 or 財星 in spouse palace -> favorable example
```

It likewise gives different adverse examples by sex, including male-spouse-palace `劫財` and female-spouse-palace `傷官` examples.

So the spouse-palace *location* is neutral while the evaluation layer is not.

### 4. The conventional spouse-star layer also remains sex-conditioned

The worked cases directly retain inherited spouse-star semantics:

- female cases identify the husband through `官星`, including a `正官` husband;
- male cases identify the wife through `財星`, including `正財` and wife-related combination interpretation.

The source therefore uses two layers together:

```text
Layer A: Day Branch spouse palace
  -> same location for male and female charts
  -> actual Day-Branch content can be interpreted as spouse relationship

Layer B: spouse-star / evaluation semantics
  -> native-sex-conditioned branches remain
  -> female husband = Officer branch appears
  -> male wife = Wealth branch appears
```

The source does not publish a replacement rule that removes Layer B's sex branching.
