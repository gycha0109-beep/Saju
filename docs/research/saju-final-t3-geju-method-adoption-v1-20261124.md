# Saju Final — T3 격국 방법 채택 v1

- 결정일: 2026-11-24
- 적용 범위: 여섯 메뉴 공통 원국 판단의 연구·Reader 경로
- 근거: R021/R028~R030, #436/#441/#509/#513/#516 계열의 기존 검토
- 상태: **후보 관측·복수 보존 방식 채택 / 일반 격국 판정기 미채택**

## 1. 결정 요약

격국은 월지 지장간 배열에서 첫 항목을 고르거나, 천간에 드러난 십신 하나를 곧바로 격국으로 확정하는 방식으로 구현하지 않는다.

명하의 T3는 다음 단계를 구분한다.

1. 월령에 실제로 들어 있는 복수의 지장간 구성 확인
2. 해당 구성과 천간 투간의 정확한 연결 관측
3. 월지에 닿는 회합 등 별도 구조 접점 관측
4. 가능한 후보의 공존·충돌 상태 보존
5. 成敗·帶忌·救應 등 성립 결과의 근거가 모두 갖춰진 경우에만 별도 판단

현재는 1~3의 일부 관측 자산과 4의 표현 구조가 존재한다. 5의 일반 실행 판정은 만들지 않는다.

## 2. 채택하는 출처 해석

### 월령 복수성과 투간

子平真詮評注의 월령 관련 구절은 월령에 저장된 내용이 하나가 아닐 수 있고, 투간·회지에 따라 용의 변화가 생길 수 있음을 보여 준다.

따라서 다음을 채택한다.

- 월령 지장간의 복수 구성은 모두 보존한다.
- 실제 투간 위치와 글자 일치를 별도로 기록한다.
- 투간이 하나라고 해서 모든 지지에 같은 선택 규칙을 일반화하지 않는다.
- 후보가 여러 개면 복수 공존 또는 미해결 충돌로 유지한다.

### 寅의 정확한 예시

검토된 원문에는 寅에서 甲을 本主로 설명하고, 甲이 투간하지 않고 丙이 투간한 경우 丙이 作主할 수 있다는 구체 예시가 있다.

이 예시는 다음 범위에서만 사용한다.

- 寅의 해당 원문 사례에서 甲의 본주 역할
- 해당 사례의 투간 대체 관계

이 사례를 모든 12개 월지에 적용하는 일반 본기·중기·여기 매핑으로 확대하지 않는다.

### 성립과 구응

子平真詮評注의 成敗·救應 문구는 단순한 성립/실패 두 값으로 끝나지 않는다. 成中有敗, 敗中有成, 帶忌, 救應 및 별도 인과 전환 표현이 구분된다.

따라서 이 어휘는 내부 연구 표현으로 보존하되, canonical chart-level terminal state나 boolean으로 자동 환산하지 않는다.

## 3. 채택하는 후보 표현

| 상태 | 의미 |
|---|---|
| NO_CANDIDATE | 관측된 후보 없음 |
| SINGLE_CANDIDATE_UNESTABLISHED | 후보 하나가 관측됐지만 성립 판정은 아님 |
| MULTIPLE_COEXISTING | 복수 후보가 함께 관측됨 |
| MULTIPLE_CONFLICT_UNRESOLVED | 복수 후보 사이의 관계·우선순위가 미해결 |
| SPECIAL_TRANSITION_REQUIRED | 건록·월겁 등 별도 전환 검토 필요 |
| INDETERMINATE | 입력 또는 근거가 불충분 |

후보 수와 후보의 source identity는 별도다. 후보가 하나라는 이유로 성립을 확정하지 않는다.

## 4. 현재 코드에 대한 의미 경계

현재 whole-chart-judgment의 month anchor와 pattern state는 분야별 Preview를 위한 월령 신호·지원·제약 관측이다.

다음과 동일하게 취급하지 않는다.

- 공식 格局候補 identity
- 成格 / 破格 판정
- 최종 用神
- 복수 격국의 승자
- 합화·회지의 성립 결과

따라서 메뉴별 해설은 월령 신호와 그에 연결된 근거를 설명할 수 있지만, 현재 anchor를 전통 격국의 확정 이름이나 최종 용신으로 부르지 않는다.

## 5. 금지할 자동화

- hiddenStems 배열 순서로 본기·중기·여기 순위를 부여
- 모든 월지에 寅의 단일 예시를 일반화
- 투간 개수로 격국 우선순위 결정
- 회지 후보를 자동 성립으로 승격
- 월령 후보 하나를 곧바로 성격·직업·재물의 확정 결론으로 변환
- 성립/실패를 단일 boolean으로 축약
- 구응 후보가 존재한다는 이유로 실패를 자동 복구
- 후보가 깨졌다는 이유만으로 종격·화격으로 자동 전환
- 미해결 후보를 LLM이 선택

## 6. 현재 남은 실행 조건

다음 항목은 이미 조사된 범위이며, 일반 문헌 탐색을 반복하지 않는다.

- 월령 지장간 전체에 대한 source-compatible candidate identity
- 전 기둥에 대한 투간·투출 admissibility와 slot scope
- 회지의 선택·변화 효과
- 복수 후보의 공존과 실제 충돌 구분
- 후보별 source clause 입력을 canonical facts에 연결
- 成敗·帶忌·救應의 혼합 결과 표현 및 순서
- 구응·구제의 적용 조건과 우선순위

이 조건이 해소되기 전까지 T3는 후보 관측과 보류 사유를 제공하며, 확정 격국을 출력하지 않는다.
