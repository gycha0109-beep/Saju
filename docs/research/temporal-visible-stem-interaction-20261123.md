## 연결과 표시

기존 Canonical 사실에 결박된 원국 T8은 원국 맥락을 계속 표현한다. 새 T9에는 정확한 기간 T9 주제 주장과 원국 천간의 십신 계산 사실이 입력된다. 두 방향은 하나의 연구 규칙 세트에서 처리되고 각 요청·절입 구간에는 독립 주장이 생긴다. Rule에 사용된 원전, Methodology, 주장 ID, 실제 실행에서 읽은 천간의 위치를 추적할 수 있다. 원국 T8 근거를 T9의 작용으로 간주하지 않는다. 같은 관계가 원국의 두 천간에서 확인되면 문단 하나에 두 위치를 표시한다. 월운의 조회 시각 문단은 선택된 T9 구간의 주장만 표시한다.
