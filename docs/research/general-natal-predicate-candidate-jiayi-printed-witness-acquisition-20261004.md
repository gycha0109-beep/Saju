# R175 — 甲乙형 인쇄 witness 획득 후보 결속

> 날짜: 2026-10-04
> 상태: 연구 완료 후보
> 트랙: saju-research

## 목적

R174에서는 甲형을 국가도서관 실제 스캔의 인쇄면 50쪽에 결속했다.

반면 甲乙형은 공개 전사에는 존재하지만 실제 판면 결속이 없었다.

R175는 甲乙형을 실제 인쇄물로 추적할 수 있는 후보를 좁히되,
직접 판면을 보지 못한 자료를 물리 witness로 잘못 승격하지 않는다.

## 후보 1 — 159쪽 디지털 PDF 색인

易經易學의 ZPZ006 문서는 다음 메타데이터를 제공한다.

- 서명: 子平真詮評註
- 저자 표기: 沈孝瞻 原著 / 徐樂吾 評註
- 형식: PDF
- 총 페이지: 159
- 공개 미리보기: 앞 13쪽

같은 문서의 장별 색인은:

- 二十六 論行運成格變格
- 91–92쪽

으로 배치한다.

장 요약에도 壬生午月 사례가 "本命有甲乙"로 기술된다.

출처:

https://www.yijingyixue.com/ZPZ006/

그러나 91–92쪽은 공개 미리보기 13쪽 범위를 벗어난다.

따라서 현재 확보된 것은:

    디지털 문서 페이지 범위 후보

이지:

    목표 인쇄면 직접 시각 witness

가 아니다.

## 후보 2 — 上海印書館 1957 서지 기록

Google Books에는 다음 서지 기록이 존재한다.

- 子平真詮評註-命學要書, Volume 2
- 沈燡燔
- 上海印書館
- 1957

출처:

https://books.google.com/books/about/%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE%E8%A9%95%E8%A8%BB_%E5%91%BD%E5%AD%B8%E8%A6%81%E6%9B%B8.html?id=cHNAzgEACAAJ

이 기록은 실제 인쇄 edition 후보를 제공하지만,
현재 목표 문구와 목표 판면은 결속되지 않았다.

## 후보 3 — 홍콩 上海印書館 영인본 기록

星易圖書의 상품 기록은 다음을 기술한다.

- 子平真詮評註
- 徐樂吾
- 香港上海印書館
- 344쪽
- 繁體竪排
- 古籍影印

출처:

https://www.xinyibooks.net/goods-8303.html

이는 영인 계열을 추적할 단서지만,
상품 기록만으로 어떤 원판을 영인했는지,
목표 문구가 실제로 어떻게 인쇄됐는지는 확정할 수 없다.

## 현재 판정

현재 甲乙형에 대해 확보된 것은:

1. 공개 전사
2. 디지털 PDF의 장별 페이지 범위
3. 上海印書館 계열 서지 후보
4. 영인본 후보

이다.

그러나 다음은 아직 없다.

- 목표 91–92쪽 직접 시각 확인
- 甲乙 표면이 보이는 인쇄면
- 해당 판면의 물리 edition identity
- 甲형 witness와의 판본 계통 비교

따라서 R174의 상태를 유지한다.

    jiaOnlyPhysicalScanPageBound = true
    jiaYiPhysicalScanPageBound = false

## 실패 폐쇄 원칙

다음 등식은 모두 금지한다.

    PDF 색인 = 물리 witness
    페이지 범위 = 시각 검증
    장 요약 = 인쇄면
    Google Books 서지 = 목표 문구 witness
    영인본 상품 설명 = 목표 문구 witness

또한 미리보기 접근이 안 된다는 사실은
해당 문구가 없다는 부정 증거가 아니다.

## 다음 작업

다음 단계의 종료 조건은 명확하다.

1. 甲乙가 보이는 목표 판면을 직접 열 수 있어야 한다.
2. 해당 판면의 edition identity를 결속해야 한다.
3. 실제 인쇄 페이지 또는 folio를 기록해야 한다.
4. 그 뒤에야 甲형 스캔과 textual lineage를 대조한다.

그 전에는 completePhysicalVariantMappingEstablished를 true로 올리지 않는다.
