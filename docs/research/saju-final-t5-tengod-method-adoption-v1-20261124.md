# Saju Final — T5 십신 방법 채택 v1

- 결정일: 2026-11-24
- 적용 범위: 여섯 메뉴 공통 원국 판단의 연구·Reader 경로
- 근거: 기존 T5 계산 계약, Career P1/P2, General Natal 고전·현대 의미 경계
- 상태: **정확한 십신 유형·관계 계열·위치별 근거 보존 채택**

## 1. 결정 요약

T5는 일간을 기준으로 한 정확한 십신 하위 유형과 오행 관계 계열을 계산·보존한다. 십신이 어느 기둥의 천간·지지·지장간에서 나왔는지는 별도의 위치 근거로 유지한다.

T5의 십신 이름만으로 현대 심리 성향, 직업 적성, 구체 직업, 수입, 승진, 성공 여부를 확정하지 않는다.

## 2. 채택하는 십신 구조

| 관계 계열 | 정확한 십신 |
|---|---|
| 비겁·동류 | 비견, 겁재 |
| 식상·산출 | 식신, 상관 |
| 재성·교환 | 정재, 편재 |
| 관성·규범 | 정관, 편관 |
| 인성·지원 | 정인, 편인 |

정확한 하위 유형은 유지한다. 예를 들어 식신과 상관, 정관과 편관, 정재와 편재를 하나의 단일 역할로 조기 축약하지 않는다.

## 3. 위치 채널 정책

| 채널 | 처리 |
|---|---|
| 천간 투간 | 드러난 글자와 위치를 보존 |
| 지지 대표 십신 | 지지의 대표 관계로 보존하며 지장간 전체와 구분 |
| 지장간 십신 | 각 지지 내부 구성원별 십신을 독립 보존 |

위치·계절·통근·구조 관계는 의미값을 바꾸는 자동 가중치가 아니라 근거·맥락이다. 지장간 배열 순서는 본기·중기·여기 또는 힘의 순위로 해석하지 않는다.

## 4. T5 의미 범위

채택:
- 일간 기준 십신 하위 유형 식별
- 십신의 생·극 관계 계열 식별
- 동일 유형이 나타난 위치·채널·출처 경로 보존
- 서로 다른 십신 관계가 함께 존재할 때 공존 상태 보존

미채택:
- 십신 출현 횟수로 강도·우세 계산
- 위치별 임의 가중치
- 지장간을 천간과 동일한 노출 의미로 처리
- 한 십신을 곧바로 직업·성격·소득·관계 결과로 변환
- 고전의 친족·사회 역할 의미를 현대 심리·적성 의미와 동일시

## 5. 고전 의미와 현대 해설의 경계

기존 연구는 고전 십신이 가족·친족 관계 개념을 중심으로 설명된 층위와, 후대 명리 실무에서 심리·적성으로 확장된 층위를 구분한다.

따라서 다음은 별도 근거가 필요하다.

- 고전 십신 관계 정체 → 현대 성향 문장
- 십신 관계 → 직업 적성·직무 방식
- 십신 관계 → 구체 직업·성공·수입 결과

단순한 십신 계산이 위 확장 의미를 자동 승인하지 않는다.

## 6. Career T5의 현재 적용 한계

기존 Career P1/P2는 다음 두 차원만 연구용으로 허용했다.

1. 정확한 십신 하위 유형 의미
2. 십신 계열 간 생·극 관계 맥락

이 경로는 research-only, unreviewed, non-narrative다. T6 상호작용과 Career T8 결론을 만들지 않는다. 따라서 다른 메뉴에도 동일한 현대 직업 의미를 무단 전용하지 않는다.

## 7. 구현 완료 조건

- 천간·지지 대표·지장간 채널이 분리된 채 모든 필요한 메뉴 입력으로 전달된다.
- 정확한 십신 하위 유형이 보존된다.
- 위치·계절·통근·상호작용은 provenance/context로 남는다.
- 십신 의미만으로 현대 성향·직업·결과를 단정하지 않는다.
- T6 효과와 T8 분야 결론은 각각 별도 규칙을 통해 연결한다.
