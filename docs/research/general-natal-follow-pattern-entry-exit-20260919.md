# R029 — 從格 / 外格 entry and exclusion boundaries

Date: 2026-09-19  
Issue: #964  
Status: ENTRY/EXCLUSION PROPOSITIONS VERIFIED / EXECUTION BLOCKED

## Source
子平真詮評註 — 論外格用捨  
https://www.ncc.com.tw/fate/paleo/bg/bg_034.htm

## Entry gates
The commentary does not permit a follow-pattern merely because the day master looks weak.

It first requires:
```text
四柱氣象偏於一方
四柱無可扶抑
```

Then it distinguishes:
```text
日與月同 -> 從強 / 從旺
日不與月同 + 日元臨絕 -> 從官煞 / 從財 / 從食傷
日干化合 -> 化氣
```

## Strong exclusions
The same passage explicitly rejects external-pattern switching when:
```text
月令自有用神
干頭已有財官七煞 ordinary path
月令有用神、四柱有扶抑
```

It also rejects a common false entry:
```text
財被劫 / 官被傷
!= 月令無取
!= automatic 外格
```

Such damage must first be evaluated for 救應; absent rescue, it can simply remain a broken ordinary pattern.

## Boundary
One-sidedness, no ordinary 扶抑 path, 日元臨絕, ordinary-use availability, rescue availability, and transformation validity are not yet all governed executable predicates.

No 從格 classifier or Production authority is created.
