# R151 — Natal–Dayun temporal overlay replay corpus

Date: 2026-09-29  
Track: saju-research  
Status: research-only

## Purpose

R151 begins the temporal reasoning/replay block by preserving a basic semantic separation:

> a natal baseline and a temporally operative luck state are not the same layer.

The corpus does not implement a Dayun fortune calculator.

It replays existing governed temporal research so later temporal work cannot silently convert temporary activation, completion, break, rescue, or structural change into permanent natal mutation.

## Corpus shape

R151 contains 15 rows:

- 5 R072 natal↔Dayun interaction classes
- 5 R073 latent / activated / temporary state rows
- 5 R076 luck-triggered break / rescue cases

R136 is attached as a governance guard for Yong/Xi/Ji role identity.

## R072 replay

R072 provides five interaction classes:

- incomplete natal structure completed by luck
- natal hidden material exposed by luck
- meeting/clash causing temporal structural change
- natal context blocking or rescuing a luck effect
- pattern completion/change separated from ordinary help/harm

R151 preserves each as a natal-relative temporal mechanism.

It rejects an independent Dayun score and rejects the idea that the same luck pillar must produce the same result across charts.

## R073 replay

R073 contributes:

- NATAL_LATENT
- ACTIVATED_BY_TRANSPARENCY
- ACTIVATED_BY_NATAL_LUCK_MEETING
- TEMPORARY_OPERATIVE_STATE
- POSITION_CONTEXT_MODULATED

The key state distinction is:

NATAL_LATENT != TEMPORALLY_ACTIVE

The temporary operative state explicitly preserves expiry / return-to-baseline semantics in its bounded source representation.

R151 does not generalize that exact duration model to every temporal mechanism.

## R076 replay

R076 contributes five configuration-specific cases:

- luck exposes a damaging hidden factor
- natal seal rescues the apparent break
- natal counterforce blocks an apparent meeting-driven change
- completion is not necessarily favorable
- change is not necessarily harmful

These cases prevent a global break/recovery toggle.

They also prevent structural transition from being used as polarity by itself.

## Natal baseline identity

R151 uses baselineLayerIdentityPreserved as a representation invariant.

This means the natal state remains separately identifiable while a temporal overlay is discussed.

It does not mean every source explicitly proves the same post-luck restoration operation.

Only the R073 temporary-operative row records explicit return-to-baseline wording.

## Role identity boundary

R136 already shows that:

- temporal support does not automatically create a new Yong identity
- temporal opposition does not automatically reassign a role
- latent activation does not automatically reassign Yong/Xi/Ji
- structural completion/change does not automatically reselect roles

R151 therefore blocks automatic temporal role reassignment.

## Rejected shortcuts

R151 rejects:

- Dayun element alone determines outcome
- same Dayun means same result across charts
- temporal activation equals permanent natal mutation
- temporal completion equals permanent natal completion
- temporal structural change equals permanent natal rewrite
- pattern break equals permanent natal break
- rescue equals permanent natal repair
- activation equals concrete event
- completion equals favorable
- structural change equals harmful
- every Dayun reselects Yongshen
- support/opposition/activation automatically reassign roles
- positional context becomes a global temporal weight
- numeric temporal score
- temporal overlay becomes InterpretationClaim authority

## Authority

R151 establishes:

- natal baseline and temporal overlay are distinct representational layers
- Dayun meaning is natal-context dependent
- latent and activated states are distinct
- temporary operative state exists in bounded source evidence
- break/rescue behavior is context dependent
- structural completion/change is distinct from polarity
- temporal interaction is distinct from role reassignment

R151 does not establish:

- a general temporal transition resolver
- permanent natal mutation
- automatic temporal Yong/Xi/Ji reselection
- fixed temporal polarity
- deterministic event prediction
- numeric temporal weighting
- engine admission
- InterpretationClaim emission
- preview promotion
- production promotion

R152 should next address Dayun stem/branch methodology divergence before higher temporal layers are composed.
