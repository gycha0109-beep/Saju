## R10 결정

R10은 새 aggregation/strength authority를 만들지 않는다.

다음 단계는 기존 constituent를 억지로 합치는 것이 아니라 아래 blocker를 source-backed authority로 닫는 쪽이어야 한다.

- 比劫 coverage
- whole-chart 印綬 coverage
- 通根 completeness
- 黨眾 cardinality
- 比印重疊 threshold
- 通根+比印 composition

이 중 하나라도 빈 상태에서 constituent array length를 count로 사용하거나 黨眾/助寡 또는 強弱을 결정하면 authority widening이다.

외부 사람/전문가 승인 게이트는 요구하지 않는다.
