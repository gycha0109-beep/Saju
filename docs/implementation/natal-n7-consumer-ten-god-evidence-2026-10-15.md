# P0-NATAL N7 — 개인별 십신 관측 위치를 사용자 사주풀이에 연결

2026-10-15. **General Natal Preview 한정.** 정식 명리 해석 주장/판매 승격 아님.

## 문제

원국의 실제 천간·지지 십신 관측이 달라도 기존 일반 풀이 의미는 6쌍에서 반복됐다. N5는 명식 네 기둥을 사용자 본문에 표시했으나, 십신 위치의 실제 차이를 읽을 수 없었고 N6에서는 의미 중복 6쌍을 계속 품질 경고로 보존했다.

## 변경

- 요청마다 독립적인 호스트와 계산 snapshot을 생성해 **다른 사용자 동시 요청과 스냅샷 혼입 없이** 계산하고, 바로 그 snapshot으로 허용된 General Preview 응답을 구성한다.
- 본문 추가 전에 실제 응답 연·월·일·시주 값과 같은 snapshot의 계산 값이 **모두 일치**해야 한다. 하나라도 다르거나 출생시각이 불명확하면 아무것도 추가하지 않는다.
- 그 snapshot의 `derivedFacts.tenGods`에서 이미 **resolved** 된 각 위치(연·월·일·시 × 천간·지지 대표 십신)만 관찰 기록으로 표시한다. 일간은 배제하고 미상/모호 항목은 만들지 않는다.
- 문장은 '계산에서 확인한 십신 위치'라는 명시적 **계산 사실**. 어떤 결과도 예측하지 않고, 기존 해석의 권한·단락·의미를 덮지 않는다.
- 35건 실제 HTTP 소비자 출력에서 기존 해석 의미가 같은 6쌍의 위치 기록도 실제로 달라지는지 비교한다.
- N6 의미 품질검사에서는 새 계산 관찰 기록을 엄격히 제외해, 원래 의미가 **여전히 같은 6쌍**임을 계속 드러낸다.
- 동시 요청·같은 생일 다른 시간·출생시간 미상·잘못 짝지은 snapshot·재삽입 공격 등을 별도 실연 테스트한다.

## 중요한 한계

1. 이는 **십신 위치라는 계산 사실을 실 사용자 리포트에서 읽게 하는 개선**이지, 동일한 소비자 해석 의미를 서로 다른 전통 해석으로 바꾼 것이 아니다.
2. 다른 규칙이 적용된 원국 3쌍에는 Research `TEN_GOD_*`의 천간/지지 채널 변화가 있지만, 현재 프로덕션 Official Reading으로 직접 승격할 수 있는 근거는 없다.
3. 같은 규칙을 내는 나머지 3쌍의 복합 조건도 여전히 **#2529 출처 심사**가 필요하다. 근거 없는 강약·격국·용신·길흉을 창작하지 않는다.
4. 다음 N8은 근거·미리보기 승인 경계의 실제 결과에 맞춰 `claim → canonical semantic → reading plan → report` 단계에서 손실 원인을 입증하고, **승인된 의미만** 추가한다.

테스트 통과가 의미적인 개인화 완성을 뜻하지 않는다는 점을 명시한다.
