# SAJU-R41 — 《子平真詮》 정확한 甲–庚–己 간격 방해 연구 판정

이슈: #2448

Watchtower-Track: saju

## 실제 의미론적 전진과 원전

R38은 年干–時干 원격 천간합, R39는 제한된 쟁투/투합 배열, R40은 R38의 I61/I65 정확한 관계 교집합만 다룬다. 이 세 판정은 **甲과 己의 중간에 庚이 개입하여 합을 방해하는 원문 예시**를 별도로 판정하지 않는다.

직접 확인한 1차 스캔: [《子平真詮》 「論十干合而不合」](https://upload.wikimedia.org/wikipedia/commons/f/fe/NLC416-11jh010455-35296_%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE.pdf), PDF page 19/287 (zero-based 18), 인쇄 면수 十. 원문은 甲己 두 간의 사이에 庚이 놓인 경우 甲이 자신을 극하는 庚을 넘어 己와 합할 수 없다는 예를 든다. 원본 SHA-256은 기존 R38의 동일 스캔 고정값을 재사용한다. R38의 기존 스캔 메타데이터를 입력 출처로 재사용하며 새로운 독립 사본/출처 승자를 만들지 않는다.

## 채택한 한정 의미론

- 인정하는 것은 순서가 정확히 **甲 庚 己**이고 다른 한 천간이 甲/庚/己 밖에 있는 경우다.
- 허용하는 위치는 연·월·일 또는 월·일·시, 즉 네 천간 중 인접 3개 위치이며 중간 庚을 실제로 건너야 하는 한 가지 간격 패턴이다.
- 위 조건이 만족되면 오직 그 甲/己 한 쌍의 **완전한 합 성립 불가**를 fullJoining=false로 판정한다.
- 역순 己 庚 甲, 중간이 다른 천간인 경우, 두 칸 이상의 간격, 중복 甲/庚/己, 기타 관계 경쟁, 해석에 필요한 사실 불명은 **미판정**이다. 패턴 부재는 합의 성공이 아니고 지원이 없다는 뜻도 아니다.
- 원문은 연월일·월일시 두 배열에 한정하여 열거하지 않는다. 이 범위는 본 프로젝트가 오판 확대를 막기 위해 선택한 **보수적 V1 적용 영역**이다. 모든 천간합 및 뒤집힌 순서로 확장하지 않는다.

## 직접 검증

실제 날짜/시각과 기존 계산 정책: 1984-06-14 05:30, solar/male, Asia/Seoul, true solar time off. 엔진이 계산한 연·월·일·시 **甲子 庚午 己卯 丁卯**의 가시 천간이 **甲 庚 己 丁**이며 정확히 한 번의 R41 T2를 만들도록 검사한다. 이 날짜는 내부 계산 회귀 표본이지 고전에서 인용한 역사적 실제 명조가 아니다.

별도 synthetic fixture는 연·월·일 및 월·일·시 두 위치, 역순/경쟁/중복/단절 음성, canon/metadata/unknown-time/scenario fail-closed, 변조 후 envelope 해시와 ID를 다시 계산하더라도 replay 불일치, 결정성/비변이/R38 비간섭, Product 거부를 검사한다.
