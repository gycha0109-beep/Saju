# 사주 상품 12메뉴 — 실제 질문 입력 화면 구현

2026-10-22 · 사주 상품화 D 질문 트랙의 실물 사용자 경로

기존 사주 웹 MVP에는 한정된 풀이 메뉴만 있고 질문을 직접 입력할 수 없었으므로 `지금 고민으로 보기`가 실제 동작하지 않았다.

이번 구현:
- `지금 고민으로 보기 — 직접 질문` 선택 시 최대 180자의 질문 입력란이 표시된다. 그 외 메뉴에서는 입력란이 숨겨지고 비활성화된다.
- 텍스트를 입력하지 않으면 **‘궁금한 점을 입력해 주세요’** 안내와 함께 요청 전송을 막는다.
- 실제 입력은 `질문: 입력내용`이라는 기존 `normalizeConsumerReadingRequest` 계약에 전달된다. `질문: 직업운`, `질문: 올해 재물운`처럼 정확한 메뉴 주제에 일치하면 해당 기존 풀이 경로를 재사용할 수 있다.
- 자유 질문을 모든 주제에 답할 수 있다고 주장하지 않는다. 별도 근거 없는 질문은 `question_specific`의 기존 `insufficient_evidence` 정책에 따른다.
- `birth`, 출력 상세 선택, 미상 시간, 기존 보안 경계는 변경하지 않는다.

코드: `src/host/static-page.ts`, 기존 브라우저 화면 계약 테스트. 독립 명리 규칙/질문 T11 승인, 시스템 프롬프트, 임의 LLM 의미 생성은 없음.
