# P0-NATAL N20 — 한 명식의 서로 다른 방향/종류의 T8 구조 관계를 함께 읽기

**2026-10-16 · Research/HOLD · 소비자 Preview/Production 의미 승인 아님**

## 해결할 실제 해석 빈틈

N13은 T5→T8의 고전 구조 관계를 개별적으로, N14/N19는 연속되는 생성 관계의 공존을 실제 명식의 십신 위치에 연결하여 연구용으로 표시한다. 하지만 같은 명식에서 **생성 관계와 견제/충돌 관계가 함께 관측**될 때 기존 연구 자료는 이를 하나의 명식 안에서 나란히 읽지 못했다.

N20은 새로운 운세 판단을 만드는 대신, **기존 Registry가 실제로 발행한 두 T8 Claim이 같은 T5 Claim을 공유하는 것**만 한정해 관측한다.

## 범위

1. `食傷→財`와 `劫財→財`: 재성이라는 동일 T5가 각각 생성 및 견제 후보의 공통 대상임을 관측한다. 반드시 **정확히 겁재**가 있어야 하며 비견만 있는 명식은 제외한다.
2. `官殺→印`과 `財↔印`: 인성이라는 동일 T5가 생성 후보와 충돌 후보에 공통으로 포함됨을 관측한다.
3. 기존 N13의 T8 Claim ID 2개, 서로 다른 upstream T5 Claim ID 3개, 실제 T0 십신 위치, 출처 locator 2개 이상과 동일 snapshot/scenario를 요구한다. 누락·불일치·복제 Claim이면 거부한다.
4. 개별 명식의 실제 연·월·일·시, 천간/지지 대표 및 십신 하위 유형을 문장에 표시한다. 계산 위치의 차이는 별도 fingerprint로 구분하되 **새로운 해석 의미의 증가로 세지 않는다**.
5. `scripts/natal-n20-mixed-relation-packet.mjs`에서 기존 8개 실제 명식의 연구 결과를 JSON/HTML로 기록하고 CI 보안 경계/근거 검증을 수행한다.

## 의미상 절대 금지

- 생성과 견제·충돌 후보가 함께 관측되었다고 **상쇄, 우세, 가중치, 길흉, 성격, 직업·돈·관계의 실제 결과**를 추론하지 않는다.
- 같은 공통 T5가 있다는 사실에서 제3의 T8 인과 관계를 만들어내지 않는다.
- 출처 개수·규칙 매치·문장 차이가 외부 전문가 심사나 Production authority를 대신하지 않는다.
- 원천 Registry, N12 `usefulComplete:false`, Official Reading/Preview admission, Release/Commerce, 다른 트랙의 authority는 그대로 둔다.

## 실제 다음 해석 품질 단계

정확한 클래식 원문 증거와 출처 정합성, 반례, 실제 reviewer 검토 및 **claim-scoped Preview admission**이 없는 한 이 구조 설명을 소비자 인격·재물·성공 여부 주장으로 바꿀 수 없다. N20은 그런 중요한 빈틈을 적법하게 좁힌 연구용 종합 구조 관측이며, 종합 사주풀이 완료 판정이 아니다.
