## 이번 구현

`src/preview/whole-chart-structural-research-runtime.ts`에 `WholeChartTemporalDomainCoreReference`, `annualDomainCoreContexts`, `monthlyDomainCoreContexts`와 실제 근거 보기 경로를 추가했다.

기존 `annualLinks`와 `monthlyLinks`의 실제 **기간 내 T9 선택**에 더하여, 아래 세 종류의 증거가 모두 같은 계산 명식의 **동일한 공유 구조 Claim ID**를 참조하는 경우만 분야별 연결을 생성한다.

1. 연운 T9는 대상 서울 달력 연도가 실제 조회 시각의 연도와 일치해야 한다. 월운 T9는 실제 절입 구간 내부여야 한다.
2. 해당 연·월운 T9와 동일 계열의 **기존 공유 구조 T8 Claim**이 있어야 한다.
3. 그 공유 구조 Claim이 직업·재물·관계·사업 각 보고서의 **독립적으로 선택된 중심 T8 Claim**과 정확히 연결돼야 한다. 단순 비슷한 문구나 십신 계열 이름만으로 분야를 임의 추가하지 않는다.

연결마다 T9/분야 중심 T8/공유 구조 T8의 실제 Claim ID와 원문 출처 ID, 시기별 적용 구간을 보존한다. 출력 본문에는 참고 관계만 설명하며 **도메인 성패·돈의 증감·직장 변화·연애 사건·길흉의 인과 해석을 추가하지 않는다**. `temporalDomainOutcomeAuthorized=false`를 강제한다.

기존 `saju-500-whole-chart-structural-final-audit.mjs`에는 세 Claim의 실제 선별/출처 일치, 기간 일치, 중복 방지, 도메인 중심 T8 미보유 시 연결 보류를 마지막 검사 항목으로 추가했다.
