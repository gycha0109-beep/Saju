# 동일 출생정보 5분야 한눈에 보기 — 실제 사용자 화면

2026-10-21 · Watchtower-Track: saju

기존 Saju 제품 화면은 **한 메뉴를 선택해 한 답변만 받을 수 있었다**.
이제 `5분야 한눈에 보기` 버튼으로 전체 사주/직업·커리어/재물/사업/연애·관계를 각각 읽는 UI를 구현한다.

- 양력/음력, 생년월일, 출생시각 미상, 성별, 윤달과 새 **간단히/기본/자세히** 선택을 일괄/단일 요청에 동일하게 적용한다.
- 먼저 `POST /api/preview/natal-five-domains`에 한번 요청한다. **서버가 Preview 접근을 실제로 허용하는 경우** 같은 Canonical 명식에 기반한 다섯 기존 독립 답변을 화면에 렌더링한다.
- Preview 전용 API는 서비스 Bearer 보호 영역이다. 브라우저에 비밀 토큰을 넣거나 요청하지 않으며, 일반 Production 서버처럼 401/404로 막히면 **기존 /api/readings를 5개 독립 요청**해서 읽을 수 있는 분야부터 보여준다.
- 한 분야가 부족하거나 실패해도 다른 분야의 결과·부족 사유는 가리지 않는다. UI는 내부 Claim/Source/Rule 식별자나 새 명리 결론을 만들지 않는다.
- HTTP의 일괄 모드와 다섯 개 독립 요청 모드는 UI에 구별해 표시해 **계산 1회라고 허위 표시하지 않는다**.
- 이 화면은 Saju의 local/browser MVP이다. 명하 별도 UX 트랙·결제·서비스 운영 승격을 의미하지 않는다.
