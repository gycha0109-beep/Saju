## 로드맵 단계별 실제 완료 범위

1. **공유 명식 구조:** 월령 오행 관계와 본래 뿌리 종류 후보의 T2를 기존 십신 T5와 연결한 구조 T8 구현. 별개 문헌·기법별 왕쇠·강약, 격국, 조후, 용신의 **최종 판정 규칙은 아직 실행 권한·입력 전제가 부족하므로 미구현**. `R121`은 일부 통근 긍정 관측이 최종 강약 판정이 아니라는 점을 명시한다.
2. **전체 명식:** 서로 다른 종류의 T2 월령·뿌리 후보와 T5 십신을 하나의 **제한적 구조 관측 T8**로 소비 가능. 전체 명식의 최우선 구조·강약·격국·용신을 단일 결론으로 정하는 엔진은 **완료되지 않음**.
3. **주제별:** 기존 5개 T8 연구 결과와 공통 구조 T8을 정확히 대응시킨 해석 출력 경로 구현. 새 공통 근거를 사용해 **재물 유불리 등 인생 결과를 추가 판단하는 도메인 T8**은 미승인.
4. **시기별:** 실제 T9 연·월운 Claim과 같은 십신 계열의 공유 원국 T8을 출처별로 연결. 500명 중 대운의 **기간 계산은 가능**, 대운 상호작용을 해석 결과로 확정할 권한은 **R072에서 명시적으로 불허**한다.
5. **마지막 검증:** 최종 빌드·린트·500건 일괄 검사를 실행하고 결과를 분리 기록. 실행 성공은 의미 품질 승인이 아님.

## 근거에 의해 막힌 구현 항목 — 임의 완성 금지

- 통근/뿌리: 관측한 후보가 실제 모든 지지에서 `無根`이라는 판정이나 뿌리 세력의 수치 우위로 확대될 수 없음.
- 강약·왕쇠/격국/조후·용신: 각 연구 자료가 계열별 방법과 충돌, 시기, 조건을 나누고 있으며 **하나의 보편적 최종 판정기를 승인하지 않음**. 근거 없는 규칙·수치·강약 등급을 추가하지 않는다.
- 주제별 해석: 공통 월령 관측은 소득, 직업 결과, 결혼, 건강, 재산 수준을 판정하는 근거가 아님.
- 연운·월운: 출처 있는 시기 십신과 원국 관측을 대응한 것이지 개인 결과의 인과 해석이 아님.
- 대운: `src/research/general-natal-dayun-natal-interaction.ts`의 R072는 해당 상호작용 클래스들을 `executable=false`로 명시한다. 이 범위를 무시해 새 길흉 해석을 구현하지 않는다.
- 최종 Reader·기록 탭의 판매용 결과: 본 연구 패키지의 제품 연결과 의미 권한 승격은 별도 미완료. 문체 개선만으로 빈 사주 판단을 만들지 않는다.

**판정:** 이전의 십신 7개 직접 입력 경로에서 출발하던 종합해석에 실제 월령·뿌리 후보 사실이 추가로 도달하는 코드 경로를 구현했다. 그러나 이 범위는 **명식 전체의 숙련된 통합 해석 완성**이 아니다. 다음 구현은 이미 확보된 방법론의 정확한 제한 조건을 소비할 수 있는 **개별 구조 Claim의 허용 범위**부터 확장해야 하며, 없는 semantic authority를 만들어 내지 않는다.
