# 명하 사주 5개 원국 메뉴 — 공유 명식 근거의 일관된 소비 구현

- 작성: 2026-10-26
- 작업 브랜치: `feat/saju/500-personalized-reading-roadmap` — 별도 브랜치·PR·병합 없음
- 선행 구현: `613294c` (I13 천간 대비 구조 관측)
- 범위: 기존 공유 구조 T8와 5개 독립 원국 T8 사이의 **실제 선택된 Claim 참조를 한 번에 구성하는 소비 경로**
- 권한: **Research Preview** 전용. 신강·격국·용신·직업 성공·재물 등 사용자 결과를 새로 판정하지 않음

## 구현

`src/preview/natal-structural-integrated-research.ts`에 `SharedChartStructuralDomainEvidence`와 `sharedChartEvidence`를 추가했다.

기존 `domainSharedContexts`는 바꾸거나 없애지 않았다. 대신 현재 명식에서 실행된 `sharedStructuralT8ClaimId`별로 기존 5개 메뉴의 **실제 선택된 분야별 T8**을 역참조해 다음을 보존한다.

- 공유 구조의 실제 Claim ID·Rule ID·Source IDs·가족/채널·구조 유형·출처 보유 설명
- 해당 구조를 참조하는 분야(`general`, `career`, `wealth`, `relationship`, `business`)
- 각 분야에서 **실제 선택된** T8 Claim ID와 Source IDs
- `authorizesNewDomainMeaning=false`를 유지해, 참고 연결만으로 재물·직업·건강·미래 결과를 승격시키지 않음

기존 HTML 출력의 **공유 구조 추가 영역**에서는 같은 구조의 설명을 분야별 연결 수만큼 반복하지 않고, **구조당 한 번만 서술하고 실제 연결된 분야별 T8을 근거 접기 영역에 열거**한다. 기존 5개 메뉴의 독립적인 명리 해석 본문은 그대로 유지한다. 사용자용 정식 Reader·판매용 기록 탭의 표시를 자동 교체하지 않는다.

`scripts/saju-500-whole-chart-structural-final-audit.mjs`에 공유 Claim 1건당 집계 그룹이 정확히 1개인지, 그룹 안의 모든 분야 T8이 이전 소비 경로에서 실제 선택됐는지, Source ID가 원본과 일치하는지 검증을 추가했다.

## 남아 있는 한계

이것은 **기존 명리 구조 근거를 더 읽기 쉽게 묶는 실제 출력 구현**이지, 강약의 우위·격국·용신·재물 성패·대운 인과 관계를 새로 판정하는 작업이 아니다.

각 분야의 기존 T8은 독립 근거로 유지하며, 공통 구조의 참조는 **해석 결론을 공동 수정하는 권한**이 아니라 **실제 같은 명식에서 출처가 확인된 근거를 공유하는 기능**이다. 상품 완성 여부는 미승인이다.

남은 구현은 기존 로드맵 P0/P1에 따라 방법론별 허용 조건을 갖춘 명식 중심 해석을 확장하는 작업이다. 기존 연구에서 최종 판단 조건이 부족한 경우에는 보류한다.
