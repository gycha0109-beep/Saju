# P0-NATAL N24 — 기존 허용된 다섯 분야 풀이를 화면에서 끝까지 읽기

> 2026-10-17 · `saju` · Internal Preview only · Watchtower-Track: saju

## 실제 문제

N23의 다섯 분야 독자 화면은 첫 화면에 각 도메인 **최대 세 원문**만 놓았다. 그 밖의 실제 전달된 도메인별 허용 해석은 ‘전체 원문·연구·기술’ 한 묶음 안에 숨어 있었다. 본문이 부실해서가 아니라 이미 있는 상세 풀이를 찾아 읽기 어려운 **제품 전달 결함**이다.

## N24 구현

- 기존 N16의 검증된 HTTP 응답 원문, 출처 위치, 계산 사실 분리와 N21/N23의 첫 세 문장 선택을 유지한다.
- 각 분야 카드 바로 아래 `이 분야의 실제 추가 풀이 N개 읽기`를 제공한다. 뒤로 밀린 **실제 원본 해석** 전체를 별도 연구용 자료를 열지 않고 계속 읽을 수 있다.
- N23 첫 화면에 노출된 문장과 다른 분야에서 이미 한 번 보여준 **동일 원문은 재출력하지 않는다**. 각 원문은 정확한 원래 Preview 출처와 함께 기록하며, 도메인에만 있는 원문을 먼저 제시한다.
- 본문이 없는 영역, 미상 시각의 보류된 해석, 계산 전용 N5/N7 기록은 추가해석으로 채우지 않는다.
- 원래 N23 의미 fingerprint를 바꾸지 않고, **처음 표시 + 추가 표시 = 기존의 서로 다른 허용 원문 전체**를 불변식으로 검증한다. 일치하지 않으면 예외로 차단한다.
- 연구용 T8 의미, 사람의 인생 결과, 분야 간 새 인과관계, 새 등급·점수를 생성하지 않는다. Research / Preview / Official / Production 권한을 변경하지 않는다.

## 회귀와 실사용 근거

1. 기존 계산 기반 N21 테스트에 N24의 다섯 도메인 원문 전체 표시·중복 제어·출처·결정성을 추가했다.
2. N5/N7 계산 전용 설명, 출생시간 미상, snapshot 불일치, 변조된 해석 원문을 재검증한다.
3. 기존 `scripts/natal-personalization-audit.mjs`의 **35개 실제 HTTP Preview 사례**에서 각 사례의 실제 source interpretation을 N24로 완전하게 읽을 수 있는지 검증한다. `*.n24-expanded-source.json`에 독립 결과를 남긴다.
4. `scripts/natal-personalized-preview.mjs`의 다섯 분야 HTML에서 분야별 실제 추가 원문을 펼쳐볼 수 있고, CI HTML smoke에서 그 영역을 검증한다.

## 변경하지 않은 미완료 목표

N24는 **새 해석을 만들어 품질이 높아졌다고 주장하는 작업이 아니다**. 이미 전달된 상세 본문을 주요 사용자 흐름 안에 드러낸 기능이다. 명식 A와 B에서 실제 해석 내용이 비슷한 문제(35개 기준 중복 의미 쌍), 실제 T5·T6의 더 세밀한 조건을 T8의 독립적 개인별 결론으로 구성하는 일, 다섯 영역의 근거 있는 연결은 **P0-NATAL 미완료**이다. 후속 기능은 기존 source-approved claim 선택·소비자 문장 매핑을 직접 개선해야 한다.

Production·공개·판매·Research 승격 여부는 변경하지 않는다.
