# P0-NATAL N19 — 두 개의 T8 구조 관계를 실제 십신 위치로 풀어 읽기

**2026-10-16 · Research/HOLD. 승인된 소비자용 운세 설명이 아니며 새로운 개인적 해석 의미를 발행하지 않는다.**

## 이전 한계

N14는 같은 명식에서 이미 실행된 두 관계(예: 食傷→財, 財→官殺)가 동일한 재성 T5 관측을 공유한다는 사실까지 확인했다. 하지만 읽기 문장에는 식상·재성·관성이 **어느 연·월·일·시, 천간·지지 대표**에 실제로 존재하는지 제시하지 않았다. 서로 다른 실제 명식의 관계 패턴이 같으면 연구용 풀이도 거의 똑같이 읽혔다.

## 구현

- 새 Registry/계산기/의미 규칙을 만들지 않고 기존 `buildNatalN14LinkedT8ResearchReport`와 N13의 **실제 T5/T8 Claim 및 정규화된 계산 위치**를 재사용한다.
- 연결된 두 T8의 실제 관측 위치에서 **서로 다른 세 계열**(출발·공통 중간·도착)을 각각 추출해 `positionWitnesses`로 보존한다. 각 위치는 `factPath`, 연·월·일·시, 천간/지지 대표, 정확한 십신 하위 유형으로 역추적 가능하다.
- 연구용 설명 문장에 세 계열의 **계산된 실제 위치**를 제시한다. 이것은 구조 관계 공존 설명을 읽기 좋게 만드는 것이지, 해당 위치의 강약·우열·직업·재물 결과 또는 `A→C` 인과를 추론하지 않는다.
- 기존 관계 패턴의 `linkedSemanticSignature`는 변경하지 않는다. 별도로 `linkedPositionSignature`와 각 쌍의 `positionEvidenceFingerprint`를 만들어 **같은 연구 관계와 다른 실제 위치를 구별**한다. 서로 다른 위치나 문구 수를 새 의미 수로 세지 않는다.
- 포맷 변경은 별도 `positionProjectionVersion`으로 표시하며 기존 N14 핵심 버전은 유지한다.
- 기존 8개 실제 명식 연구 패킷 JSON/HTML을 업데이트하고, Research/HOLD·출처·미승인 표시를 유지한다.

## 검증과 다음 단계

- 두 개 실제 실행 T8과 3개 독립 T5를 요구하는 N14 게이트를 그대로 유지한다. 모든 표시 위치는 N13이 검증한 T0 십신 위치와 일치해야 한다.
- 같은 관계 집합이지만 관측 자리만 이동한 대비 명식에서는 **의미 서명은 그대로, 위치 서명과 문장은 다르게** 나온다.
- 조건 미충족, 원본 Registry/스냅샷 불일치, 합성 인과·현대 개인 결론, Preview/Production/Commerce 승격은 여전히 차단한다.
- 다음 과제는 정확한 원문 locator·조건·예외·독립 reviewer 및 범위별 Preview admission이 확보된 **특정 T8 의미**만 실제 소비자 원국 풀이로 연결하고, 최소 10건의 사람 리뷰로 검증하는 것이다.
