# P0-NATAL N10 — 35건 동일 의미 사례와 고유 표시 명식 쌍 분리

**분류 범위:** 기존 로드맵 N4/N6 내부 품질감사 확장. Research-only 의미·Preview 승인·Production·출시·판매 권한의 변경 없음.

## 재현 배경

N9 PR #2537 이후 실제 35건 Preview에서 같은 의미-only 본문을 가진 다른 표시 명식 **사례조합 20쌍**이 확인됐다. 하지만 2024-03-10 12:30은 반복 대조 fixture로 들어가므로 **고유 표시 명식 조합은 19쌍**이다. 20은 별도 의미 주장 20개가 아니다.

## N10 자동화

새 분석기는 N3 Research Claim 이름과 N6 소비자 본문 지문/계산 표시 지문을 결합한다. `GENERAL_NATAL_{family}_{channel}_THEME`의 *이름*이 다른 이유를 분리하되 그것을 명리학상 새로운 해석으로 바꾸지 않는다.

| 유형 | 실제 사례조합 | 고유 표시 명식 조합 |
| --- | ---: | ---: |
| 같은 십신 계열의 천간·지지 관측 채널 변화 | 3 | 3 |
| 다른 십신 계열 또는 복수 계열 조합 | 8 | 8 |
| 한쪽에만 특정 Research 테마 관측 | 6 | 5 |
| Research 규칙이 같으나 명식 사실이 다름 | 3 | 3 |
| **합계** | **20** | **19** |

`natal-baseline.n10-triage.json`에 두 집계와 원본 사례의 rule/claim 이름 차이를 보존한다. 기존 N8 3쌍 단계별 추적도 유지하며 신규 14쌍은 이 자료로 분류한다. 알 수 없는 규칙 차이는 `other_rule_change`로 보고하고 숨기지 않는다.

**한계:** 표시 명식의 factFingerprint는 전체 Canonical snapshot 동등성 증명이 아니다. 서로 다른 명식이 같은 의미를 가질 수 있다. 사람 검수와 출처판본/locator/방법론/Preview admission이 선행되기 전에는 십신 차이에 맞춰 직업·재물·성격·미래 결론을 새로 만들거나 의미 품질 통과로 간주하지 않는다.

## 남은 P0 종료 조건

사람이 직접 열어 읽은 대표 10건의 가독성·근거 적절성 검수, 실제 명식 차이에 상응하는 근거 기반 조합, 안전한 미상 입력/부분 근거 처리 및 제품 전체 품질의 최종 판정이 여전히 필요하다.
