# SAJU-R1 Canonical Capability & Runtime Reachability Audit

Status: observational refresh audit  
Issue: #1957  
Track: `saju`  
Authority effect: **none**

## Purpose

This R1 artifact answers one question: **what does the merged repository actually contain and what can the current runtime actually reach?**

It supersedes neither the 21-capability frontier nor any semantic/source authority artifact. It joins calculation, structural research, domain producers, extended readings, consumer plumbing, and verification into one inventory so the next implementation is selected by leverage rather than by the next available research micro-task.

## Current result

The strongest pattern is:

1. T0 calculation and ambiguity infrastructure are already implemented.
2. The main shared bottleneck is **chart-level structural synthesis**, not missing raw research volume.
3. Root/Tonggen, 旺衰/強弱, 黨眾/助寡, 格局, 調候, and 喜/用/忌 have substantial bounded research evidence but are not proven as one governed shared runtime layer.
4. Stem/branch relation facts are executable, but qualification/precedence/effect remain fragmented.
5. The existing five bounded Preview natal routes remain usable without being reclassified as Production semantic authority.
6. Spouse T8 now has Engine P0-P2 plus project-governed position-only materiality; the next gap is integration/materialization, **not external expert review**.
7. Annual/monthly routes have executable candidates and ProductHost coverage, but temporal semantic coherence remains upstream of consumer widening.
8. Compatibility and Question-Specific still lack dedicated governed producers.
9. Family remains a bounded research gap.
10. Consumer plumbing is mostly not the first blocker.
