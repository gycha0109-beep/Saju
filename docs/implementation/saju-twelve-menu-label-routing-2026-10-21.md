# 사주 12개 메뉴의 정확한 화면 명칭 → 기존 ReadingIntent 연결

2026-10-21 · Track: saju

사용자가 화면에서 선택하는 `직업·커리어 / 재물 / 연애·관계 / 사업 / 삶의 단계 / 올해 / 이번 달 / 배우자·관계`가 기존 사용자 요청 어댑터에 **정확한 정규화 키**로 등록되지 않아 정상 해석 엔진에 도달하지 못하는 부분을 수정한다.

- 기존 허가된 ReadingProfile과 Canonical 사실·기간 정책을 변경하지 않고 실제 UI 표시 명칭을 기존 reading intent로만 매핑.
- `가족`은 부모/자녀 중 임의 선택하지 않고 둘 중 어느 관계에 대한 해석인지 묻는다.
- `지금 고민으로 보기`는 구체적인 질문이 없으므로 결과를 만들어내지 않고 질문 입력을 요청한다.
- `궁합`은 상대방 명식/식별자를 여전히 요구한다.
- `올해`·`이번 달`은 요청 시점이 있어야 달력 기준 기간이 확정되며 명리 절기·대운 결과 승인으로 확장하지 않는다.
- `질문: 재물운`처럼 이미 구현된 정확한 질문 메뉴 라우팅은 상위 PR #2625에서 구현됐으며 본 PR은 **화면에 실제 표시되는 메뉴 명칭**을 추가한다.

이것은 입력에서 기존 해석으로 도달하는 연결 기능이며 자체 신규 풀이/출처/승인/Production/Commerce 권한을 발행하지 않는다.
