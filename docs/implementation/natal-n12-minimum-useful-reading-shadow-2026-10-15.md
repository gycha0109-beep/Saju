The general-natal useful theme T8s simply carry the same `FAMILY_MEANING` family-level headline/summary from T5. This is technical reachability, **not evidence of a substantive composite reading**.

N11 main follow-up: #2539 records 10 actual HTTP cases; N10 records 35 real cases and 19 independent distinct-chart copy collision pairs. Neither text uniqueness nor correct T0 facts proves T8 quality.

## Implemented in N12

- `src/reading/general-natal-mur-shadow.ts` classifies selected, snapshot-bound General Natal T8s into generic theme / observed structure / candidate core. It does not silently count generic themes or month-branch context as a meaningful multi-evidence synthesis.
- The shadow's `usefulComplete` is always **false until an independently admitted, source/version/methodology-qualified core synthesis is explicitly implemented**; the code does not allow callers to flip a boolean.
- The shadow keeps technical coverage, real HTTP consumer delivery state, candidate-core count, scenario uncertainty and provenance gaps separate, and fails on mismatched snapshot or nonexistent selected claims.
- A candidate core without explicit semantic admission remains `blocked_authority`, not automatically useful. Repeated upstream IDs are not independent evidence.
- N12 standalone 35-input audit executes the same canonical snapshot, official Registry, reading composition, and real Preview HTTP route as existing N3/N11 regression and exports `natal-mur-shadow.json`.
- CI confirms **35 actual HTTP cases, 33 technical deliveries, zero admitted substantive cores**. This is an accurate failure baseline, **not** a successful product quality metric.
- Existing `ProductReadingResponse.state`, partial evidence policy (`reading` forbidden), client entitlement, Legacy narrative, Research lifecycles and Official reading semantics remain unchanged.

## Quality semantics

A delivered reading with only general Ten-God topic paragraphs is `limited`, even if technical coverage is `complete`. A selected source-bounded research core candidate without exact claim-level admission is `blocked_authority`. A missing core or evidence is `insufficient`. Incomplete scenario coverage cannot be combined to simulate one complete person.

The N12 evaluator is deliberately conservative: no production-grade `useful_complete` branch is reachable yet. This makes the remaining **real** implementation requirement visible rather than gaming checks.
