# 명하 관상 엔진 — 전체 관상 범위 구현 로드맵 (FR-0~FR-11)

> 갱신일: 2026-11-04
> 트랙: face-reading / 저장소: gycha0109-beep/Saju
> 문서 성격: **기존 관상 아키텍처 v0.3의 FR-0~FR-11 범위·순서·완료 기준 명료화**. 새로운 개발 단계·전통 출전·측정/해석 권한을 발행하지 않는다.
> 전체 목표: 실제 관찰 가능한 얼굴 특징 → 출전별 전통 부위·형태 정의 → 근거가 있는 규칙 판정 → 부위별/종합 의미 결과 → 사용자 서술. 관상 해석은 전통 문화적 해석이며 과학적으로 입증된 개인 성격·미래 판정이 아니다.

## 1. 이번 갱신의 핵심

- **삼정만 완료하고 관상을 끝내지 않는다.** 삼정은 첫 시연·증거 검증 단위다. FR-1/FR-2에서 얼굴 전체의 세부 특징을 조사·추적하고, FR-3~FR-5에서 개별/복합 전통 규칙을 연결한다.
- 반대로 **모든 얼굴 부위의 측정 완료를 기다렸다가 해석을 시작하지 않는다.** 출전·관찰·방법론·실행 권한이 갖춰진 부분부터 연구용 실측/해석을 세로로 연결한다. 미지원 영역은 unavailable로 남긴다.
- 기존 구현(중립 관찰, TypeScript 평가기, 정적 snapshot, 출전 registry, 연구용 사진 CLI, FaceLab/Character 경계)을 재사용한다. 부위마다 별도 진단 엔진·임의 점수표·새 웹앱을 만들지 않는다.
- **세 가지 목록을 분리한다:** (A) 사진에서 관찰·측정할 물리적 특징, (B) 판본별 전통 부위/분류 지도, (C) 해당 특징/분류에 연결되는 출전·조건·결과 규칙. '인식할 수 있음'은 '관상적으로 해석할 수 있음'이 아니다.
- v0.3의 원칙(출전 계보 구분, 정적 V1에서 동적 기색 차단, 부위 가림 시 해당 부위만 unavailable, F1/F2/F3/F7 분리, semantic/서술/Character 경계, 사진 비공개)을 유지한다.

## 5. '전통 규칙' 목록 (C) — 등록 단위와 연결법

각 항목의 연결 사슬:

1. **출전**: 문헌/판본(witness)/원문 구절/계보와 검토 상태
2. **전통 부위**: 체계·방법론·버전·위치/형태 정의
3. **중립 관찰**: 사진에서 직접 측정 가능한 값·상태·촬영/품질 조건
4. **측정 연결**: 정식 기준점/계산/단위/보정/오차/누락 조건
5. **형태 판정(F1)**: 문헌 용어에 대응하는 검토된 조건(임계값 임의 생성 금지)
6. **개별 해석(F2)**: 출전이 정한 역사적 조건/결과, claim 종류와 해석 허용 범위
7. **부위 간 규칙(F3)**: 출전이 허용한 보강·상쇄·긴장만 결합
8. **종합(F7)**: 비교/우선순위 권한이 있을 때만 정리, 그렇지 않으면 병렬·보류
9. **표현/제품**: semantic projection → narrative → Character; 어디서나 원문·제약·불가 사유 추적 가능

각 분석 항목의 현황값은 **관찰 상태**, **전통 연결 상태**, **실행/공개 권한**으로 따로 표시한다. '코드 파일 존재'나 '연구 후보 5개 작성'만으로 개인에게 판정 가능한 상태가 아니다.

| FR-4.5 비교 | 삼정·오관·십이궁 간 비교 가능한 범위/비교 불가 원칙 고정 | 근거 없는 '가장 강한 궁'/TOP3/숨은 점수 차단 |
| FR-5 F7 종합 | 부위별 결과를 wealth/career/relationship/social lens에 **허용된 규칙에 한해** 종합 | claim graph/충돌/누락을 명시하고 무근거 개인 추론 없음 |
| FR-6 semantic | 개별 부위 측정/판정/종합 출전/보류 사유를 기존 semantic projection으로 전달 | 구조화 의미만 출력, 캐릭터가 새 결론 발명 불가 |
| FR-7 서술 | 눈·코·입·귀/전통 체계별 설명과 복합 판독을 기존 deterministic renderer에 연결 | 설명의 단호함이 승인 범위 이상의 사실 주장으로 확장되지 않음 |
| FR-8 UX | 얼굴 지도 선택→세부 관찰→전통 분류→원문·개별/복합 해석 표시; 삼정·오관·십이궁·종합 탐색 | 미지원/가림/승인대기 부위가 실제 UI에 구분됨; 근거 있는 TOP만 출력 |
| FR-9 Character | 승인된 의미 결과만 세연 등 캐릭터에게 전달 | 캐릭터별 말투 차이는 허용하되 해석 결론은 동일 |
| FR-10 bridge | FaceLab 공통 중립 관찰 재사용과 동의 기반 전달 | 중립 입력만 공유; 스타일 해석을 관상 근거로 사용하지 않음 |
| FR-11 future | 연령지도·점/흉터 확장·장기 기록·사주×관상 등 기존 후속 범위 | 명시적 범위/근거/동의·승인이 있을 때만 진행 |

**중요:** FR-0/FR-1/FR-2의 전면 종료를 기다려야만 FR-3가 시작되는 것은 아니다. 개별 부위의 출전·측정·승인이 충족된 세로 경로부터 연구용 평가를 실행한다. 다만 미완료 근거를 우회하거나 연구→Production 권한을 자동 승격할 수는 없다.

## 7. 다음 작업 순서 — 확인된 미완료부터

1. **중단된 기존 작업을 보존:** PR #2755의 중복·충돌 상태를 main과 대조해 정리하고, 로컬 미커밋 헤어라인 구간별 검토 코드의 내용·검증을 확인한다. 이미 #2756에 포함된 기능은 다시 만들지 않는다.
2. **기존 사진 검토 마무리:** 3·6·10번 검토의 부분 적합/부적합을 실제 좌표 영역으로 지정하고 검토 이력을 같은 사진/동일 검출 결과에 결속한다. 이 작업은 정식 측정 승인이 아니다.
3. **실제 관상 전체 목록 확정:** FR207을 출발점으로 A(물리 관찰)×B(전통 체계)×C(출전 규칙) 대응표를 현재 코드로 작성. 각 행에 '있는 코드/필요한 최소 기능/사용할 사진/연구 규칙/실행 권한/보류 이유'를 기록한다.
4. **측정 가능한 부위부터 세로 통합:** 기존 눈/눈썹/코/입술/턱 모듈을 사진 입력·중립 메트릭에 연결. 귀·이마/헤어라인·측면 필요 항목은 최소 추가 관찰만 구현; 불가하면 unavailable. 부위 하나마다 장기간 독립 검증 프로그램을 새로 만드는 방식을 반복하지 않는다.
5. **문헌 해석 병행:** 麻衣 삼정 연구 후보 5개와 별도로, 오관/개별 얼굴 부위의 원문 조건·결과를 기존 FR-0/FR-3 계약으로 정리. 수치 기준 없는 전통 용어는 정식 개인 해석에 사용하지 않는다.
6. **삼정 실측 미완료 마무리:** FR313~FR319 실사진/사람 검토, 동일 캡처 보정, 전통 기준점, 구간 차감 권한을 실제 근거에 따라 연결한다. FR319 중립 공통 프레임만으로 三停 실측 완료를 주장하지 않는다.
7. **부위 조합·종합·제품:** 근거 있는 F3→F7→FR-6/7→FR-8→FR-9 경로로 확장. 실제 사진에서도 관찰/측정/전통 해석 완료 여부를 부위마다 나눠 보여 준다.

## 8. 작업별 추적 항목과 완료 조건

전수조사/구현표 한 행에 필요한 항목:

- **관찰:** 영역명, 세부 특징, 실제 사진 필요 각도/가림/자세 조건, 기존 구현 경로, 측정값의 단위·출처·버전·동일 캡처 근거, 관찰 가능/제한/불가.
- **전통 연결:** 체계명, 원문/판본/페이지, methodology/region map, 중립 feature와의 대응, 해석 조건, claim/rule family, 문헌 상충/별도 계보.
- **실행/표현:** 연구 후보/승인된 연구 실행/정식 개인 실행/공개 중 정확한 상태, 불가 이유, 테스트/PR 근거, 부위별 사용자 화면 표시 방법.

**로드맵 완료 판단은 '파일 수'나 'CI 통과 수'가 아니다.** 우선 확정된 관상 범위의 각 행마다 실제 연결이 되었는지, 아니면 자료/측정 한계 때문에 불가능하다는 근거가 남아 있는지 확인한다. 승인된 범위의 필수 구현·검증·문서화가 실제로 모두 끝난 경우에만 ROADMAP_COMPLETE를 선언한다. 전체 대상 수·진행률은 전수조사 완료 전 임의 산정하지 않는다.

## 9. 승인 및 안전 경계

- FR207, 기존 엔진, 아키텍처 v0.3을 기초로 한다. 이 문서는 **새 측정 threshold·궁 경계·전통해석 claim·실행 권한**을 발행하지 않는다.
- 허용 범위 밖의 생산·캐릭터 공개는 HOLD를 유지한다. 《麻衣相法》 삼정 방법론 0.3.0 reviewed 승인은 유지하며 재요청하지 않는다.
- 귀 가림·헤어라인 실패처럼 일부 부위가 unavailable이면 다른 독립 부위의 측정/해석까지 일괄 실패시키지 않는다. 다만 연관 규칙의 입력이 없으면 해당 규칙은 보류한다.
- 인종·민족·종교·정치·성적 지향·질병/정신질환·범죄성·지능 등 민감하거나 근거 없는 속성을 얼굴에서 판정해 공개하지 않는다.
- 원본 얼굴 사진, 좌표 원자료, 신원 정보, 비공개 검토 기록은 로컬/일시적 처리 원칙을 따른다. 공개 Git에 올리지 않는다.
- 기존 사주 전용 docs/ROADMAP.md는 변경하지 않는다. 본 문서는 **관상 전용 기존 FR 단계를 구체화한 실행 로드맵**이다.
