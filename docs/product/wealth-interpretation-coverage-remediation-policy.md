# 재물운 해석 누락의 근본 해결 원칙 — 2026-10-31

> 상태: **개선 방향 기록 / 구현 및 품질 완료 아님**
> 기준: `docs/ROADMAP.md`의 2026-10-25 500명 실측과 현행 7단계 실행 로드맵
> 적용: 재물운 누락 원인 분석과 해석 지식 보강. 이후 다른 상품으로 확장할 때도 별도 품질 검증 필요.

## 1. 문제 정의

- 500개 명식의 계산은 모두 성공했으나, 재물운 풀이 문단은 389건에서 생성되고 **111건(22.2%)에서 생성되지 않았다**.
- 이는 해당 사람에게 재물운이 없다는 뜻이 아니며, 실제 서비스에서 반드시 빈 화면이 나온다는 뜻도 아니다. **현행 검사에서 소비자용 재물 해석 문단을 만들지 못했다**는 뜻이다.
- 현재 재물 중심 후보는 식상+재성+관성, 식상+재성, 재성+관성, 재성+인성, 비겁+재성, 비겁+재성+인성 등 6개 기본 패턴을 중심으로 한다. 111건 전부가 패턴 부족 때문인지는 확인되지 않았다.
- 단순히 문단 수를 채우거나 실패 사례 111개에 개별 예외 규칙을 추가하는 것은 근본 해결로 인정하지 않는다.

## 2. 확정한 개선 원칙

1. **역추적 후 공통 원인별 보완:** 111건의 입력 → 계산 사실 → 사용 가능한 구조적 근거 → 규칙 평가 → 활성 Claim → EvidenceSelector → 최종 문단을 추적한다. 원인을 계산·입력, 미등록 규칙, 규칙의 근거/권한 불충족, Claim 선택 누락, 렌더링 누락으로 구분한다. 확인되지 않은 원인은 미확인으로 남긴다.
2. **기존 지식의 누락을 우선 복구:** 계산 사실과 해석 근거가 이미 있는데 전달·선택·표현 과정에서 사라졌다면 해당 경로를 수정한다. 불필요한 새 규칙을 만들지 않는다.
3. **해석 지식의 일반화:** 등록된 6개 조합만으로 풀이 가능성을 판단하지 않는다. 기존 출처와 방법론이 실제로 뒷받침하는 범위에서 재물 관련 가치 생산, 자원·교환, 관리·책임, 준비·지원, 배분·협력, 구조적 긴장 등의 **독립 해석 축**을 검토한다. 축의 이름만 추가했다고 명리학적 의미 규칙이 생긴 것으로 취급하지 않는다.
4. **복합 명식 해석:** 단순 패턴 일치 문장을 나열하지 않고, 명식에서 확인된 핵심 결론, 적용 근거와 연결 이유, 독립적인 보조 요인, 상충 조건, 해석 한계를 함께 종합한다. 재성의 유무만으로 재물운의 유무를 단정하지 않는다.
5. **근거 부족 시에도 정확한 부분 풀이:** 충분한 종합 결론이 불가능하더라도 확인 가능한 사실과 그에 기반한 부분 풀이, 부족한 근거의 종류를 구체적으로 제공한다. 근거 없는 소득·투자 성공·재산 규모 예측으로 공백을 메우지 않는다.
6. **검증된 공통 해석 우선:** GLM 대화와 Luna 보고서가 서로 다른 명리 결론을 독립적으로 발명하지 않도록, 장기적으로 동일한 검증된 해석 결과를 공유하는 구조를 지향한다. 이 문서는 GLM/Luna 연동 완료나 해당 모델의 운영 배치를 선언하지 않는다.

## 3. AI 종합해석의 검토 경계

- **제안(미승인·미구현):** 결정론적 계산은 Saju 엔진에 유지하고, 모델에 확정 계산 사실·검증된 방법론·상품 범위·적용 제한을 제공하여 복합 해석 *후보*를 생성하게 하는 방안을 검토한다.
- AI의 해석 후보를 곧바로 공식 Claim이나 유료 Reading으로 승격하지 않는다. 기존 `mayGenerateClaims: false`, 근거/방법론/출처 권한, Official Reading 발행 경계와 충돌하는 변경은 **별도 아키텍처 결정 및 검증**이 선행돼야 한다.
- 계산 사실 대조만으로 복합 명리 해석의 타당성을 완전히 검증할 수 있다고 주장하지 않는다. 출처·적용 조건·상충 관계·반례 검증을 구분한다.
- AI 도입은 누락 해결의 필수 전제나 현재 확정된 구현 작업이 아니다. 기존 7단계 로드맵을 임의로 확장하지 않는다.

## 4. 실행 및 합격 기준

현행 `docs/ROADMAP.md`의 **단계 1(누락 원인 분류) → 단계 2(재물 풀이 개선) → 공통 의미 검증** 순서를 따른다.

- **원인 증거:** 111건 각각의 누락 지점과 실제 원인 또는 원인 미확인 상태를 재현 가능한 기록으로 남긴다.
- **결함 복구:** 원인별 공통 수정이 기존 실패 사례를 어떻게 바꿨는지 계산·근거·Claim·선택·문단으로 연결해 입증한다.
- **품질 기준:** 충분한 근거가 있는 유효 명식에서 근거 선택·출력 결함으로 인한 문단 누락은 0건을 목표로 한다. 근거가 부족한 명식은 확인 가능한 범위의 부분 풀이와 구체적인 제한 사유를 제공한다.
- **일반화 검증:** 기존 500건 재실행과 별도 신규 명식·경계 사례를 구분하여 검사한다. 문장만 달라지는 가짜 개인화, 정상 풀이의 회귀, 같은 명식의 의미 불일치를 불합격으로 본다.
- **출시 판단:** 문단 존재율 100%만으로 유료 상품 출시 적합성을 선언하지 않는다. 실제 해석의 깊이, 근거성, 개인화, 일관성, 독립 상품 가치가 함께 충족돼야 한다.
