## 2. 내부 채택 가능한 해석과 단계별 통과 조건

### T9 연·월운 — Saju #2762
- 기존 Canonical 원국·대운·연주·월주 및 서울 달력연도·입춘·절입의 실제 구간을 근거로 사용한다. 서로 다른 구간의 사실을 합치거나 달력연도를 입춘 운효력 연도로 바꾸지 않는다.
- 기존 T9 해석 규칙 중 구간/원국에 검증 가능한 핵심 의미를 내부 서비스 규칙으로 채택한다. 개별 기간의 핵심 주장마다 실제 계산 입력·해석 규칙·한계와 한국어 문단을 연결하고 모순·시각 미상을 테스트한다.
- 단지 다른 고전 원문·전문가 결재가 없다는 이유로 지원 범위 안의 풀이를 정지하지 않는다. 지원하지 않는 조합은 **그 문장만** 보류한다.
- 정식 발급 연결은 **별개:** 정확한 해석 버전·명식·구매 연/월·결과·서명과 고객 Reader 계약을 통과해야 한다. CI Green은 실제 운영 발급 허용과 다르다.

### T10 두 사람 비교 — Saju #2763
- 두 독립 Canonical 명식, 실제 합·충 위치·인물 식별·동일 해시, 생시 미상, 구조 상충을 검증한 **명하 내부 관계 설명 규칙**을 채택한다.
- 지원하는 범위에서는 합을 서로 맞춰 볼 지점, 충을 서로 조율할 지점을 점검하는 **조건부 대화·관계 구조**의 한국어 해석으로 제공할 수 있다. 이 표현은 명하가 채택하는 해석 관점이며, 합=무조건 좋음/충=무조건 나쁨 또는 결혼 성공·이별·외도·수명의 예언이 아니다.
- 원전 등급·용신 강약·다요인 우선순위가 재현되지 않은 경우 **그 방법의 단정·점수만 제외**한다. 실제 계산된 두 명식의 내부 규칙 기반 해석 전부를 자동 거부하지 않는다.
- 첫 상대/추가 상대/본인 T8+첫 상대 결합을 각각 실제 인물·구매·동의·권한·해석 버전에 결속한다. T8 문단 병치는 두 사람 종합 궁합을 의미하지 않는다.
- 명하 공식 발급 경로에서 서명·상대 동의/철회·중복발급·환불/취소 후 접근·보관함/Reader를 검증한 이후에만 내부 상품 해석 준비 완료로 판단한다.

## 4. 변경 금지 및 출시 판정

- `sourceType`, `reviewerStatus`, 서명 권한, 핸드오프 `maySell=false` 등을 용어만 보고 일괄 교체·승격하지 않는다. 내부 규칙이 구현·품질 검증되고 **정식 서명·권한 계약을 실제 통과**하기 전에는 발급/판매를 허위로 열지 않는다.
- `해석 자체 준비`와 `명하 전체 결제·운영 판매 가능`은 **서로 다른 결론**이며, 첫 번째를 통과한 후에도 결제·DB·개인정보·복구·배포의 실증이 필요하다.
- 과거 원전 감사·연구 결과는 그대로 보존하며, 현재 활성 로드맵과 상품 문서의 **새 완료 조건이 옛 역사적 판단 문구보다 우선**한다.
- 작업 완료 확인 항목: A형 불필요한 차단 정비 → B형 상품 의미/품질 구현 및 CI → C형 실제 발급·Reader 연동 및 보호 테스트 → 관련 문서/이슈 동기화. 모든 항목이 실제 증거로 충족될 때만 `ROADMAP_COMPLETE`.
