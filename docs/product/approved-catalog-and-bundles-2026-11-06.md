# 승인된 사주 상품 카탈로그 및 패키지 정책 (2026-11-06)

상태: 사용자 승인 확정. 문서화와 실제 상품·결제 활성화는 별개다.

## 단품
- 직업·커리어 / 사업 / 재물 / 본인 인연·관계운: 각 9,900원
- 올해의 사주: 7,900원
- 이번 달의 사주: 4,900원
- 궁합 독립 메뉴, 가족·배우자 별도 단품, 사랑·관계 패키지는 폐지/통합.
- '지금 고민으로 보기'는 판매 보류. 올해/이번 달에 사전 관심 분야 설문 없음.

## 패키지 및 옵션
| 구매 구성 | 포함 | 가격 |
|---|---|---:|
| 커리어·경제 | 직업·커리어 + 사업 + 재물 | 24,900원 |
| 전체 사주 기본 | 직업·커리어 + 사업 + 재물 + 본인 인연·관계운 | 29,900원 |
| 전체 사주 + 올해 | 기본 4종 + 해당 연도 | 35,800원 |
| 전체 사주 + 이번 달 | 기본 4종 + 해당 월 | 33,800원 |
| 전체 사주 + 올해 + 이번 달 | 기본 4종 + 해당 연도·월 | 39,700원 |

전체 사주 옵션은 각각 독립 체크박스로 선택한다. 추가액은 올해 5,900원, 이번 달 3,900원. 해당 연·월의 결과만 구매하며 자동 갱신/구독이 아니다. 기존 구매 결과는 재열람 가능하다. 구매 후 추가 옵션 선택 가능하되 과거 구매·환불·중복 권한에 대한 실제 차액 규칙은 Commerce 계약 검증 후 적용한다.

## 관계 비교
- 본인 인연·관계운과 관계 비교는 독립 구매 가능.
- 첫 상대방 12,900원, 동일 본인 명식의 두 번째 이후 서로 다른 상대방 각 9,900원.
- 본인 관계운 + 첫 비교 동시 구매 19,900원.
- 모든 패키지에서 타인 명식 비교는 제외.
- 자세한 규칙은 relationship-product-policy-2026-11-06.md 참조.

## 결제 권한 및 출시 경계
- Product와 Capability/Entitlement를 구분하며 구매 시 가격·권한·명식·기간을 변경 불가능한 스냅샷으로 저장한다.
- 서버에서 PortOne V2 결제 조회로 확인된 증거만 권한을 부여한다. 브라우저 리다이렉트만으로 권한을 부여하지 않는다.
- 기존 Commerce 결제 트랙 문서의 Launch MVP에는 bundle billing이 제외되어 있었다. **이번 승인으로 패키지 상품 정책은 확정됐지만 기존 결제 출시 범위가 자동 변경되거나 Production 판매가 활성화되지는 않는다.** 관련 결정문/계약 갱신과 구현 검증을 거쳐야 한다.
- 기존 구매의 중복 할인, 환불, 부분 보유, 업그레이드, 타인 출생정보 보관·삭제는 Commerce 및 개인정보 계약에 맞춰 구현한다.
- 각 단품의 공식 해석은 패키지 구매 여부와 무관하게 완결성을 유지한다.
