# 사주풀이 생성 언어 고정 정책 (2026-10-30)

## 적용 범위

- 명하의 **개별 사주풀이 생성 결과(Reading)**에 적용한다. 계정의 표시 언어(`accountLocale`)나 앱 UI 언어(`uiLocale`)를 영구 고정하는 정책이 아니다.
- 사주풀이를 처음 생성하기 전 **결과 언어를 필수로 명시 선택**한다. 계정·기기 언어를 결과 언어로 묵시 확정하지 않는다.
- 최초 생성 요청을 확정한 순간 해당 Reading의 `readingLocale`을 고정한다. **생성이 시작된 뒤에는 결과 언어를 변경하거나 다른 언어로 재생성·자동 번역하지 않는다.**
- 결과를 다시 열거나 PDF·앱·웹 등 다른 채널로 표시해도 최초 선택한 결과 언어를 그대로 사용한다. UI 언어를 바꿔도 기존 Reading의 본문 언어는 변하지 않는다.
- 실행 실패에 대한 재시도는 **같은 Reading과 같은 `readingLocale`**로 처리한다. 중복 생성 및 중복 과금 방지는 생성 요청의 멱등성 계약에서 보장해야 한다.
- 다른 언어의 새 풀이가 필요한 경우 기존 Reading의 언어를 수정하지 않고 **별도 생성 흐름**으로 취급한다. 구매·추가 비용 정책은 별도로 결정한다.
- 언어 선택 목록은 실제 생성이 지원되고 승인된 언어만 제공한다. 언어 코드가 카탈로그에 있다는 사실만으로 제공 가능한 언어라고 광고하지 않는다.

## 필수 UI 고지 및 확인

언어 선택 화면에서 생성 확정 **이전**에 아래 문구를 표시한다. 결제 단계가 있다면 결제 확정 전에도 같은 제한을 확인할 수 있어야 한다.

> **사주풀이 언어를 선택해 주세요.**
>
> 선택한 언어로 개인화 사주풀이가 생성됩니다.
>
> **사주풀이 생성이 시작된 후에는 언어를 변경할 수 없습니다.** 생성된 결과는 선택한 언어로만 제공되므로 신중하게 선택해 주세요.

사용자가 선택 언어를 확인한 뒤에만 최초 생성 요청을 전송한다. 단순 앱 언어 변경은 이 확인을 대신하지 않는다.

## 구현 경계

1. 생성 요청: 지원되는 `readingLocale` 필수 입력 및 확인 상태 검증.
2. 결과 기록: 생성 요청 및 결과에 고정된 `readingLocale`, 관련 요청 ID와 버전 연결.
3. 재조회·재시도: 최초 생성 언어와 다른 요청은 기존 Reading 수정으로 처리하지 않음.
4. 생성·계산·해석 및 언어 지원 여부 검증은 기존 권한 체계를 따른다. **이 정책만으로 다국어 생성, 제품 공개, 결제, T8/T9/T10/T11 해석 권한을 부여하지 않는다.**

이 문서는 확정된 **제품 UX·생성 정책**을 기록한다. 현재 사주 엔진에 언어 고정 저장·결제·생성 경로가 모두 구현되어 있다는 뜻은 아니다.
