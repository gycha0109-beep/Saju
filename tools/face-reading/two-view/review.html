현재 사진의 눈썹 분할 마스크가 있으면 가시 띠 두께, 분할 중앙선의 굽음·기울기와 두 영역 사이 간격 비율을 확인합니다. 실제 미간의 해부학적 너비, 눈 사이 거리, 개별 눈썹 털의 굵기·밀도, 전통 관상 형태 판정은 하지 않습니다.

현재 원본 사진의 양쪽 눈썹 모델 영역 안에서만 이웃 화소의 밝기 차이를 관찰합니다. 화소 차이로 개별 털의 굵기·밀도나 방향을 판정하지 않습니다.

이마·모발 접경 — 분할 영역 연구 후보

기존 머리카락–피부 접경 마스크를 사진 평면에서 평가합니다. 가려진 구간과 분리된 접경을 구별하며 실제 모근선·이마 높이·관상형을 자동 확정하지 않습니다.

정면 한 사람의 얼굴 타원과 눈썹 위에 위치한 피부 분할 후보를 확인합니다. 실제 모근선과 가려진 이마를 추측하지 않습니다.

귀 전체 분할 가시 영역 — 2D 모델 후보

기존 귀 전체 마스크의 상대 폭·높이·면적을 사진별로 비교합니다. 분할된 귀 전체 영역을 귓바퀴·귓불·부착부로 나누거나 실제 귀 두께·펼쳐짐을 측정하지 않습니다.

비공개 사람 귀 외곽 표시가 있을 때 표시선 다섯 지점과 모델 귀 전체 영역 경계의 사진상 거리를 대조합니다. 실제 귀 해부학적 정답이나 3D 돌출을 측정하지 않습니다.

코 분할 윤곽의 단면별 폭과 중심 이동 — 모델 후보

현재 정면 사진의 코 분할 마스크가 유효하면 위·중간·아래의 상대 폭과 중심 이동을 표시합니다. 분할 마스크의 높이 비율로 단면을 고른 것으로 실제 콧볼·콧구멍·코끝을 구분하지 않습니다.

양쪽 눈 분할 영역 — 2D 모델 후보

양쪽 눈 클래스의 폭·높이·면적·중심 간격을 확인합니다. 눈꺼풀 실제 경계·쌍꺼풀·전통 관상형은 판정하지 않습니다.

눈꺼풀 실제 경계·주름선 — 사람 직접 표시

정면 원본 사진에서 화면 왼쪽·오른쪽의 눈꺼풀 윗경계, 쌍꺼풀 주름선 및 피부 덮임의 가시 경계를 따로 표시합니다. 보이지 않는 주름은 임의로 생성하지 않고 해당 부위만 보류합니다. 기존 쌍꺼풀 보임/덮임 상태 라벨과 별개인 연구 검토 자료이며, 한 사람의 선은 검증된 해부학적 정답·입체 돌출·전통 관상형이 아닙니다.

턱·하관의 보이는 하단 윤곽 사람 표시

정면 원본에서 사진에 실제로 보이는 턱 아래 얼굴 외곽만 표시합니다. 완전 표시와 부분 가림을 구분하며, 골격·턱끝 돌출·실제 안면 해부학·전통 관상형을 판단하지 않습니다. 파일은 비공개 로컬에 보관하며 독립 정확도 검증 전에는 연구용 자료입니다.

입술·인중 경계 — 사람 직접 표시

정면 원본 사진에서 윗입술/아랫입술의 실제 보이는 경계, 인중 양쪽 경계, 화면 기준 좌우 입꼬리를 구분해 검토합니다. 분할 클래스 비율은 실제 입술 피부 경계의 정답이 아닙니다. 가려지거나 확인되지 않는 부분은 해당 부위만 보류합니다. 사람 표시 후보는 정확도 검증 전 모델 학습·정규 관측·전통 판독에 사용하지 않습니다.

귀 외곽·귓불·부착부 — 사람 직접 표시

정면 및 선택적 측면 사진에서 실제 보이는 귀의 외곽·귓불 경계와 얼굴에 맞닿는 점을 각각 기록합니다. 화면 좌우는 인물의 해부학적 좌우가 아닙니다. 불확실한 부위는 가림·사진 밖·판단 보류로 표시하세요. 이 결과는 연구용 사람 검토이며, 정면 사진만으로 귀 두께·펼쳐짐·전통 관상형을 판정하지 않습니다.

코끝·콧볼·콧구멍 — 사람 직접 표시

모델은 코끝·콧볼·콧구멍의 독립 해부학적 경계를 확정하지 못합니다. 정면 원본 사진을 보면서 보이는 부분만 직접 표시합니다. 화면 좌우는 인물의 해부학적 좌우가 아니며, 사람 표시선은 독립 정답·전통 판독이 아닙니다. 콧구멍 외곽이 선명하게 모두 보이는 경우에만 단일 선을 한 바퀴 그려 시작점으로 닫으세요. 완전히 보이지 않으면 일부 표시 또는 보류 상태를 선택하세요. 닫힌 표시선의 픽셀 명도 차이도 실제 내부 구조를 판정하지 않습니다.

눈썹 중심선 — 사람 직접 표시

모델 분할선이 아닌 원본 사진 위에 사람이 표시합니다. 화면 왼쪽·오른쪽 구별만 사용하며 전통 관상 판정이나 모델 학습에 자동 연결되지 않습니다.

사람의 중심선 표시 후 모델 분할선과 비교합니다.
